# 2D 内部有限尺寸通量思想如何升级到 3D

| 2D 实际实现 | 本轮 3D 对应要求 |
| --- | --- |
| root vessel 内部的一条线，垂直于根血管方向 | 首个分叉前的真实体网格平面截面，保留四面体切割三角形 |
| `_valid_interval_flux` 对可容纳给定半径的线段积分 | 对满足刚性球 WALL 间隙与上游连通条件的截面面积积分，得到 `Q_feasible(D)` |
| 半径边缘分布由可用线流量加权；旧源码采用均匀半径源分布 | 当前冻结 SonoVue `D≤4 µm` 源 PDF 乘 `Q_feasible(D)` 后归一化 |
| 给定半径，按线段流量选位置，线性密度逆 CDF | 给定直径，按正法向面积通量选择三角形及其内部位置，不能把三角形中心当随机样本 |
| 浓度 × 有效厚度 × 可用二维线流量 → MB/s | 浓度 × 对粒径积分后的真实体积通量 → MB/s，不引入有效厚度 |
| 与积分时间步无关的事件时间；Halton 坐标决定尺寸和位置 | 与时间步无关的物理进入率；事件 ID 和独立随机角色决定采样，worker 数不改变结果 |

不能直接复制 2D 的 µm、µm²/s、有效厚度、一维横向坐标或均匀粒径范围。3D 内部计算统一用 SI，面积为 m²，流量为 m³/s；展示时才换算 µm。源分布使用原冻结 SonoVue 合同，不改原始数据。

一个容易遗漏的事实：旧源码 `_nearest_inlet_connected_clearance_um` 实际返回当前位置的局部壁面距离，并未搜索三维上游可达路径。因此它不能作为 3D 上游有限尺寸连通性的证明。本轮必须单独证明；无法证明时应明确失败，不能把局部放得下解释为从入口过得来。

同样，旧 2D 的 `_build_root_section` 用网格深度及根段长度决定偏移。本轮不搬用这个经验偏移：先追溯真实几何的 root/first-junction 拓扑，按几何与网格确定候选序列，选择第一个通过全部门槛的截面。截面流量验证沿用冻结流场的 `mass_limit=1e-6` 相对误差标准，不另设宽松阈值。没有合格截面即停止，后续粒径表、事件和真实轨迹不得伪造或绕过此门槛。

新模型应使大粒径由于可用血流较少而更少进入，而不是先抽到大球，再不断寻找位置强迫该事件成功。生产采样器不得接触出口标签；出口流域仅用于独立审核。旧 Method B/C、旧轨迹及全部冻结动力学保持不变。
