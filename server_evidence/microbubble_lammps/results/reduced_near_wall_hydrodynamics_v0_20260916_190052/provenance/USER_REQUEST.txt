5. GCB 文献 closure
============================================================

本阶段采用 Goldman, Cox & Brenner 1967
“Slow viscous motion of a sphere parallel to a plane wall — II Couette flow”
作为 flat-wall simple-shear 物理依据。

DOI：

10.1016/0009-2509(67)80048-4

near-wall asymptotic 如果实现，必须在代码和 contract 中明确：

它只属于 h/a << 1 approximation。

不要把 near-wall asymptotic 宣称为 all-gap exact solution。

定义 dimensionless functions：

FU(epsilon)

FOmega(epsilon)

采用统一定义：

V_GCB
=
FU(epsilon)
*
d
*
g_wall

Omega_GCB
=
0.5
*
FOmega(epsilon)
*
(n cross g_wall)

这样 far-field convention 是：

FU -> 1
FOmega -> 1

如果本地已有可信的 GCB numerical/table reference：

10. Shear API
============================================================

实现概念 API：

evaluate_shear_rhs(
    radius_m,
    viscosity_Pa_s,
    gap_m,
    frame,
    g_wall
)

其中：

g_wall 单位：

1/s

并且必须 tangent to wall。

先显式投影：

P = I - n n^T

g_t = P g_wall

构造：

d = a + h

V_free =
d * g_t

Omega_free =
0.5 * cross(n,g_t)

构造：

V_GCB =
FU(epsilon) * d * g_t

Omega_GCB =
0.5 * FOmega(epsilon) * cross(n,g_t)

然后：

q_free =
[V_free, Omega_free]

q_GCB =
[V_GCB, Omega_GCB]

R_single =
R_bulk + R_wall_excess

最后：

b_wall_shear =
R_single*q_GCB
-
R_bulk*q_free

注意：

不得人为加入任何 normal force。
