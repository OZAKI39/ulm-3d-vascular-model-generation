9. 数学方程
==================================================

正式 ODE：

dX/dt =
U(X)

其中：

X =
bubble center position

U(X) =
FlowFieldSampler
对 frozen velocity field
做三线性插值得到的速度。

==================================================
10. 时间积分方法
==================================================

不要使用最简单 forward Euler
作为最终 production V0。

正式采用：

SECOND_ORDER_MIDPOINT_RK2

每一步：

k1 = U(X_n)

X_mid =
X_n + 0.5*dt*k1

k2 =
U(X_mid)

X_{n+1} =
X_n + dt*k2

然后：

V_{n+1} =
U(X_{n+1})

保存：

particle velocity =
sampled advective velocity

==================================================
11. 为什么使用 RK2
==================================================

报告说明：

RK2：

比 forward Euler 更稳定/准确，

但比 RK4 更便宜，

适合作为第一版大量粒子
frozen-flow transport baseline。

Python 独立 reference：

允许使用：

DOP853 / RK45 high accuracy

验证 RK2。

14. timestep 基础定义
==================================================

从 frozen field 计算：

max magnitude of valid fluid-node velocity

定义：

C_adv * dx / U_MAX

0.25

含义：

预计不超过约 0.25 dx 位移。
