# 下一轮最小开发选项（本轮未实施）

本文件只提出基于本轮数据的开发方向；不授权启动 500 条 production，不改变现有 2 nm handoff、horizon 或 subdivision 上限。诊断完成不等于这些修复已经被验证。

## 1. 先处理入口 rim 上的剪切目标适用性

**问题：**ID 3、15 的 FEM 向内速度约 2.4 mm/s，w=1 后却被约 1e-8 m/s 的 q_wall 目标替换；ID 22 同样极慢。成功路径也存在低剪切入口状态，不能仅用 mismatch 拟合开关。

**修改位置：**`planar_wall_hydrodynamics.py:planar_wall_affine_block` 的背景状态/目标构造；必要时由 `particle9a_motion.py:augment_planar_system` 提供已有的 feature 与入口拓扑信息。

**物理含义：**明确真实 FEM 背景输运与静止平面剪切近壁修正各自负责什么，推导入口边缘是否适用当前“完全替换背景”的闭合。候选应保留明确的远场/平面剪切极限和互易性，避免把有限边缘的法向直接当成充分的局部平面流动假设。先完成物理与代数约束，再决定最小代码表达；不强制速度向内，不挪出生点，不凭 mismatch 阈值开关模型。

**风险：**重复计入背景驱动或切向阻力、破坏平移/转动耦合与自由空间极限，或只修入口而仍保留内部 handoff 问题。

**最少重验：**已有 P9-A 单元与 pure-normal 回归；同样 ID 3、15、22 的首步和短程；通过后同一 12 条 A/B，仍使用原 1.5 s horizon。检查当前五条完成路径是否被破坏。无需先算 500 条。

## 2. 处理原 handoff 激活与试步验证之间的反复启闭

**问题：**ID 7、12、14、17 的末窗主要为 HANDOFF_ENDPOINT_BELOW_LOWER；接触带外恢复向壁速度、接触带内约束启用，反复产生微小接受区间。7、14、17 从相同状态切回 P6.5 仍失败；12 切回后恢复完成。

**修改位置：**`nearfield_handoff.py:handoff_constraints` / `wall_handoff_certificate`，以及 `particle65_motion.py:v1_trial` 的事件与约束衔接。

**物理含义：**使进入、沿着和离开既有 2 nm 下限的状态变化与连续时间几何验证一致。优先研究在原物理位置上定位 handoff 事件、保持可证明的单边约束续行，而不是依赖极窄的浮点接触带重复开关。保持几何原样、原 h_lower 和保守证书。

**风险：**隐藏地投影位置、吞掉被拒的物理时间、错误地保持已脱离的约束，或者破坏原 pair/wall normal 回归。

**最少重验：**四个已保存相同检查点的 P6.5/P9-A 续行；wall/pair handoff、连续时间覆盖、no accepted state below lower 与 no position projection 测试。比较接受位移等于速度乘实际 dt；不扩大 max_depth/guard。

## 3. 单独修正同一有限网格边上的近重复约束秩处理

**问题：**ID 7 的试步 453、454 中，三角形 3068 与 12079 共享同一条网格边，两条接触约束使接触子问题条件数约 1.19e13、velocity budget 增至 0.0332 m/s，实际向壁速度未被纠正。阻力 R 矩阵并未病态。

**修改位置：**`kinematic_contact.py:_dual_active_set`；必要时在 `nearfield_handoff.py` 提供同一几何接触特征的确定性标识，由 `resistance_solver.py` 保持原阻力度量下的独立法向残差检查。

**物理含义：**同一条几何边不应仅因属于两片相邻三角形而让数值容差膨胀。研究严格几何等价约束的秩表达/冗余处理，不新增 multi-wall 物理，不随意合并真正不同的法向。

**风险：**把不同壁面/角点所需的独立约束误删，破坏确定性次序、KKT 或互补条件。该问题只解释 ID 7 的一部分拒步，单独修它不保证四条全部恢复。

**最少重验：**本轮保存的同边双约束状态、一个真实不同法向的角点状态、原单接触和 pair 接触测试；再重放 ID 7 同一检查点。分别报告 R 条件数、接触条件数与实际法向残差，不能只看求解器 PASS。
