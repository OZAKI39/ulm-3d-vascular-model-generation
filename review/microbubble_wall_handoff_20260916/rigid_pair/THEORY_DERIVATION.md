# 刚性球近场阻力的独立推导与适用范围

两个刚性微泡靠近时，正面挤压液体、擦肩滑动和旋转都会产生阻力。本阶段的球半径固定，形状不会改变。

本模型是有明确定义的近场近似，不是精确的双球 Stokes 全距离解，也不是有壳层的真实微泡模型。系数的 1e-10 门槛检验实现与冻结数学定义的一致性，不表示对真实微泡具有 1e-10 的物理准确度。

## 原生项为什么不够

原生 sq/sh 的标量与修正后的 XA/YA 奇异部分一致，但原生接触点速度把力—转动耦合固定为 a*YA、b*YA。异径球需要独立的 YB 系数，两者不同。原生 pump 又把单球 C11 类型系数直接加在已包含旋转力矩的 shear 之上，不能视为完整耦合矩阵的剩余 pump 阻力。lubricateU/poly 中的相关实现也单独提取验证，不能因为名称相近就假定与 lubricate/poly 完全一致。

## 从独立阻力矩阵分离 shear 与 pump

令 L=log(1/xi_gap)，beta=b/a，以下系数含 mu：

```
Y0 = 6*pi*mu*a * [4*beta*(2+beta+2*beta^2)/(15*(1+beta)^3)] * L
Bi = 4*pi*mu*a^2 * [beta*(4+beta)/(5*(1+beta)^2)] * L
Bj = Bi evaluated with a,b exchanged
Cii = 8*pi*mu*a^3 * [2*beta/(5*(1+beta))] * L
Cij = 8*pi*mu*a^3 * [beta^2/(10*(1+beta))] * L
```

这些式子满足 Bi+Bj=s*Y0，Cii+Cij=s*Bi。它们支持通过平方配方分离接触点滑动和相对横向旋转：

```
l_i(contact) = Bi/Y0
l_j(contact) = Bj/Y0
P0 = Cii - Bi^2/Y0
   = 6*pi*mu*a^3*b^3/[s*(2*a^2+a*b+2*b^2)] * L
```

这是 Schur 补，不是把两个不同的旋转阻力做经验平均。P0 对 a,b 对称且为正。等径时 P0=3*pi*mu*a^3*L/5；单球 Cii=8*pi*mu*a^3*L/5，二者不是同一个物理量。

## 有限间隙的客观性补全：本项目 V0 的显式近似

文献奇异横向矩阵按接触极限 R≈s 写出。直接把接触臂长用于实际中心间距 R，会产生 O(h) 的内部总力矩，也不会严格消去球对整体刚体转动。

本项目采用工作共轭的客观性补全：

```
l_i = (R/s) * Bi/Y0
l_j = (R/s) * Bj/Y0
P   = (R/s)^2 * P0
```

因此 l_i+l_j=R。对横向旋转作 R/s 的合同变换后，仍然有对称的非负耗散；这一补全不是从原文中照抄的有限间隙精确解。它的差异在 h/s→0 时消失。本项目保留稳定版已经核对的完整 sq/sh 标量（含 xi_gap*log 项），但不声称这样补全的全部横向高阶项等于精确 Stokes 阻力。

记 Pn=I-nn，定义滑动 s_t=Pn*(Vi-Vj)+n×(l_i*wi+l_j*wj)，横向相对转动 w_t=Pn*(wi-wj)。无背景驱动时半耗散为：

```
Phi = 0.5*X*[n·(Vi-Vj)]^2 + 0.5*Y*|s_t|^2 + 0.5*P*|w_t|^2
```

生产 C++ 从各模式 B^T D B 构造矩阵；独立 Python 直接构造 3×3 分块，两种实现相互检查。力和力矩等于 -dPhi/dq，因此 Fi+Fj=0，R*n×Fi+Ti+Tj=0。给整个球对加相同平移或刚体转动，不产生内部阻力。

## 背景流及六自由度求解

每颗球读取冻结三线性速度和其解析导数，取得 Uinf、Omega_inf=curl(U)/2、E_inf=(gradU+gradU.T)/2。孤立平动、转动阻力分别是 6*pi*mu*a 和 8*pi*mu*a^3。

球对使用局部仿射闭合，Ebar=(Ei+Ej)/2。模态目标由 B*q_inf 减去 s*Ebar*n 的法/切向分量构成，与原生表面应变修正的近场约定一致。对于单一仿射流，剩余法/切向背景滑动是 h*E*n。高阶空间变化不等于精确双球非均匀流解。

旋转/任意驱动验证算例的外力、外力矩只加在总 RHS，不能伪装成流体 Omega_inf 后一起抵消掉球对阻力。正式真实血管案例没有这些额外驱动。

矩阵按 q_scaled=(V,a*omega) 缩放后做性质审计；验证 SPD 后选择 PCG。硬接触通过主动集的 Schur 补求解，线性阻力子问题仍使用 PCG。

## 非重叠与积分

h_min=0.001*a*b/s 只用于避免阻力发散，不是弹簧、壳层或实测粗糙度。作用区 h<0.2*a*b/s；从冻结前即固定，不根据结果调节。

每一步都约束 n_start·(Vi-Vj)>=-max(h_start,0)/dt。因为距离范数大于等于它沿初始法向的投影，该约束保证整条线性位移段不穿透，不仅保证末端点。RK2 中点与最终位移分别使用半步和整步约束，再独立计算 swept-sphere 最短距离。最终轨迹接受门槛为 gap>=-1e-12 m。

C_adv 保持 0.25。C_gap 的 0.4/0.2/0.1 对照及预先冻结的误差门槛保存在 contract；0.1 为参考。每步还检查壁面间隙与流场查询有效性。

## Twist 的待验证范围

Townsend 式 (26–27) 确实给出非奇异 XC11、XC12，包含 Hurwitz zeta 与 xi*log 项。但是这组完整轴向阻力包含共同旋转相对于远处流体的阻力。直接加到保留的孤立 Stokes 转动阻力会重复计数；只取交叉项或删除集体模式也会额外定义一个尚未验证的匹配模型。

本次没有把这些非奇异项强行加入，twist=PENDING_BLOCKER，C3 不执行，也不允许 FULL_ROTATIONAL_LUBRICATION=PASS。已实现的横向旋转、异径球耦合和防重叠必须各自通过；不能用 twist 待验证掩盖它们的失败。
