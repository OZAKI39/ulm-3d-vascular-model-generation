# BraVa 局部 P2 / 近壁模块联合审查

结论：**LOCAL_P2_NOT_YET_SPATIALLY_RESOLVED**；近壁实现：**IMPLEMENTATION_MATCHES_DECLARED_MODEL**。已按 A 区停止门槛结束本轮计算。图文入口（历史引用 `OPEN_RESULTS.html`；结论见本报告和最终摘要，旧路径已清理）。

1. **主要原因是什么？** 现有证据更支持近壁 CFD 场表示及几何/单元边界上的输运敏感性，而非已发现的近壁模块实现错误。直接复用既有失败机制（历史引用 `../mesh_particle_validation_v2/P1_FAILURE_MECHANISM_ZH.md`；结论见本报告和最终摘要，旧路径已清理）：原 P1 单元 138584 的四个顶点全在零速壁面，使整个单元精确零速；ID440/1505 接近其内部零速面时发生有限精度推进停滞，当时没有接触约束，不能解释为物理黏附。ID1189 加速窗口速度约 0.030→64.16 mm/s，而硬接触修正最大仅 0.00191 mm/s；该观察不能证明所有速度急变都只有一个原因。

2. **P2 是否已稳定改善？** 尚不能。A 区同边界局部 P1、P2-medium、P2-fine 已完成；P2 两档比较未通过预先冻结门槛：

| 距壁 | u 相对差 | G 相对差 | WSS 相对差 | 法向速度差/细网格速度范数 |
|---|---:|---:|---:|---:|
| 0.1 µm | 21.76% | 21.75% | 15.95% | 14.97% |
| 1 µm | 21.62% | 21.47% | 15.95% | 14.89% |
| 10 µm | 20.22% | 19.31% | 15.95% | 14.14% |

门槛为近壁 u≤5%、G/WSS≤8%、法向速度差/速度范数≤0.5%；bulk u 差为 1.30%（门槛 2%）。原 388769 单元中心的相对散度 η，局部 P1 / P2-medium 为 0.987 / 0.600；细网格在该点的 6 个单元侧梯度给出 0.092–0.409。内部面上的原始梯度不唯一，见[单侧值核验](field_comparison/A_TARGET_ONE_SIDED_TRACES.json)。单点变化不替代空间稳定性，未经稳定性门槛的 P2 不能作为正确解裁判。

近壁压力 RMS 差/网络截面压差为 4.07%–4.15%（门槛 2%）。fine 全局相对流量缺口为 9.4e-10，仍不能抵消上述局部差异。

3. **近壁代码是否忠实实现声明模型？** 五类小夹具通过；ID1189 与正常近壁控制 ID637 共 33,198 个保存状态重算，最大速度复现误差 3.06e-18 m/s，未重新积分。两共面三角形切换时，gap、normal、velocity 未跳变。混合权重满足 C1；阻力截断允许 C0 折点。硬接触启用可以截去朝壁速度，其速度连续性不属于模型承诺：这是 **MODEL_LIMITATION_NOT_IMPLEMENTATION_BUG**。源码、近壁参数和 SonoVue 未修改，也未重复大规模 CPU/GPU parity。

4. **下一步怎么选？** 暂停升级与生产计算；不继续全域 P1 加密，不立即全域 P2，不据此修改近壁物理。若用户决定继续，应先解决局部 P2 空间稳定性及人工截面条件的适用范围；本轮不执行该阶段。

边界沿用“中心线阻力估算 → 压力”：原设计 O1/O2/O3 为 508.2334365 / 0 / 24.3093602 Pa；局部入口取网络流量，下游压力由同一网络沿程推算，未使用校准 CFD。旧 M0/25/20 仅作历史证据，不能把不同边界下的差异归因于元素阶次。局部 P1 使用必要的 SUPG/PSPG 稳定化，因此也不是对 SimVascular 原离散的逐项复刻。

A 的 P2 网格为 28,268 / 101,401 单元、130,794 / 447,679 DOF。采用 DOLFINx 0.11.0、8 MPI CPU 进程；RTX 4090 用于 FP64 近壁审查。原几何未平滑，P2 导数按单元二次多项式直接求值；人工边界区不进入核心统计。预处理与求解器适配失败日志均保留，见开发记录（历史引用 `provenance/DEVELOPMENT_NOTES_ZH.md`；结论见本报告和最终摘要，旧路径已清理）。

A 核心单元最长边的中位数为 217.7 / 126.7 µm；这是体单元实测尺度，不能当作旧 25/20 µm 表面网格参数。合格 fine 求解耗时 24.8 min、进程树峰值 10.74 GiB；包含失败适配的已记录求解作业累计 69.8 min，见资源账目（历史引用 `monitoring/EXECUTION_SUMMARY.json`；结论见本报告和最终摘要，旧路径已清理）。
