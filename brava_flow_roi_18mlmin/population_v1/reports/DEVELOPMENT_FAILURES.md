# 开发失败记录（不作为最终生产结果）

1. `runs/realization_0000`，代码 `71dfef5d17488f079604e597e5aaa04de3aeeb78`。共享时钟下某个困难近壁轨迹促成极小子步；原单泡进展保护直接套用全部同步粒子，误触发其他粒子。核实 PID=663341/命令/算例目录后仅 SIGINT 该新程序，未影响旧 STOPPED 批次或 CFD。中断时终态证据写入循环尚未完成，异常处理中的 accounting assertion 阻止最终关闭；因此部分 gzip 可能没有尾部，原 bytes 和 NPZ 保留，不伪造完整 manifest。
2. `runs/realization_0000_guardfix`，代码 `76fc91e50a86b683123d960925c9079363ea5907`。已修显式 handoff，但拒绝试步后递归细分的责任者未记录，导致群体时间停留在约 1.4905002146 s；未像第一版批量误移除，而仍不能及时释放细分触发者。核实 PID=664809 后 SIGINT；FAILED_EXECUTION 和 manifest 如实保留。
3. `e62d654a63b33225e2629df7316200a57a58de67` 记录所有拒绝来源（wall/pair/FEM endpoint）的责任者；小步保护只作用于实际触发者。新增 GPU/CPU 安全监视回归及球对拒绝责任回归，25 测试通过。阈值没有放宽。正式 run `realization_0000_final` 使用该版本。
4. 阶段四最初的测试期望曾用三角形质心简单求和以及过短 Poisson 观察窗，造成夹具断言错误，修正测试后保留原失败描述。不能用修正夹具替代真实入口 30,000 事件检查；后者另行运行。
5. GPU 有限壁面验证初次执行的科学 JSON 已保存 PASS，随后 console `json.dumps(np.bool_)` 打印失败。打印改为读取规范 JSON 字符串；真实数值结果和原日志保留，不将此说成 CUDA 几何失败。
6. 单体三壁支持静止判据不适合直接应用于耦合接触组件。最终实现要求连续32次孤立求解，耦合球对不会被该单体判据误移除。合成正碰/斜碰及稀疏链另有组件验证。

前三条运行是同一随机种子的开发重复，不是独立统计 realizations。不得合并计数。终态 `SOLVER_FAILURE`、人为中止开发 run、模型支持静止、观察截止是不同情况。

7. `realization_0000_final`（e62d654a6）是第三个开发/审计运行，不能因名字含 final 就当最终产品。真实失败点1131的32个历史状态暴露近共线法向的 GPU 容差过宽：场/壁面几何一致，但速度最大差2.633736141417612e-7 m/s。生产已核实PID后中止。改用与原 dual Gram 相同的 sqrt(n*eps) 数值分辨率识别无法可靠处理的奇异值；这类状态明确交由原 CPU 正锥约简权威处理。新增合成近共线回归，另实际回放该32状态验证有效回退，而非仅另写公式自证。当前交付使用 `realization_0000_contactfix`、commit `98d705f13babdfa0cba6c12331623292a588cb77`。

补充脚本的失败也保留：`benchmark_pair_component.log` 曾把组件容器当作单组件读取字段；修正读取 `components` 后计时成功。实际接触回退回归最初要求32个状态全部回退；其中12个已是精确重复法向，原GPU严格解可处理，因此修为只在需要回退的状态走真实引擎回退，并对所有32个有效结果与原CPU逐一比较。
