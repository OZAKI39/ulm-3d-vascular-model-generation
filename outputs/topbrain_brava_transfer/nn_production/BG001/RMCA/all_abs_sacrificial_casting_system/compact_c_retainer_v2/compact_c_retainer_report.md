## 方法与冻结边界

本研究只重构 s1-10 的独立防浮插片。血管芯、半径、延长管路线和长度、外模尺寸、墙厚 2 mm、底厚 3 mm、下托弧、壁侧溶剂窄片、中央血管放置和已验证裁切面保持原值。O2 主基准和其余次基准均从当前布局清单读取。源 CAD、STL、清单、SWC 与旧生产文件逐字节保护；本轮没有重新拟合血管，也没有修改既有可视化界面。

角度候选为 90°、120°、150°，分别保留 270°、240°、210° 开口。候选先经过抗浮、顶部装入、轴向余量、中央零接触、延长直段限制、壁侧通路、孔腔和真实切片门槛，再按最大高度、总体积依次排序，无黑箱评分。C 弧轴向长度 1.20 mm、径向壁厚 0.44 mm（实际 0.22 mm 线宽的两条线），通过渐变短颈连接到原导向内的短舌。后端落座于既有内墙；不改变内墙或导向。打印时 C 的轴向端面朝下，局部端口轴转为打印 Z 轴，短颈逐层扩展，不采用悬空长柄。

顶部装入的障碍包括冻结血管、完整外模及托座、已经装好的插片。前段路径采用连续距离界限检查；最后短距离落座使用去除墙体后的连续检查、盒腔凸半空间约束与最终 CAD 零交叠共同证明，不把有意的墙面接触误报为穿透。插片向上 0.8 mm 时原导向阻挡，端口向上 1 mm 时新 C 上限位阻挡。有限探测并不证明任意组合运动都被约束，更不证明抗浮承载力。

## 溶剂路径与孔腔解释

正式端口路径为外部浴 → 外墙 → 壁生窄片 → 有限面积接触区 → 延长端口 → 血管网络。重建图后明确移除所有插片节点再验证四条独立通路。短插片完全包埋时，不能仅凭“同为 ABS”断言能够溶解；本方案另验证其后端与外墙的有限接触面，使外墙移除后能到达插片自身。该支路不会计入血管必要入口。两类名义接触都必须实物确认，若形成连续 PDMS 薄膜，应视为通路失效。

新插片的孔腔全部位于原端口外围裁切区内。沿用同一组 11 个有限裁切面，不移动切面迁就插片；中央血管和无关端口未被切到。最终 PDMS 与“原保留包络减去冻结血管”的理想域做双向布尔比较，检查额外缺损与残留。诊断布尔沿用原共面接触数值处理，仅在已被血管占据的域内进行 0.0001 mm 接触缝合，生产 STL/STEP 不变。
