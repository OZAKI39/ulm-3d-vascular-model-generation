# MEVO acoustic–microbubble project snapshot

The current PZT → acoustic field → microbubble project is in
[computation_examples/mevo_acoustic_microbubbles](computation_examples/mevo_acoustic_microbubbles/SNAPSHOT_README.md).

This branch adds its source, complete source Git history, selected scientific data,
run logs, validation evidence and current B2/B3 animations. Large event streams,
rebuildable caches and active Stage J binary data are excluded with an inventory.
Stage 4 as a whole is not declared complete. See the project snapshot guide for
result identity, known physical limitations, verification and historical path requirements.

The existing vascular-lumen code and test fixtures from `main` remain in place.
