三、固定本次物理目标和单位
==================================================

权威目标从第二阶段已冻结的 physical_case 和 unit_mapping 读取。

已知数值仅作一致性核查：
- 密度：1056 kg/m³；
- 运动黏度：3.27e-6 m²/s；
- 动力黏度：0.00345312 Pa·s；
- 温度：298.15 K，即用户批准的25°C假设；
- 入口总流量和三个出口表压：保留旧测试工况；
- 固定、不渗漏、无滑移壁面；
- 不允许显著时间平均出口回流。

这些边界值是测试值，不是生理实测。
本轮周期小盒不直接施加真实血管的入口出口，
只检查液体是否具备支持那些要求的物性基础。

第一轮空间设计线索：
L0 = 0.5 µm
m_star = 1
n_star = 8
kBT_star = 1
rc_star = 1
M0 = 1.65e-17 kg
t0 约为31.6558 µs

首先读取保存的精确值，不从上述舍入值重新定义单位。

主比较优先保持相同：
- 物理长度尺度；
- 液体质量密度和温度；
- 粒子质量与平均间距；
- 测试区域的物理尺寸；
- 物理黏度目标。

单位必须同时检查：
rho_phys = rho_star * M0 / L0^3
kBT_star * M0 * L0^2 / t0^2 = kB * 298.15
nu_phys = nu_star * L0^2 / t0
mu_phys = mu_star * M0 / (L0 * t0)

不能通过重设时间单位使测得黏度自动命中目标。
不能把 kBT=1 自动解释为任意物理温度。

特别注意：
SDPD 的 viscosity 参数应按本地源码确认其量纲。
若它代表动力黏度，必须传入 mu_star，
不能直接传入目标运动黏度 nu_star。

按第一轮单位，nu_star 约为414，mu_star 约为3312；
程序应使用精确换算值，这两个量不能混用。

如需探索不同空间尺度或粒子数密度：
建立单独候选，保留新的完整单位映射；
明确它不再属于“相同离散设置”的比较。
本轮不开展大范围尺度扫描。

==================================================
五、公平比较：分清“算得快”和“算得对”
==================================================

输出两类比较，不能混成一个排名。

A. 数值执行成本比较

在明确记录的粒子数、区域、精度、采样和输出设置下，
比较单步耗时、密度计算额外开销、显存和初始化成本。

若物性不同：
只称为“这些设置下的执行成本”，
不能称为“同一种目标液体谁更快”。

B. 目标液体适配比较

比较两种模型是否能满足：
- 密度和温度；
- 实测黏度；
- 时间步/驱动敏感性；
- 压力—密度响应；
- 合理密度波动；
- 满足误差要求所需的物理采样时间和计算成本。

只有两边达到相近物理目标和误差要求时，
才允许给出目标问题的时间效率比较。

旧 DPD 基线与高耗散候选均未合格。
它们可以作为历史参考，但不能把低黏度基线的速度
当成合格血流模型的速度，与目标黏度 SDPD直接排名。

不强制两种模型使用相同 dt。
分别采用经检查的稳定时间步，但必须换算到秒。

不要比较相同计算步数后直接宣布谁更快。
必须报告：
实际物理演化时长、有效采样时长、误差及墙钟耗时。

相同粒子间距不自动代表相同空间误差。
本轮只能给出有限尺度下的对照，不声称完成网格收敛。

六、SDPD 候选：黏度直接输入，其他约束仍需检查

优先建立一组目标物性的 SDPD 候选。
必要时最多增加一组有明确理由的修订候选，

注意：
rho_0 是 EOS 中的参考参数，
不是可以不加判断地等同于初始化质量密度。

EOS 设计同时考虑：
- 目标压力差；
- 可接受的密度变化；
- 流动速度与声速比；
- 显式时间积分的稳定性；
- 核密度波动；
- 背景压力可能对离散稳定性的影响。

声速选择必须有依据。
不能盲目采用示例的10，也不能为了声称物理准确就
无依据使用真实水声速并忽略计算代价。

可用 Δp/(rho*c_s²) 估计所需密度变化，
但它只是设计估计，必须用实际密度和压力响应检查。

压力参考：
- 保留旧表压差；
- 不导入旧LBM的rho*cs²数值偏置；
- 不把负表压直接当负热力学绝对压力；
- 不擅自假设大气压；
- 为每个模型明确相同物理参考的映射方式；
- 不通过移动零点改变需要实现的压力差。

仅平移压力零点不能扩大已测压力区间。
背景压力在离散粒子模型中也不能未经检查就视为完全无影响。

SDPD 输入动力黏度后仍需实际测量。
保存“输入黏度”和“实测黏度”两列，
不得用输入值生成虚假的测量点。

普通DPD和SDPD的体积黏度、可压缩性等若未独立匹配，
必须保留限制，不宣称复制了旧模型全部物性。

==================================================
八、测量方法必须可靠，且适用于各自模型
==================================================

黏度：
- 复用经核实的周期流动解析解与拟合代码；
- 明确驱动是每粒子力、加速度还是体力密度；
- 不遗漏粒子质量和数密度；
- 每组都同时输出目标解析剖面和实测剖面；
- 区分“按目标黏度预测的曲线”和“拟合实测黏度的曲线”；
- 分箱平均修正和速度偏置处理一致；
- 报告黏度、拟合残差、95%置信区间和有效样本。

温度：
- 平衡态扣除整体质心运动；
- 流动态扣除有依据的局部平均流速；
- 检查分箱内剪切残留导致的偏高；
- 不为得到25°C而减去任意速度场；
- 不关闭随机力、改变kBT或额外加恒温器凑通过。

压力：
分别核查DPD和SDPD的观测定义，不盲目复用同一公式。

区分：
- EOS给出的模型压力；
- 粒子维里/动量通量得到的机械压力；
- 动能贡献、体积归一化和应力符号；
- 全盒平均与局部平均；
- 质量密度与核数密度。

若SDPD的压力中已有热贡献，
需明确是否会与额外动能项重复计数。
不能把 N/V 代入输入EOS，再将结果称为“独立实测验证”。

用当前库支持的压力/应力输出，
或对少量真实快照采用有依据、可复核的独立估计。
CPU独立估计只用于小样本核查，不代替Mirheo时间推进，
其开销与物理假设单独记录。

原生接口不能提供可靠机械压力时：
标记PRESSURE_OBSERVABILITY_LIMITED，
保留其他有效测试，禁止用解析曲线伪装实测点。

采样：
- 核实各输出的时间标签和采样位置；
- 旧Stats与virial的一步时间差不能不加核对地套用；
- 按实际松弛时间、稳定性和相关时间选择平衡段及统计块；
- 至少区分初始化、平衡、正式统计；
- 不能把高度相关的记录当作大量独立样本。

旧血管短/长物理窗口继续记录：
但它们不是小周期盒材料测量是否充分的唯一判据。
分别报告“局部材料统计是否充分”和“是否覆盖旧血管窗口”。

不把多次独立初始化的短测试拼成一段连续轨迹。
需要续跑时必须验证真实状态和随机过程的恢复关系。

3. 稳定计算阶段耗时；
4. 采样、CPU传输和输出耗时；
5. 实际物理演化时长；
6. 有效统计物理时长；
7. 粒子数、kernel支持范围及精度；
8. 主机内存与设备显存采样。

测量GPU时间时注意异步执行，采用有完成保证的计时边界。
不把提交GPU任务的Python耗时当作GPU完成时间。

两种模型的正式对照使用相近的物理采样间隔、
空间分箱和输出负载。
不能一边频繁复制全部坐标到CPU，另一边关闭输出，
然后把差异称为算法加速。

同时报告：
- 每步耗时；
- 推进单位物理时间的耗时；
- 达到本次误差要求所需的时间，若实际达到。

若一边没有合格结果，“达到合格解的耗时”应为null/尚未达到，
不能用不合格参数的高速结果排名。

小盒只反映小盒性能。
不依据数千粒子的测试直接承诺整段血管或RBC模型加速多少倍。

==================================================
十、验收与结论规则
==================================================

优先沿用上一轮冻结的PROPOSED筛选判据。
保留其“建议初筛”身份，不称为最终用户验收标准。

新增加的判据：
在测试前写入配置，注明依据和适用范围。
不能结果不好就放宽阈值。

每个模型/候选独立给出：
- 接口可运行；
- 单位一致；
- 密度和温度；
- 实测黏度匹配；
- 时间步与驱动力敏感性；
- 压力定义已核实；
- 压力范围/密度响应；
- 稳定性和统计充分性；
- 性能可比性；
- 后续边界和膜耦合缺口。

可能的结论包括：
- SDPD在本次目标下更值得继续；
- DPD在本次目标下更值得继续；
- 两者都可用，但取舍不同；
- SDPD部分指标改善，但尚未合格；
- 两者均未合格；
- 预算或接口不足，尚不能判断。

“改进幅度”和“是否合格”分开。
SDPD比旧DPD更接近目标，也可能仍不合格。

没有合格候选时：
selection=null。
不能自动选择“分数最高的失败者”作为生产默认。

即使纯液体SDPD通过，也不能声称：
- RBC膜耦合已验证；
- 冻结壁面无需重新检查；
- 开放压力边界已解决；
- 微泡或黏附可直接使用。

列出后续兼容性检查：
SDPD近壁密度核截断、冻结壁面处理、
膜内外液体与膜节点的耦合、开放储液区和压力测量。
本轮只做能力盘点，不实现整套后续功能。
