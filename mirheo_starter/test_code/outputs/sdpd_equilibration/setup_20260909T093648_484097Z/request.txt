==================================================
六、稳定性判断：先问“稳不稳”，再问“对不对”
==================================================

这两项必须独立判断。

A. 是否稳定

至少观察：
- 无驱动COM扣除后的温度；
- 机械压力；
- 核密度均值、波动和结构变化；
- 总动量或平均速度是否持续漂移；
- 全盒粒子数、质量是否守恒。

周期盒里N*m/V不变是构造条件，
不能单凭它就证明局部结构已经稳定。

使用预先登记的物理时间窗，
显示完整启动曲线，不隐去9倍左右的温度峰值。

优先沿用已有方案的正式区间[0.30,0.40]。
判断用整个指定区间，不事后移动到最接近目标的那一段。
若该区间不够，报告，不自动向后延长。

可以展示其他固定区间作为诊断，
但不能从多个窗口中挑出最好看的一个作为正式通过结果。

主实验前冻结：
- 最小观察长度；
- 两半窗口或多个固定块的漂移标准；
- 温度、压力和结构稳定性的归一化方法；
- 置信区间与有效样本规则。

已有热平台方案包含：
两半温度均值的相对漂移不超过0.5%。
它属于本轮事前筛选设计，不是普适物理定律。

不能把“斜率检验未显著”直接等同于“已经证明无漂移”；
样本不足也可能导致无法检出漂移。
漂移量、误差和足够采样应一起报告。

压力稳定性不能只用巨大的背景压力作分母，
使明显压力变化看起来相对很小。
使用有明确物理意义的绝对变化尺度或冻结判据，
不把压力稳定与覆盖出口目标混为一谈。

B. 稳定温度是否正确

目标是298.15 K，或同一单位下的kBT_star=1。
百分比按绝对温度/热能计算，不以25作为分母。

沿用当前2%初筛，并计入均值的不确定性，例如：
abs(mean / target - 1) + CI_halfwidth / target <= 0.02

只有在稳定性和采样充分性满足时，
才评价“稳定温度通过初筛”。

程序不得执行任何操作把瞬时温度钉死在目标。
允许真实热涨落。

C. 统计充分性

复用修复后的分块统计：
均值、CI和正式结论使用同一批完整块，
尾部数据保留并单独报告。

有效块数要求沿用至少8块。
块长参考稳定段的相关时间及已冻结的最小时间尺度。

特别注意：
旧过渡段得到的82.44样本相关时间只能作规划参考，
不能当作新稳定段的已知真值。
持续漂移时，自相关估计不作为可靠稳态证据。

先检查结构和时间趋势，再计算稳态统计。
不能为了凑8块人为缩短块长。

报告：
总样本数、平衡段、正式段、块长、块数、
丢弃尾部数量、相关时间估计和CI依据。

==================================================
七、明确分支：结果不同，后续动作不同
==================================================

最终分别判断以下情况：

1. 仍在降温或结构持续变化
   状态：TRANSIENT_PERSISTS
   说明此次观察范围内尚未稳定。
   不给出“稳定后的温度偏差”，不开始黏度拟合。
   根据实际末段趋势估计下一次需要的观察量，但不保证收敛。

2. 看似平稳，但独立统计不够
   状态：STATIONARITY_OR_SAMPLING_INCONCLUSIVE
   说明是缺少证据，不等于已经正确或已经失败。
   给出缺少多少采样的条件估算，不自动追加运行。

3. 稳定且温度明确偏离目标
   状态：STATIONARY_BUT_THERMALLY_BIASED
   此时“只是没等够”的解释不能继续当成唯一原因。
   下一优先项应是稳定状态下的无驱动dt/dt2对照。
   本轮不擅自修改黏度、kBT、声速或添加恒温器。

4. 稳定且温度通过2%初筛，结构与压力统计也稳定
   状态：EQUILIBRIUM_SCREEN_PASS
   表示在本次盒子、参数、时间步和统计范围内，
   已建立可继续验证的无驱动稳定参考。
   不能写成所有物性合格或selection已确定。

5. 温度读数、状态读取或统计代码出现新错误
   状态：MEASUREMENT_OR_ANALYSIS_ERROR
   先增加可复现测试，再最小修复。
   区分“重新分析原始数据即可”与“必须重新运行”。

6. 数值溢出或运行异常
   状态：NUMERICAL_OR_RUNTIME_FAILURE
   保留日志、最后可靠状态和实际用量。
   不自动换参数重试。

即使第4项通过，也不自动启动流动或压力扫描。
本轮仍保留液体生产参数selection=null。
后续需要黏度、压力响应及必要的时间步检查。

如果温度已经明显形成偏高平台，但CI太宽，
用“不确定”，不要硬归为第3项或第4项。
