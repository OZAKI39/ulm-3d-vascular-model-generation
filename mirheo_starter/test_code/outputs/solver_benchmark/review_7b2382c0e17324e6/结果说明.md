# Mirheo / HemoCell 纯流体实测结果

HemoCell 已实际安装、编译并通过零细胞原生烟雾测试。主基准采用链接 HemoCell/Palabos 的
C++ D3Q19 Guo BGK 纯流体路径；不是 Python LBM，也不是包含红细胞成本的全血性能。
HemoCell 固定提交 `5a410848bd5c57d5ae1c171112e78eab4a82e650`，配套 Palabos 固定提交
`05712164d940a42e06afdd705249912fa0c49f14`。二者与派生 C++ 案例为 AGPL-3.0-or-later。
HemoCell 库编译 151.560 s，案例编译及首次 API 修正 36.281 s，均与数值运行成本分开。

实测电脑为 i7-13700HX、WSL2 可见 24 个逻辑 CPU、约 7.62 GiB WSL 内存、
RTX 4060 Laptop GPU（8188 MiB）。LBM 使用 CPU 双精度、1/2/4 MPI rank、OMP_NUM_THREADS=1；
SDPD 使用现有 GPU 单精度构建、1 个计算 rank 加 1 个后处理 rank。
求解器互斥运行，编译不与计时实验重叠，未修改 Mirheo 源码、共享库、兼容补丁、虚拟环境或系统工具链。

## 共同物理条件与实际结果

双方均为 4 µm 周期立方盒，ρ=1056 kg/m³、ν=3.27e-6 m²/s、μ=0.00345312 Pa·s，
下半盒加速度 −50000 m/s²、上半盒 +50000 m/s²，共用 16 个空间分箱。
宏观初始速度为零；SDPD 保留热随机初速度。计划 0–1 µs 无驱动准备、1–3 µs 建立流场、
3–8 µs 正式采样，实际边界按各自时间步取整。背景 298.15 K 是旧数值测试物性，尚非 PDMS 实验测量。

| 当前部署 | 步数 / 实际物理时长 | 完整墙钟（两次独立主基准） | 计算 ms/步 | 完整工作流 s/物理 µs | 剖面相对 L2 |
|---|---|---|---|---|---|
| LBM 16³，1 rank | 2511 / 7.998853 µs | 1.7144–1.7148 s | 0.3517–0.3543 | 0.21433–0.21438 | 1.4356% |
| LBM 16³，2 rank | 2511 / 7.998853 µs | 1.5136–1.5138 s | 0.2360–0.2479 | 0.18922–0.18925 | 1.4356% |
| LBM 16³，4 rank | 2511 / 7.998853 µs | 1.71663–1.71666 s | 0.1649–0.1672 | 0.214609–0.214613 | 1.4356% |
| LBM 32³，1 rank | 10045 / 7.999650 µs | 26.2937–27.1910 s | 2.4600–2.5424 | 3.2869–3.3990 | 0.3589% |
| SDPD 4096 粒子，RTX 4060 | 252719 / 8.000015 µs | 317.7046 s（一次成功重试） | 1.2333 | 39.7130 | 20.1719%（完整块描述均值） |

LBM 的 dt 分别为 3.1855249745 ns 和 0.7963812436 ns，τ=1；SDPD dt 为 0.0316557734 ns。
SDPD 平均粒子间距 0.25 µm、核半径 0.5 µm；这与 LBM 格距相近不代表相同精度。
SDPD 成功任务的同步计算耗时 311.6662 s、采样/传输/归约/输出 4.0999 s、设置约 1.2042 s；
完整墙钟还包含启动、退出及未归类开销。各后端的详细分段、全部重复和低 I/O 辅助运行均在 HTML 中。
这些数字是当前工作流的执行成本，不是双方都得到正确稳态解的耗时。

## 局部通过、未通过与下一步

LBM 16³ / 32³ 的半盒通量误差约 1.5625% / 0.3906%，表观黏度误差约 1.3019% / 0.3287%。
粗细网格剖面差 1.0767%，所有主基准重复通过运行前冻结的 `PROPOSED` 局部平均流场筛选。
资格成本计入从新状态完成主运行及另一档网格验证的墙钟，约 28.0–28.9 s；这是完整固定方案的已发生成本和，
不是搜索到的最短达标时间。标准等温 LBM 的粒子热温度统计为不适用，没有虚构温度误差或零总误差。

SDPD 正式窗口有 790 个规则时间样本。考虑相关性后，剖面块长 616 样本，仅有 1 个完整块，
未达到至少 8 块要求，因而 20.1719% 仅为完整块描述误差，无有效 CI；全窗口描述误差也列出，为 17.8477%。
没有删除任何空间 bin。完整块表观 ν=2.960071e-6 m²/s，偏低 9.4779%；半盒通量误差 15.8653%，
窗口前后半剖面漂移 14.9912%。全局密度守恒；瞬时空间 bin 密度最大波动 6.6406%，保留粒子热涨落口径。
正式窗口温度均值 325.1637 K，相对 298.15 K 偏高约 9.0604%，前后半温度漂移 7.9018%；
温度所需块长超过窗口，0 个完整块，温度 CI 同样为 null。

因此 SDPD 的 `time_to_qualified_solution = null`，全部 `qualified_speedup = null`。
不能用 317.7 s 除以 LBM 墙钟宣称得到合格结果的加速倍数，也不能保证延长同一轨迹就会修复温度或流场。
下一步应先解决 SDPD 温度稳定性和均值流场偏差，再获得足够独立统计块、验证时间步与近壁行为。
本轮不自动追加运行。圆管为 `PIPE_BENCHMARK_DEFERRED`：近壁核截断、冻结壁面密度与滑移仍缺验证。
已有平均流场对照值得保留；公平 RBC 对照尚需匹配细胞尺寸、膜力学、浓度、内外黏度及耦合精度。
本轮没有验收 RBC、真实血管、PDMS 实验液体、真实压力出口或完整物性，0.263 Pa 历史压力门槛未被更改或宣称修复。

## 资源、预算和核查证据

本轮共有 19 次 CPU 数值运行：1 次部署冒烟、8 次主基准、6 次低 I/O 计时、4 次内存补充审计。
CPU 累计 119.365107860 s，低于 1200 s 限额。
GPU 首次启动在导入 Mirheo 前因缺少 mpi4py 失败，0 个流体步，仍计费 2.458043783 s。
改为现有 OpenMPI C ABI 并通过真实双 rank CPU 通信检查后，按用户明确批准只重试一次。
成功重试 317.704629736 s；GPU 合计 320.162673519 s，新增 600 s 额度余 279.837326481 s。
首次失败、两条用户批准、修正记录、固定方案、实际 worker 哈希及账本全部保留。余额不代表可继续扫描或自动第三次重试。

初版主机采样按进程组追踪，实际只捕获 mpirun，未覆盖 OpenMPI 另建进程组的 ranks。
原文件封存不改；分析将其标成 `LAUNCHER_ONLY_RANK_RSS_NOT_MEASURED`，不当作求解器总内存。
修正递归子进程采样后，四次 CPU 补充审计的进程树 RSS 采样峰值为：
16³/1 rank 37.25 MiB、16³/2 rank 61.40 MiB、16³/4 rank 109.49 MiB、32³/1 rank 43.41 MiB。
单个 rank 约 23.9–24.1 MiB，32³ rank 约 30.1 MiB；这是 RSS 采样峰值，重复计入共享页，非 PSS。
四次审计期间 WSL 最低可用内存约 4.446 GiB，各 rank 亲和性和原始样本均保存。
Mirheo 主机 rank RSS 仍为未测；GPU 全设备显存采样峰值 1725 MiB 含桌面/其他程序，不是本任务独占显存。
小盒成本与资源不能直接线性外推到完整稀疏血管。

最终 CPU 回归 129 项通过（含既有正式模块回归；合成测试不替代流场实测）。
Chrome 离线检查通过：6 图、3 行结论、全部成本行、数据回读一致、零外部请求、无 JavaScript 异常及缩放重置。
人工验收始终 `PENDING`。安装脚本重复运行只核查复用；重复 `--execute` 已确认读取缓存、三份预算文件哈希均不变。
保护清单核查 21288 个原有重要文件：21287 个保持相同，仅共享池按明确批准追加一条授权及本轮成员，所有旧账本保持原样。

## 查看与文件

解压结果包后直接用 Windows Edge/Chrome 打开根目录 `benchmark_review.html`，无需 Web 服务或网络。
同目录 `results.json` 是嵌入页面的完整结果，`bundle_manifest.json` 列出包内文件 SHA256。
`browser/` 留存自动检查及截图；`mirheo_starter/` 是本轮新增代码、配置、授权和原始运行；
`hemocell_starter/` 是独立 C++ 案例、安装脚本、环境/构建/保护证据，含 AGPL 许可文本。

结果包不含二进制、虚拟环境或全部旧结果；重新计算依赖现有项目正式模块和固定安装，离线 HTML 本身独立可看。
