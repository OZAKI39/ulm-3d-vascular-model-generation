# 全通道候选与群体运动

复用冻结 F10X OpenCV 检测：高斯背景 sigma=4，暗信号 ≥10，连通域面积 8–450 px²，长短边比 ≤2.8，边界检查。候选没有长期单泡 ID；面积衍生质量分数只是启发式，不是标定置信概率。低对比、重叠和失焦漏检仍是限制。

正式录像使用 SHA 绑定的 1476×1120 几何：完整通道 polygon，左壁低可见区排除，中央条纹保留。每个进入分析的帧都扫描有效通道。所有 PIV 窗口计算与有效窗口、候选检测分别计数。局部密度按观测遮罩有效面积，而非整张矩形面积归一化。

PIV 复用 CuPy B4，48/24 窗，原 peak2peak 1.2、局部中值 2.5、纹理 ≥2，无替换向量冒充有效。因果 EMA 背景 .08；最多保留 4 帧，取最近历史中不超过 250 ms 的最远合法间隔。丢帧后用真实 dt，不硬设固定帧间隔。

Rust B2 为本机参考/备用。CuPy 的 FFT padding 与 Rust 不是相同离散算子，本轮不声称二者逐向量等价。F10X 已审计的 upstream int32 mask 修正继续使用，没有重写内核。

输出固定图像区域的平均速度、方向一致性、径向相对速度和二维散度，单位 px/s 与 s⁻¹。所有窗口仍受信号和注册门控；不足支持为 null。没有对“每个泡泡”构造虚构六参数。原六参数数学保留只读依赖；新 M4 中 six_parameters=null，避免把 Eulerian 区域冒充有身份泡团。
