# PZT 状态与俯视布局

## 第一次使用

1. Windows 打开 `F:\Tektronix_control\start_gui.cmd`，点击 **Connect Devices (Read Only)**。只保留一个 AFG 控制器窗口。此操作读取设备，不修改输出。
2. 启动原来的观测界面：

   ```bash
   bash /home/lzy/projects/external_connect/vision_tracking_research/realtime_collective_observation_v1/start_live.sh
   ```

3. 右侧选择 **PZT status / layout**。四路状态会自动更新；首次完整读取约需 4–5 秒。相机的 **Start / Stop** 与 PZT 输出独立，开始录像不会开启 PZT。
4. 点击 **Edit layout**，根据实际接线填写位置。默认没有任何已登记位置，不使用仿真的位置替代真实装置。

## 填写俯视布局

| 栏目 | 填写方法 |
|---|---|
| PZT | 固定通道标识，先沿实际电缆确认对应哪一枚 |
| Position set | 已确认位置才勾选；取消勾选可从图中移除 |
| X / Y (mm) | PZT 中心位置，使用你选定的同一个原点，单位毫米 |
| Normal (°) | 发声面朝向：0° 向右（+X），90° 向上（+Y），180° 向左，270° 向下 |
| Diameter (mm) | 实际直径；输入框初值 7 mm，保存前按实物确认 |
| Wiring check | 人工检查后的接线状态；初值 Not checked |

点击 **Save** 后立即更新，重新启动仍保留。**Cancel** 放弃此次修改。布局保存于 `configs/pzt_layout.json`，有格式和有限数值检查。

俯视方向为从 +Z 看向 XY，+X 向右、+Y 向上，XY 使用相同缩放。银灰短条示意竖放圆片的顶部投影，箭头是用户输入的发声法向，旁边标记通道和输出状态。位置是实验台坐标，尚未与相机图像配准；箭头不是声力计算结果。发生器通道映射来自其 `config.json`：

| PZT | 发生器 | USB 序列号 | 输出 |
|---|---|---|---|
| PZT1 | A | 2147075 | CH1 |
| PZT2 | A | 2147075 | CH2 |
| PZT3 | B | 2439003 | CH1 |
| PZT4 | B | 2439003 | CH2 |

## 读取状态与启动后参数

- **AFG connected**：对应通道最近成功读回。**ON / OFF**：实际查询的发生器输出开关，不是用户尚未提交的输入框。
- 参数显示实际频率（MHz）、幅值（Vpp）、相位（度）、波形和模式。SIN 是正弦波、SQU 是方波、CW 是固定频率；Sweep / Burst 的详细参数及负载设定可将鼠标停在卡片上查看。
- 相位沿用现有驱动的弧度到度转换，不将两台发生器的读回相位当作经过测量的跨设备相位同步。
- **Last read** 显示读取距今多久。每秒安排一路只读查询，四路轮询；用户控制操作优先，繁忙时暂缓后台读取。它不是毫秒级启动时刻测量。
- 连续超过 8 秒没有新读数时显示 **Readback expired / UNKNOWN**，旧参数不再作为当前值展示。控制器关闭、状态文件不可用、查询失败也会明确显示；一台设备读失败会使该设备两路失效，另一台可继续更新。
- **Wire** 来自你的人工确认。AFG 的 USB 接通和输出 ON 不能证明放大器或 PZT 电缆接通，也不能证明实际发出了超声。软件没有这类负载传感器读数。
- **Vpp 是发生器输出读回值，不是声压 Pa**。未做电声标定，因此不换算声压或实际 PZT 推力。

## 日常操作

在原 Windows AFG 窗口按既有流程配置并启动输出后，观测界面自动更新相应读回参数。仅在 AFG 输入框中打字、尚未 Apply 的内容不会被显示成实际参数。读回 OFF 时仍可以显示已配置频率和幅值，但不会标成正在输出。

**AFG controller folder** 打开控制器文件夹，双击 `start_gui.cmd` 即可。不要同时打开多个控制程序。布局可以先填写，不要求相机或发生器在线。

实时观测程序只消费 `F:\Tektronix_control\observation_status.json`；不另外打开 VISA 会话，不发送 ON、OFF、触发或参数写入命令。现有视频仍保存相机画面与识别叠加，PZT 侧栏是监视界面，不属于实验视频图像。

## 实现与验证

- Windows 与 WSL 的 `Tektronix_control/afg_gui.py` 同步增加了 `afg_telemetry.py`。后台读取复用原单线程 USB 工作队列；原 `afg_control.py` 保持原样。关闭控制器时仍使用其原有退出行为。
- 只读参数与输出开关分别计时：单独 OFF 回执不会将旧频率和相位刷新成新测量。状态文件原子替换；WSL 在后台线程读取挂载盘，避免拖慢画面。
- `src/pzt_status.py` 处理新鲜度和布局持久化；`src/pzt_panel.py` 实现英文状态卡、俯视图及对齐的编辑表格。
- `evidence/pzt_monitor_20261019/` 保存修改前备份、测试、实际设备查询、代码哈希和视觉检查。截图中的四向测试布局只供 UI 检查，不写入用户正式布局。
- 2026-10-19 真实设备只读 GUI 联调完成，四通道全部读回成功；测试前后设置一致、全部输出 OFF，新增遥测发送的全部 SCPI 都为查询命令。真实 ON 过程未在此次开发中主动执行；ON 状态、断连、参数过期和关闭路径通过离线测试覆盖。
