# 5. 统一六参数几何接口

所有候选方法的运动结果必须使用相同参数定义。

\[
\mathbf v(\mathbf x)=\mathbf v_0+A(\mathbf x-\mathbf x_c)
\]

六参数：

`translation_vx, translation_vy, divergence, vorticity, shear1, shear2`

其中：

- `divergence = A11 + A22`
- `vorticity = A21 - A12`
- `shear1 = (A11 - A22)/2`
- `shear2 = (A12 + A21)/2`

图像 x 向右，y 向下。

平移单位 px/s。

其余四项单位 1/s。

参考位置采用固定 ROI 几何中心，而非当前候选点群平均位置。

对有限仿射变换使用 F10U 已验证的齐次矩阵对数转换，得到区间等效六参数。

优先复用：

`collective_motion_v1/src/affine.py`

不能把点云协方差变化直接当成完整六参数。

对于非仿射、信息不足、时间断裂或错误匹配情况，输出有效性和原因，不可观测参数用 null，而不是零。

新方法必须兼容 F10V 已建立的 M4 版本化状态规则，不破坏原始 F10U 1.0 接口。

# 6. 研究顺序：先零样本，再决定是否自监督适配

## 6.1 零样本研究

第一轮严禁先重新训练模型。

使用官方已有权重进行推理。

测试数据包括：

- F10U 现有已知运动合成基准；
- F10V 已保存的历史失败案例，仅用于诊断，不再冒充新的独立最终测试；
- 新开发素材中的已知解析运动；
- 真实 Chronos 录像；
- 固定背景、失焦、漏检和非仿射案例。

比较：

- 预测是否随真实运动方向变化；
- 运动幅值是否正确；
- 是否再次产生接近零的预测塌缩；
- 各六参数的误差；
- 错误接受与拒判；
- 可用覆盖率；
- 处理延迟与显存。

若新模型仍完全无法恢复基本运动，不要立刻扩大训练规模。

## 6.2 自监督适配的准入

只有某个已有模型在零样本实验中显示出合理的运动敏感性，才进入真实视频自监督适配。

优先复用官方已有自监督机制。

不从零创建大型光流网络。

可研究：

- 图像变形／重建误差；
- 正反向流一致性；
- 遮挡处理；
- 多帧时序一致性；
- 高质量伪标签；
- 仅针对运动候选区域的可信权重。

特别注意：

**原始显微图像含有大量固定 PDMS 背景。**

如果对全图使用普通重建损失，零运动可能获得较低损失，从而再次出现预测塌缩。

必须检查移动微泡区域和固定背景区域各自的损失与运动估计表现。

不能仅凭自监督 loss 下降宣布成功。

如果全部零样本模型都无法获得有用的运动证据，应先报告失败与主要原因，不要无依据进行长时间 GPU 训练。
