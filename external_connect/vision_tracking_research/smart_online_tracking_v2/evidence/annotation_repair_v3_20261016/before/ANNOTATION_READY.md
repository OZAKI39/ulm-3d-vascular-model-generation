# 微泡标注工作台：操作说明（2026-10-16 修复版）

**先用“逐张标注”页的手工轮廓完成第一张，再尝试可选的 SAM。** 默认启动不会加载大模型；不需要相机在线，也不需要等待 GPU。原有两张草稿完整保留。当前提供 **84 张候选图片**：72 张录像帧和 12 张单独隔离的实时候选。

修复后的工作台采用 **napari 原生 Labels 工具**，在同一个窗口内换帧。SAM 只在点击“生成 / 更新候选”时启动后台进程，可取消；超过 90 秒自动停止该任务。它使用原版 SAM ViT-B，不使用 SAM 2。

## 1. 启动与恢复上次进度

在 **WSL 终端**复制整行执行：

```bash
bash /home/lzy/projects/external_connect/vision_tracking_research/smart_online_tracking_v2/start_annotation.sh
```

保留这个终端，不要在标注过程中关闭它。窗口标题为“微泡人工标注”。右侧是中文操作步骤，中间是原图，左侧是 napari 图层列表。启动后会恢复上次停留的图片、已保存草稿和审核人名字。

如果只想手工标注，明确禁用 SAM：

```bash
bash /home/lzy/projects/external_connect/vision_tracking_research/smart_online_tracking_v2/start_annotation.sh --manual-only
```

从第 1 张打开：末尾添加 `--index 0`；从第 11 张打开：添加 `--index 10`。进入窗口后也可以在右下“图片序号”输入 **从 1 开始**的编号，点“跳转”。同一时刻只允许一个正式工作台，避免两个窗口相互覆盖标签。不要使用 `--smoke` / `--smoke-sam` 开展正式标注，这些参数只写入软件测试区。

## 2. 第一次操作：先完成一个对象并保存

这一段只用右侧 **“逐张标注”** 页，不需要在多个 SAM 图层之间切换。

1. **先看清对象。** 在图上滚动滚轮缩放；按住空格并拖动来平移。看不到整幅图时点“查看整幅图”。没有光学标定，所有标注仍使用原始像素坐标。
2. 在 **“① 对象类别”** 选择“单泡 | SINGLE_BUBBLE”。只有你确实能判断它是一个可见单泡时才用此类；看不清选“不确定”。
3. 点 **“② 新建轮廓”**。程序会自动选中对应图层、分配新实例编号并进入多边形描画模式。不需要自己去左侧寻找图层。
4. 在对象可见边界上依次单击。通常沿边界放 8–20 个点即可；小目标可更少，复杂边界可更多。**至少需要 3 点。** 不用一直按住鼠标，不需要绕着对象拖画。
5. 点 **“③ 完成轮廓”**。所围区域出现半透明颜色，表示这个对象已经写入当前类别。仅有折线而没有填充，表示还没有完成；这种轮廓不能保存或带到下一帧。
6. 选另一个对象时，**再次点“② 新建轮廓”**，再重复描边和完成。这样每个对象都有独立编号，不会把多个泡当成同一个实例。
7. 点 **“④ 保存草稿”**。右上状态会显示“草稿已保存（尚未确认）”以及各类实例数。草稿不等于完整人工审核。

**第一轮先做到这里即可验证工作台是否顺手。** 不需要第一次就把整幅密集画面全部完成。可以关闭窗口，重新运行启动命令，确认刚才的轮廓能恢复，再继续标注。

## 3. 画错、改边界与删除对象

| 遇到的情况 | 怎么操作 |
|---|---|
| 多边形还没画完，点错了 | 点“取消未完成轮廓”，再点“新建轮廓”重画。未完成时不要直接换帧。 |
| 刚完成的手工轮廓或笔画不对 | 点“撤销本次笔画”。也可以选中相应 Labels 图层后按 Ctrl+Z；撤销仅针对本帧该图层的编辑记录。 |
| 边界需要补一点或擦一点 | 修改**刚画的对象**可直接点“画笔修边”或“橡皮擦”；左侧 `brush size` 调整笔刷大小。要修改旧对象，先按下一行选中它的编号。 |
| 需要修改以前的对象 | 在“实例 / 短轨迹”页填“要修改的实例编号”，确保“逐张标注”页类别正确，点“选中此编号进行修改”，再回主页面用画笔 / 橡皮擦。 |
| 一个对象全部标错了 | 在“实例 / 短轨迹”页选中它的编号，点“删除选中实例（可撤销）”。 |
| 类别选错了 | 在原类别删除该实例，再到正确类别重新描画；不要在两类中保留同一区域。 |
| 只想移动图像，不想继续画 | 点“移动 / 缩放”；要开始下一对象时再点“新建轮廓”。 |
| 颜色遮住了图像细节 | 左侧选中相应图层，降低 `opacity`；或点击图层前的眼睛暂时隐藏。隐藏不等于删除。 |

每个类别保存独立实例编号；编号相同但类别不同不表示同一对象。默认保护已存在的标签，同类实例不会被新笔画直接覆盖。**不同类别之间不允许像素重叠**；确认时会检查冲突。二维投影重叠难以区分时，用 `UNCERTAIN` 标记该不确定区域，不强行画出多个重叠“真值”。

## 4. 五个类别怎么选

| 类别 | 何时使用 | 不应这样用 |
|---|---|---|
| 单泡 `SINGLE_BUBBLE` | 你能根据实验观察确认的单个可见微泡，边界足够清楚 | 不能因为一个暗点像圆形就全部当成泡 |
| 微泡团 `AGGREGATE` | 可确认由多个泡形成的可见团，标其二维可见外轮廓 | 不把任何大暗块、PDMS 纹理、投影重叠直接当成团 |
| 背景 / 杂质 `BACKGROUND_ARTIFACT` | 可判断的通道纹理、污点、固定结构或非微泡杂质 | 不能用“静止”作为唯一依据，因为泡也可能暂时不动 |
| 不确定 `UNCERTAIN` | 无法判断身份、两个对象投影难以区分、边界判断不可靠 | 不为了凑数量强行改成单泡或团 |
| 失焦 `OUT_OF_FOCUS` | 明显模糊、焦平面不合适且边界不可靠 | 不把模糊光晕硬画成精确泡边界 |

只描当前图中**可见且能判断的投影边界**。二维靠近、重叠或消失不是三维接触、吸收或融合的证据。细则见 [MICROBUBBLE_ANNOTATION_PROTOCOL.md](MICROBUBBLE_ANNOTATION_PROTOCOL.md)。

## 5. 草稿、正式确认和换到下一张

- **随时保存草稿：** 点“④ 保存草稿”或 `Ctrl+S`。有修改时每 30 秒自动保存；换帧和正常关闭窗口也会保存修改。每次保存都产生新的修订，不覆盖旧修订。
- **正式确认一张：** 检查整幅图，包括边缘、背景、漏标、错误类别和重复实例。填写“审核人”，勾选“我已检查整幅图，包括漏标和背景”，再点“⑤ 确认本帧人工审核完成”。只有成功显示“人工审核完成”才计入专家确认帧。
- **还没检查完整：** 保留草稿即可。不要为了进入下一张而勾选完整审核。只标一个泡不代表这一整帧可以当作完整检测真值。
- **换帧：** 点“⑥ 保存并下一张”。窗口保持打开，只替换图片；上一张内容会保留。也可用 `Alt+→` / `Alt+←`。普通方向键不会换帧。
- **跳转：** 右下图片序号从 1 开始，输入后点“跳转”。跳过未标帧不会自动确认它。
- **空画面：** 确实完整检查后，没有目标的帧也可以确认，它是有价值的背景参考。
- **已确认帧又修改：** 修改后的保存会恢复为草稿，需要再次完整确认。没有改动时点保存或换帧，不会取消原确认。
- **关闭前：** 最稳妥的顺序是完成 / 取消正在画的轮廓 → 保存草稿 → 点窗口右上角关闭。强制关闭 WSL 或断电可能丢失最后一次自动保存以后的修改。

如果提示“未保存”，**不要关掉终端**，按右上状态修正。常见原因是轮廓未完成、类别区域冲突，或者正式确认时没有填写审核人。

## 6. SAM 辅助：可选，不是必做步骤

只有手工流程已经顺手、确实希望加速描边时再使用右侧 **“SAM 辅助”** 页。

1. 先在“逐张标注”页选好对象类别。
2. 切到“SAM 辅助”，点 **“1. 放正点（对象内部）”**，再在目标内部单击；绿色点是正点。
3. 如果需要排除邻近纹理，点 **“2. 放负点”**，在不希望包含的区域单击；红色点是负点。
4. 点 **“3. 生成 / 更新候选”**。后台加载原版 SAM 并计算，界面仍可缩放、保存。修复验收时单个任务约 8–13 秒，实际取决于缓存和负载；状态会显示当前阶段。
5. 检查候选掩码。**原版 SAM 不懂“微泡”这一类别，可能选中整片通道或背景。这样的结果不要接受。** 可增加负点后重算，或点“清空候选和所有点”，改用手工轮廓。
6. 边界与类别都正确时，点 **“4. 接受候选到当前类别”**。它成为待审核草稿，正负点会自动清空。返回主页面保存。
7. 算得太久或不需要了：点“取消计算”。超过 90 秒也会自动取消，不改动已保存标签。换帧会取消旧任务，旧图结果不会写进新图。

SAM 候选未接受前不会进入标签文件。接受也不等于专家确认。与已有对象冲突的候选会被拒绝，不会静默覆盖。SAM 接受动作不保证进入 napari 手工笔画撤销栈；如接受错了，请按第 3 节删除对应实例。

### 6.1 跟着做：用 SAM 标出一个清晰的单泡

1. 放大画面，找到一个边界能看清的泡。在“逐张标注”里选“单泡 | SINGLE_BUBBLE”。**走 SAM 流程不需要先点“新建轮廓”**；该按钮用于手工多边形。若已有未完成的手工轮廓，先完成或取消。
2. 切到“SAM 辅助”，点“1. 放正点（对象内部）”，在这个泡的内部单击一次。选择能确认属于目标内部的位置，不要点在外围模糊光晕或邻泡上。出现一个绿色点即可开始尝试。
3. 点“3. 生成 / 更新候选”，等状态变成“候选已显示”。图中半透明区域就是模型提议的范围；正点本身不是泡边界，也不是最终标签。
4. 检查范围：只覆盖目标且边界合理，就点“4. 接受候选到当前类别”。接受后会分配新的实例编号，清空本次正负点和候选；留下的有色区域是标签。
5. 回“逐张标注”，点“④ 保存草稿”。继续下一个泡时，回 SAM 页重新放正点即可。**不要把多个独立泡泡的正点一次性全点完**，否则可能得到把多个泡合在一起的单个实例。

### 6.2 候选不对时，按现象修正

| 候选现象 | 具体操作 |
|---|---|
| 只选中了目标的一部分 | 点“放正点”，在**同一个目标漏选的内部区域**补一个绿色点，再点“生成 / 更新候选”。 |
| 把邻泡或背景也圈进来了 | 点“放负点”，在被误选的邻泡 / 背景内部放红点，再点“生成 / 更新候选”；不要把负点放在想保留的泡内部。 |
| 正点点错了，或者想换另一个对象 | 先等计算完成，或点“取消计算”，再点“清空候选和所有点”，重新开始。取消计算不会自动删除提示点。 |
| 仍然选中了整片通道，几次修正都没有改善 | 不接受；清空候选和点，回“逐张标注”用“新建轮廓 → 完成轮廓”手工标注。 |
| 半透明颜色挡住了边界 | 在左侧选中“SAM 候选（未接受）”，调低 `opacity` 或临时隐藏；随后重新点“放正点 / 放负点”即可继续放点。 |
| 接受时提示与已有实例重叠 | 先检查是否重复标了同一个泡。已有对象应到“实例 / 短轨迹”中选中原编号修改；新对象则用负点排除误选区域。程序不会覆盖已有对象。 |
| 接受后发现错了 | 按第 3 节选中该类别和实例编号，删除或修边，再保存草稿。不要依赖 Ctrl+Z 撤销 SAM 接受动作。 |

正点和负点可以各有多个，但都应服务于**当前一个对象**。每次增减点后，都需要再点“生成 / 更新候选”才会重算。完成所有对象、检查完整幅图之后，才填写审核人并点击“确认本帧人工审核完成”；不要每接受一个 SAM 轮廓就确认整帧。

## 7. 连续 8 帧的短轨迹（可晚些做）

录像候选中有三段连续帧：120–127、450–457、780–787。仅给确实能对应的少量对象设置短轨迹 ID，不要求每颗泡跨长时间保持身份。

在“实例 / 短轨迹”页：选正确类别和当前帧实例编号 → 填 `A`、`B` 等短轨迹 ID → 点“保存短轨迹 ID 到本帧” → 保存 / 确认本帧。同一片段中同一对象的 ID 应保持一致。不同帧实例编号可以不同。看不清、失焦或遮挡时留空，不凭运动方向猜身份。

## 8. 常见故障

| 现象 | 处理 |
|---|---|
| 启动后短时没有窗口 | 查看终端；首次导入图形库可能稍慢。新版主窗口不会等待 SAM 权重加载。不要连续启动多个窗口。 |
| 提示工作台已在运行 | 回到已有窗口；需要重启时先正常关闭旧窗口。异常退出后重新启动会检查进程锁，不要直接删标签。 |
| 点图没有画轮廓 | 先点“② 新建轮廓”；不要停留在“移动 / 缩放”或 SAM 点模式。 |
| 只有边界线，没有填充 | 至少点击 3 个顶点，再点“③ 完成轮廓”。 |
| 点击下一张没有变化 | 看右上提示；通常是未完成轮廓或保存错误。先完成 / 取消轮廓再换帧。 |
| SAM 输出一大片背景 | 模型不适合该对象或提示不足；不要接受，改用手工描画。 |
| SAM 无响应 | 点“取消计算”；继续手工标注。可下次用 `--manual-only` 启动。 |
| 中文显示方框 | 本次已配置 Windows 微软雅黑字体；若换电脑需安装中文字体。 |
| 仍出现卡顿 / 异常 | 保留 `logs/annotation_日期_进程号.log`；SAM 详情位于 `results/annotation_jobs/任务号/worker.log`。说明停在哪个按钮即可，无需重做已保存标签。 |

## 9. 文件、数据划分与完成后的通知

正式标签：

`/home/lzy/projects/external_connect/vision_tracking_research/smart_online_tracking_v2/data/annotations/<图片ID>/`

每次保存包含 `.npz` 五类实例掩码、`.json` 修订信息和指向最新版本的 `latest.json`。文件记录原图 SHA、审核状态、审核人、类别、短轨迹 ID，坐标和图像原始分辨率一致。恢复进度文件为 `data/annotations/session.json`。

候选分组已预登记：录像训练 / 验证 / 测试各 24 张，时间区间之间留空；12 张直播画面在 `QUARANTINE_UNASSIGNED`，不会自动混进训练或测试。只有一条原始录像时，不代表已验证跨实验泛化。

**完成一批后，请在聊天中说明“完成了哪些图片 / 大约几张，已点击人工审核确认，可以继续核查”。** 程序会核对真实文件与确认状态后再冻结评价；未确认草稿、自动 SAM 候选和软件测试标记不作为专家真值。未完成前持续保留 `EXPERT_GROUND_TRUTH_PENDING`，不生成虚构准确率。
