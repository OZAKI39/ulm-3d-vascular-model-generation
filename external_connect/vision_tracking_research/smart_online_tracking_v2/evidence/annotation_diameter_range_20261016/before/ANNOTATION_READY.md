# 微泡标注工作台：操作说明（2026-10-16 局部批量标注版）

**现在推荐：框选一小块 → 一次生成多泡候选 → 删错、补漏 → 只确认这一小块。** 不必为了完成一张密集图而把整幅图全部标完。默认仍是画笔；`N` 新增单泡，`P` 画笔，`E` 橡皮擦。已保存的旧标签和历史修订保留。

## 0. 先按这个流程做一小块

首次使用先在一张训练图片里试一块，熟悉后再做更多区域。所有按钮在右侧“逐张标注”页；左右两列按钮等宽对齐，页面较矮时可向下滚动。

1. **选择审核范围。** 保持“只审核当前小区域（推荐）”。点 **① 框选小区域**，在原图拖一个矩形，建议约 **128–256 原图像素**宽；不要一上来圈满整条通道。点 **放大当前区域**，青色框就是本次需要检查的范围。青框与 SAM 页的黄色提示框用途不同。
2. **批量生成。** 默认模型是 **Cellpose cyto3（当前图像优先）**，典型单泡直径起点为 **16 px**。点 **② 批量生成候选**，不需要逐泡放点。首次加载需几秒，后续同模型请求复用进程。出现彩色对象后，它们仍在独立的“批量候选（未审核）”图层里。
3. **先删明显错误。** 点 **点删错误候选**，连续单击不应保留的彩色对象，每次删除一整个候选。删错点 **撤销候选删除**。这一步还没有写入正式标签；想放弃整批就点 **清空未纳入候选**。
4. **纳入可修改草稿。** 点 **③ 纳入草稿**。候选各自获得独立单泡编号；与已有任一类别标签重叠的候选会整只跳过，不会裁小或覆盖手工内容。该批可用 **撤销标签编辑** 一次撤销，或“重做”恢复。**纳入草稿不等于人工确认。**
5. **补漏、修边、拆分。** 漏掉的泡：按 `N` 后用画笔涂满，每画另一个泡再按 `N`。误标：点 **点选已有对象** → 点击标签 → **删除选中对象**。边界不准：选中后按 `P` 补画、`E` 擦除，不按 N。两个泡被合成一个：选中该对象 → **两点拆分粘连对象** → 在两个泡内部各点一次 → **完成拆分**；检查分界，不对就撤销。
6. **把框内真正检查完整。** 包括无彩色标记的小泡、框边缘的部分对象、模糊结构及背景。过大或碰到框边界的候选会被排除，但这些位置仍需要人看；不能把“模型没检出”理解为没有泡。无法判断的区域用 `UNCERTAIN` 或 `OUT_OF_FOCUS` 标出。只标可见投影，不猜遮挡泡。
7. **确认这一块。** 填写审核人，勾选“我已检查框内全部对象、漏标和背景”，点 **⑤ 确认当前区域**。状态显示区域审核完成；**框外未标部分不会当作背景训练**。还没检查完就只点 **④ 保存草稿**，不要勾选审核。
8. **继续一块或换图。** 可重新框另一小块并重复；上一块有效审核记录会保留。也可直接“保存并下一张”。在 **更多 / 训练 → 本帧已确认区域 → 返回所选审核区域** 可以回看以前确认的区域。

![批量候选界面：彩色区域尚未人工审核](evidence/annotation_batch_roi_20261016/gui_1792166027885817810/bulk_candidates.png)

**典型单泡直径如何选？** 它是原图像素大小的操作参数，不是物理标定。默认 16；较小的泡可试 8–12。调整尺寸或模型会清除未纳入候选，需要重新生成，已纳入标签不受影响。不要为了让大片背景通过而无限增大尺寸。边长 32–768 px 的区域可以批量计算；手工画笔不依赖模型。

**为什么默认没有选最新 SAM 模型？** 本轮在同样三个预先选定的训练区域比较了 cyto3、Cellpose-SAM v2 和 µSAM 显微镜模型。后两者几乎没有候选；cyto3 在两个区域分别产生 24、17 个候选，但也有漏检及模糊对象误选。因而暂用 cyto3 作为可修改起点，其他模型保留为对照。候选数量不是准确率，也尚未实测你的标注时间节省比例。详细对照见 [开发记录](evidence/annotation_batch_roi_20261016/REPORT.md)。

**两个模型入口不要混淆。** “批量生成候选”调用 Cellpose / µSAM 预训练模型；“SAM 辅助”仍是每泡提示分割。默认后台自动微调更新的是原版 SAM 的单泡掩码解码器，**本版不自动微调 cyto3 或 Cellpose-SAM 批量模型**。自动微调和状态位于 **更多 / 训练**，仍默认开启，且必须通过独立验证才替换模型。

## 2. 画笔标注：画一个泡，按 N，再画下一个

这一段只用右侧 **“逐张标注”** 页，不需要在多个 SAM 图层之间切换。

1. **先看清对象。** 在图上滚动滚轮缩放；按住空格并拖动来平移。看不到整幅图时到“更多 / 训练”点“查看整幅图”。没有光学标定，所有标注仍使用原始像素坐标。
2. 在 **“对象类别”** 选择“单泡 | SINGLE_BUBBLE”。只有你确实能判断它是一个可见单泡时才用此类；看不清选“不确定”。
3. **打开后已经是画笔模式，可直接画第一个泡。** 也可点 **“新增 / 下一个单泡（N）”**，程序会自动选中单泡图层并准备独立编号。不需要自己去左侧寻找图层。
4. **按住鼠标左键，把这个泡的可见区域涂满，然后松开。** 默认笔刷直径为 5 个原图像素；左侧 `brush size` 可以调整大小，或在图像区按 `[` 缩小、`]` 放大。不要只画一圈空心边缘，也不要把背景光晕涂进去；不确定的边界不强行当作准确真值。
5. 同一个泡可以分几笔补全，**这些笔画保持同一个编号**，无需点击“完成轮廓”。画多了按 `E` 使用橡皮擦，按 `P` 回到画笔，或 `Ctrl+Z` 撤销上一笔。
6. **开始另一个泡之前，松开鼠标，按一次 `N`。** 状态会显示新编号，继续涂下一个泡。忘记按 N，会把两个泡记为同一个实例；请撤销后重新分开画。没有画任何像素时重复按 N，不产生空对象。
7. 点 **“④ 保存草稿”**。右上状态会显示“草稿已保存（尚未确认）”以及各类实例数。草稿不等于完整人工审核。

**快捷键在图像区获得焦点时使用**：点击“新增单泡”或“画笔”按钮会自动把焦点送回图像区。在审核人或备注输入框中打字不会新增单泡；使用中文输入法时，切到英文输入再按字母快捷键。画笔模式下，点击图像就会落笔，临时平移请按住空格。

| 快捷键 | 作用 |
|---|---|
| `N` | 切到单泡类别，准备下一个独立编号，进入画笔模式；也可从 SAM 页返回手工单泡标注。 |
| `P` / `E` | 在标注图层中切换画笔 / 橡皮擦，不新增编号。 |
| `[` / `]` | 缩小 / 放大笔刷。 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做当前类别的笔画或编辑。 |
| `Ctrl+S` | 保存草稿。 |
| `Alt+→` / `Alt+←` | 保存修改并切换到下一张 / 上一张。 |

标微泡团、背景或不确定区域时，先选相应类别；开始第二个同类对象到“更多 / 训练”用 **“新增当前类别（画笔）”**。`N` 始终表示**新增单泡**，不会将已画好的其他类别改成单泡。

**多边形仍然可选：** 到“更多 / 训练”点“可选：新建轮廓”，沿边界单击至少 3 点，再点“完成轮廓”。未完成时按 N 不会丢掉顶点，会提示先完成或取消。

第一轮可以先画几个泡并保存，重开窗口确认恢复正常，再继续。无需第一次就完成整幅密集画面。

## 3. 画错、改边界与删除对象

| 遇到的情况 | 怎么操作 |
|---|---|
| 多边形还没画完，点错了 | 点“取消未完成轮廓”，再到“更多 / 训练”点“可选：新建轮廓”重画，或按 N 改用画笔。 |
| 手工笔画、SAM 接受或删除操作不对 | 点“撤销标签编辑”或 Ctrl+Z；“重做”或 Ctrl+Shift+Z 可以重做。撤销针对本帧当前类别。 |
| 边界需要补一点或擦一点 | 修改**刚画的对象**用 P 画笔 / E 橡皮擦，保持原编号，不按 N；左侧 `brush size` 调整笔刷大小。要修改旧对象，先按下一行选中它的编号。 |
| 需要修改以前的对象 | 点“点选已有对象”，在彩色标签内部单击，程序选中类别和编号；再用画笔 / 橡皮擦修边。也可在“更多 / 训练”手动输入编号。 |
| 一个对象全部标错了 | 点选对象后点“删除选中对象”；刚接受的 SAM 对象也可直接点“删除上次接受的一批 / 对象”。删除可以撤销。 |
| 类别选错了 | 在原类别删除该实例，再到正确类别重新描画；不要在两类中保留同一区域。 |
| 只想移动图像，不想继续画 | 按住空格拖动，或点“移动 / 缩放”；P 继续当前泡，N 开始下一个泡。 |
| 不小心删除或隐藏了类别图层 | 新版自动恢复必需图层；也可点“恢复 / 显示图层”。已有像素和撤销记录保留。 |
| 颜色遮住了图像细节 | 左侧选中相应图层，降低 `opacity`；或点击图层前的眼睛暂时隐藏。隐藏不等于删除。 |

每个类别保存独立实例编号；编号相同但类别不同不表示同一对象。默认保护已存在的标签，同类实例不会被新笔画直接覆盖。**不同类别之间不允许像素重叠**；确认时会检查冲突。二维投影重叠难以区分时，用 `UNCERTAIN` 标记该不确定区域，不强行画出多个重叠“真值”。

## 4. 五个类别怎么选

| 类别 | 何时使用 | 不应这样用 |
|---|---|---|
| 单泡 `SINGLE_BUBBLE` | 你能根据实验观察确认的单个可见微泡，边界足够清楚 | 不能因为一个暗点像圆形就全部当成泡 |
| 微泡团 `AGGREGATE` | 可确认由多个泡形成的可见团，标其二维可见外轮廓 | 不把任何大暗块、PDMS 纹理、投影重叠直接当成团 |
| 背景 / 杂质 `BACKGROUND_ARTIFACT` | 可判断的通道纹理、污点、固定结构或非微泡杂质 | 不能用“静止”作为唯一依据，因为泡也可能暂时不动 |
| 不确定 `UNCERTAIN` | 无法判断身份、两个对象投影难以区分、边界判断不可靠 | 不为了凑数量强行改成单泡或团 |
| 失焦 `OUT_OF_FOCUS` | 明显模糊、焦平面不合适且边界不可靠 | 不把模糊光晕硬画成精确泡边界 |

只描当前图中**可见且能判断的投影边界**。二维靠近、重叠或消失不是三维接触、吸收或融合的证据。细则见 [MICROBUBBLE_ANNOTATION_PROTOCOL.md](MICROBUBBLE_ANNOTATION_PROTOCOL.md)。

## 5. 草稿、正式确认和换到下一张

- **随时保存草稿：** 点“④ 保存草稿”或 `Ctrl+S`。有修改时每 30 秒自动保存；换帧和正常关闭窗口也会保存修改。每次保存都产生新的修订，不覆盖旧修订。
- **默认只确认区域：** 按第 0 节检查青框内全部内容，填姓名、勾选检查、点“⑤ 确认当前区域”。元数据记录 `REGIONS_CONFIRMED`，整帧 `expert_confirmed=false`；未审核部分仍是草稿。
- **确实要确认整幅图：** 将“审核范围”改为“整幅图都已检查”，完整检查整图后勾选，点“⑤ 确认整幅图”。这才产生 `EXPERT_CONFIRMED`。不能只标了几个泡就确认整幅图。
- **框内也还没检查完整：** 保留草稿即可。不要为了换图或触发训练而勾选。你可以缩小到一块确实能检查完整的区域，再确认那一块。
- **换帧：** 点“⑥ 保存并下一张”。窗口保持打开，只替换图片；上一张内容会保留。也可用 `Alt+→` / `Alt+←`。普通方向键不会换帧。
- **跳转：** “更多 / 训练”中的图片序号从 1 开始，输入后点“跳转”。跳过未标帧不会自动确认它。
- **空画面：** 确实完整检查后，没有目标的帧也可以确认，它是有价值的背景参考。
- **已确认后又修改：** 区域模式仅撤销像素发生变化的已审核区域；其他未变区域保留确认。整帧确认后若编辑，整帧确认失效。保存时会复核区域像素哈希；没有改动时换帧不会取消确认。
- **以前误把漏标帧当作整帧确认：** 回到该帧，范围选“整幅图都已检查”，到“更多 / 训练”点“撤回所选范围的审核状态”，保存草稿；标签保留。再按局部流程重新确认已完整检查的小块。不会在后台擅自重写你的历史确认。
- **候选还没处理：** 未纳入候选不自动保存成标签，也不能带着待处理候选确认；先纳入草稿或清空，再完成检查。换图会丢弃尚未纳入的预览，生成请求与原始结果仍保存在日志目录。
- **关闭前：** 最稳妥的顺序是完成 / 取消正在画的轮廓 → 保存草稿 → 点窗口右上角关闭。强制关闭 WSL 或断电可能丢失最后一次自动保存以后的修改。

如果提示“未保存”，**不要关掉终端**，按右上状态修正。常见原因是轮廓未完成、类别区域冲突，或者正式确认时没有填写审核人。

## 6. SAM 辅助：每个绿点分别分割一个泡

**单泡默认流程：每泡点一下 → 生成独立候选 → 逐泡检查 → 分别编号接受 → 保存。**

你可以像截图里那样，连续在多个不同泡内放绿点。旧版把这些点当成“同一个大对象”的提示，是生成大片区域的一个原因。新版单泡默认采用 **“每点一个单泡”**，每个点分别计算；黄色大框只表示选区，不再把框内的多个泡合成一个对象。

### 6.1 跟着做：连续点选多个泡

1. 在“逐张标注”选择 **单泡 | SINGLE_BUBBLE**，切到 **SAM 辅助**。
2. 确认“提示方式”为 **每点一个单泡（可连续点多个泡）**。不用点手工工具的“新增单泡”或“新建轮廓”。
3. 滚轮放大图像，点 **“1. 放正点”**，在每个要标的泡内部各点一次；可连续点多个泡。状态显示“10 个绿点 → 10 个独立单泡”。**同一个泡不要重复放绿点**；补点修同一个对象请用 6.3 的模式。
4. 默认无需画黄色框。若要限定一片区域，点 **“画选区框（可选）”** 后拖动；已有绿点保留，所有绿点需要位于框内。框不决定单泡大小。
5. **“每个单泡的局部框宽 (px)”** 默认 16 px，代表原图像素，不随屏幕缩放改变。这只是操作起点，不是物理直径标定。明显较大的泡可调整；不要仅为让错误大块通过而调大。
6. 点 **“3. 生成 / 更新候选”**，等待逐泡进度。界面仍可操作；初次加载模型较慢。
7. **“查看哪个泡”** 默认显示全部独立候选，每个泡分别着色。状态会列出需修正的泡编号。**通过尺寸检查不等于轮廓正确。**
8. 逐个选择“泡 1”“泡 2”检查边界；“候选轮廓”可切换三个结果。取消 **“保留当前泡，纳入批量接受”** 可跳过不想接受的泡。
9. 确认后点 **“接受全部有效单泡（分别编号）”**，各泡获得独立编号；异常候选不写入标签。也可选定一个泡，点 **“4. 接受当前泡 / 对象”**。接受过的泡默认退出本批待接受列表，避免重复。
10. 回“逐张标注”保存草稿。接受只是写入标签，**不等于已完成人工审核**；仍可画笔修边、橡皮擦或删除。

已有手工轮廓尚未完成时，先完成或取消，再使用 SAM。

3. 保持“每点一个单泡”，点击生成。恢复只恢复点和框，不会自动接受旧大块或覆盖标签。

历史列表也保留了之后的单点请求；请按点数选取需要的记录。软件回归测试请求不会混入该列表。

对原图和原始 10 点的真实复测中，9 个点有通过尺寸/提示检查的独立候选，第 7 个点的候选仍不合格。这个数字**不是准确率**；尚无这 10 个泡的人工真值，必须查看实际边界。

### 6.3 一个泡边界不准，怎样修正

| 情况 | 操作 |
|---|---|
| 候选不合适 | 先在“查看哪个泡”选该泡，再切换“候选轮廓”。 |
| 背景或邻泡被选入 | 在误选背景加红色负点，再生成整批；相邻其他泡的绿点也会作为当前泡的排除提示。 |
| 某泡始终显示“禁止接受” | 跳过该泡，先接受其他正确泡；再清空提示，单独框选它或手工描边。无需让整批重做手工。 |
| 要用多个绿点修**同一个**泡 | 切换提示方式为 **“一个对象：框选 / 多点修边”**，清空旧点，紧框这个泡，再补正点/负点。此模式所有绿点共同描述一个对象。 |
| 只想框选一个泡，不点绿点 | 使用“一个对象”模式，画紧贴该泡的框后直接生成。 |
| 标的是团或不确定区域 | 在主页面切换相应类别；自动使用“一个对象”模式。不要用单泡模式把一个团当成一个小泡。 |
| 两个候选相互重叠 | 两者都暂不纳入批量接受；切换候选，或只保留确实正确的一项。不会按顺序裁切来凑两个对象。 |
| 与已有标签重叠 | 不会覆盖原标签。点选原对象修边，或删掉错误原标签后再生成。 |
| 修改了点、框、尺寸或类别 | 必须重新生成，旧候选不能直接接受。 |
| 点错或要开始下一批 | 点“清空候选和所有点”，再重新放点。 |

逐泡模式保留 SAM 原始掩码，并取**包含点击像素的连通区域**作为当前对象候选，去掉与该点不相连的背景碎片；不平滑、不填洞、不强制圆形，也不沿小框截断大块。若与点击点相连的区域仍过大，直接拒绝。它仍是辅助分割，不会自动辨认微泡身份。

### 6.4 错误接受后，怎样删除和恢复

- **整批接受错了：**点 **“删除上次接受的一批 / 对象”**，或 `Ctrl+Z` 一次撤销该批；`Ctrl+Shift+Z` 可重做。
- **只错了一个泡：**点“点选已有对象” → 单击该泡彩色标签 → “删除选中对象”。不会删除同批其他泡。
- **删错了：**保持同一类别，点“撤销”恢复。换帧/重启后内存撤销记录不保留，但旧保存修订仍在。
- **想改边界：**点选对象后用“画笔”/“橡皮擦”，无需重新运行 SAM。
- **不小心删了 SINGLE_BUBBLE 图层：**必需图层会自动恢复；也可点“恢复 / 显示图层”。不会清空未保存标签。

删除/修改后保存草稿；修改已确认帧会回到待审核状态。

### 6.5 计算时间与取消

本次原始 10 点的后台复测冷启动约 8 秒，实际速度随负载而变。模型及最近 16 个局部图像特征会复用；同一批再次生成无需重新加载模型或重新编码所有区域。

“取消计算”、清空提示、换帧、正常关闭窗口会取消正在计算的任务。空闲 120 秒模型释放；超过 90 秒的任务自动取消。已有标签不受影响，手工标注不依赖模型。

### 6.6 自动微调已经默认开启

**正常启动工作台即启用自动训练，无需另开终端或再次通知开发者。** “更多 / 训练”页的 **“自动微调（人工确认后后台训练）”** 默认勾选，下方显示训练状态和当前正在使用的 SAM 版本。手工标注和 SAM 提示点仍可继续使用。

操作流程：

1. 手工描画，或检查并修正候选。完整检查一个训练区域，或确实完整检查整张训练图片。
2. 点 **“⑤ 确认当前区域”**，或整图模式的“⑤ 确认整幅图”。新确认标签会被后台发现；仅保存草稿不会触发训练。区域样本的图像上下文、正负提示和目标都限制在该审核区域内。
3. 程序等待约 15 秒合并近期变动，然后自动训练一小轮。训练间至少间隔 5 分钟；相同内容再次保存或确认，不反复训练。
4. 训练在后台进行，GPU 在训练步骤之间优先响应 SAM 分割请求。手工画图、保存、换帧保持可用。若 GPU 显存不足，会显示等待资源。
5. 本轮训练后的权重先保存为候选。若已有合格的独立验证标注，后台自动比较原版、当前使用版本和候选版本；改善达到门槛后，下次生成自动使用新版本。已有人工标签不会被新模型改写。

**默认只微调单泡辅助分割。** 只读取既定 `train` 分组中人工确认的 `SINGLE_BUBBLE` 掩码，至少 8 个有效单泡；测试图片和隔离的直播图片不进入训练。验证标签只评价、不计算梯度。含不确定/失焦区域的局部上下文以及被裁断的对象会排除并写入日志。未检查的自动候选和草稿永不当作真值。

每轮最多 **80 个优化步骤 / 180 秒 worker 内预算**，冻结图像编码器和提示编码器，只更新掩码解码器；CPU 线程设为 2。编码器特征在本轮复用，权重单独保存在 `results/sam_auto_training/`，不会覆盖原始 SAM 权重。时间上限不含进程启动/导入；外层另有超时看护。失败保留日志，原模型继续可用。

### 6.7 “等待验证”时该做什么

首次真实训练已经用 38 个有效单泡完成（39 个确认实例中 1 个因裁剪截断而排除）。这次历史训练没有确认的验证帧，因此当时显示 **“候选模型已保存，暂未替换当前模型：需要至少 2 张验证帧 / 10 个单泡”**。

可在“更多 / 训练”页跳转到 **第 25 张 `video_000360`、第 26 张 `video_000374`** 开始验证集标注，按窗口中的 `validation` 分组核对。可在这些验证帧里分别选区域并完整检查后确认；应覆盖不同位置、密度和清晰程度，不能只挑模型分得好的泡。无需移动现有图片的数据分组。

自动切换要求：至少两个不同来源验证帧的已审核区域或整帧、合计至少十个有效单泡（同一帧多个区域仍只算一帧）；候选在这些固定人工提示下的平均 IoU 比原版提高至少 0.02，比当前使用版本提高至少 0.005；任何验证帧平均 IoU 不下降超过 0.03，IoU < 0.5 的失败提示比例不增加。缺少数据或没有达到要求，就继续保留原模型。

这些是**辅助标注工具的工程切换门槛**，不是微泡自主检测或跨实验泛化的科学验收。提示来自人工掩码内部位置，并使用固定局部框。训练集拟合改善也不等于独立效果改善。当前所有图片仍来自有限实验，测试集继续隔离。

### 6.8 暂停、恢复与回退

- **临时不想训练：**在“更多 / 训练”取消“自动微调”勾选；在下一检查点停止当前训练。手工标签保留。
- **继续训练：**重新勾选；被取消的一轮可重新排队。没有新内容且上一轮已完成时不会重复计算。你的开关选择会保存，首次默认开启。
- **新模型不好用：**点 **“恢复原版 SAM”**。下次生成用原版，当前未接受候选清除，人工标签保留。可以同时取消自动微调，保持原版。
- **关闭窗口：**最后一个正式工作台关闭后，训练服务停止；正在训练的任务会取消。重新打开自动恢复检查。
- **本次启动只禁用训练：**启动命令末尾加 `--no-auto-train`。使用 `--manual-only` 则同时禁用所有模型分割和自动训练。软件测试窗口不会启动正式自动训练。
- **训练失败：**状态会明确提示，失败日志在 `results/sam_auto_training/<运行编号>/worker.log`；不会把失败模型替换到工作台。更新有效标签或修正训练代码后才重新尝试，避免持续失败循环。

运行状态：`data/auto_training/status.json`。每次训练保存冻结的数据来源、版本、SHA-256、优化损失、真实耗时、显存、模型校验和及是否通过切换检查。`decoder.pt` 只保存微调模块，原版权重保持原位。

实现复用 [micro-sam 的原版 SAM 微调组件](https://github.com/computational-cell-analytics/micro-sam/blob/main/doc/python_library.md)。

## 7. 连续 8 帧的短轨迹（可晚些做）

录像候选中有三段连续帧：120–127、450–457、780–787。仅给确实能对应的少量对象设置短轨迹 ID，不要求每颗泡跨长时间保持身份。

在“更多 / 训练”页：选正确类别和当前帧实例编号 → 填 `A`、`B` 等短轨迹 ID → 点“保存短轨迹 ID 到本帧” → 保存 / 确认本帧。同一片段中同一对象的 ID 应保持一致。不同帧实例编号可以不同。看不清、失焦或遮挡时留空，不凭运动方向猜身份。

## 11. 本轮局部批量流程验收与限制

实际原图上的 GPU 批量生成、真实鼠标框选、候选删除/撤销、整批纳入/撤销/重做、两点拆分、原标签保护、换帧取消、参数变更取消、草稿重开均有独立软件验收。按钮采用统一两列网格，侧栏宽 440 / 500 下逐项检查位置、宽度和文字可见性。软件测试目录与正式标签分离。

区域确认只表示你完成了该矩形内的人工检查。还没有证明跨实验泛化，也没有证明批量模型自主识别准确率。若要评价整帧漏检率，仍需整帧真值，或预先登记、具有代表性的独立 ROI 基准；不能把这些 ROI 的指标直接称为全视野指标。预先固定训练/验证/测试分组保持不变。
