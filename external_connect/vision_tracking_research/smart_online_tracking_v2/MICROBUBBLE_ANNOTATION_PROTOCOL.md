# 微泡人工标注规范

> **最新续研：2026-10-16，已完成离线人工ROI评价。** 以下较早记录按历史保留；当前状态以文末续研和[完整报告](results/supervised_20261016_v1/REPORT.md)为准。

标注依据是实验人员对当前显微图像及相邻短片的判断，不是模型预测、固定流向或 F10S 模拟规律。图像单位为 px；物镜、适配器、焦平面或 µm/px 未确认时保持未知。

| 类别 | 使用条件 |
|---|---|
| SINGLE_BUBBLE | 能确认是独立可见微泡，边界能合理描出；每泡一个实例编号。 |
| AGGREGATE | 实验人员确认是多个泡组成的可见团，标二维可见投影外轮廓；不推断内部遮挡泡的数量。 |
| BACKGROUND_ARTIFACT | 已确认的 PDMS 纹理、固定结构、碎屑或非泡对象。不能只因不运动就认定是背景。 |
| UNCERTAIN | 不能确定生物身份、投影重叠关系或是否为团；保留拒判，不强行拆分或合并。 |
| OUT_OF_FOCUS | 失焦导致位置/轮廓不可可靠判定；不用模糊光晕制造确定轮廓。 |

优先画可见对象内部及边界，避免把宽光晕当作真实泡径。同一像素不允许被多个类别占用；本轮采用互斥二维实例掩码，不支持隐藏三维对象重叠真值。若两个投影不可分，将无法确定的区域归为 UNCERTAIN。团外轮廓与组成单泡不可在同一像素重复计数。

每个拟确认的区域（或整幅图）至少进行两遍检查：第一遍找单泡和团，第二遍检查背景误标、视野边缘、弱对比漏标和不确定区域。空白像素在“完整人工审核”后才具有已检查背景的含义，未审核图像的空白不是真值背景。

Cellpose、µSAM 和原版 SAM 只作轮廓建议。用户必须检查、修正并明确确认；批量纳入只是草稿。整帧审核使用 EXPERT_CONFIRMED；局部矩形审核使用 REGIONS_CONFIRMED，expert_confirmed=false，并记录原图坐标、人工审核人及区域像素 SHA。只有确认矩形内的未标像素才具有已检查背景含义；框外未审核内容不进入区域训练/验证。改动使受影响区域的审核失效，其他区域保留。

短片段仅核查 8 帧中的少量可辨对象，手动记录短轨迹 ID；遮挡、失焦或突然出视野时允许中断。突然转向不是删除对象的理由。二维重叠、消失、团面积增加均不能证明三维接触、吸收或物理融合。

数据按固定时间块分组，连续片段不跨组。相邻帧不能随机分到训练和测试。模型参数只能根据训练/验证标签选择；测试集不用于调阈值。若不足以确认跨实验日/样本泛化，保留 CROSS_SESSION_GENERALIZATION_NOT_VERIFIED。

Cellpose 训练导出仅接受正式确认标签。标准 Cellpose 损失不支持本工程的忽略区域时，含 UNCERTAIN/OUT_OF_FOCUS 的拟导出图像（整帧或已审核 ROI）默认排除训练，避免把未确认对象当背景学习；不静默将这些掩码转换为负例。单泡与团的类映射另存 JSON，不能把 Cellpose 的无类别实例输出称为已验证的微泡分类器。


## 局部审核与数据边界（2026-10-16）

- 可以只做一小块，但块内必须检查漏标、误标、框边对象和背景。不能仅接受模型检出的对象就确认。画面太密集时缩小审核框，而不是把框内漏标当作背景。
- 同一图可以有多个审核区域；同帧的多个区域不构成独立验证帧，不重新随机拆分训练/验证/测试。区域坐标保留原像素分辨率，不作物理标定声明。
- SAM 自动微调的完整上下文裁剪被限制于单个已审核矩形内；截断目标及含忽略区域的上下文排除。Cellpose 导出直接裁出审核矩形，含忽略像素的裁剪不导出；框边实例只保留可见截断部分，不能用于声称完整粒子形态。
- 多个审核区域重叠时 SAM 同帧同 ID 样本去重。通用 Cellpose ROI 导出保留各个裁剪和来源 ID；评估方须按来源帧分组，不能把重叠 ROI 当作独立样本。
- 已有人工整帧确认不会被软件擅自篡改。若审核人发现旧帧漏标，可在界面撤回审核、保留草稿，再分区域完成。
- 两点 watershed 拆分是人工指定的编辑建议，保留原像素并集，必须检查分界；不能因此推断真实三维接触或融合。


## 2026-10-16 已有标注的离线续研（supervised_20261016_v1）

本轮只评价冻结的10个已审核ROI。验证133个单泡中4个边界/裁断排除，129个计分；中心6 px匹配与mask IoU≥0.5分开。一对一先最大化有效匹配数；排除项逐ROI保存。不确定类样本不足，不报拒判准确率。未经审核的外部区域不作为背景。
