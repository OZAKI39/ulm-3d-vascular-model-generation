Tektronix AFG1062 real-device switch test - 2026-10-15 (Europe/Zurich)

Result: a worthwhile additional improvement was found, implemented and validated.
All timings below are medians of three cycles per channel per version, in ms.

Channel    Before ON check         ON through confirmation    OFF through confirmation
PZT1      182.3 ->   121.9     252.6 ->   162.1      70.2 ->    40.0
PZT2      182.3 ->   121.9     252.8 ->   162.0      70.3 ->    40.1
PZT3      182.5 ->   122.0     252.9 ->   162.1      70.3 ->    40.1
PZT4      182.5 ->   121.9     253.0 ->   162.1      70.3 ->    40.1

Protocol and limits:
- A = serial 2147075, firmware V1.0.9; B = serial 2439003, firmware V1.1.0.
- Each channel was actually switched ON/OFF at 0.001 Vpp into a 50 ohm load setting.
- Only one channel was enabled at a time. OFF followed ON confirmation immediately.
- The test kept each channel's original frequency: A/CH1 5 MHz, others 2.5 MHz.
- All original checked parameters were restored, including amplitudes of 0.1 Vpp.
- All four final output-state queries returned OFF. No instrument errors occurred.
- These are software/USB and instrument-state timings, not oscilloscope measurements
  of analog output onset or PZT behavior. GUI scheduling time is not included.

Change:
- Batch both error queries around the existing 17 pre-ON parameter queries.
- Batch output-state and error confirmation after ON/OFF.
- Preserve all validation, consume every response before enabling, report all errors,
  and block further control on partial responses. No checks were removed.
- 58 offline regressions passed, including both protocol modes and error recovery.

Stop decision:
The remaining measured time is mostly instrument/USB response time. No other
clear redundant wait was identified. Stop further optimization at this version.
