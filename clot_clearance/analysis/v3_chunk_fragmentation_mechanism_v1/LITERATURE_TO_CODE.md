当前单键虚拟失效能量计算为：固定所有 x 和其他 d，将目标连接两端的星能量分别重新极小化。局部能量可以写为 `U_i=0.5 Σ D_a w_a e_a² + 0.5 n_i²/a_i`；断开该连接时同时更新星内 `n_i`、`a_i`，所以包含与其余连接的耦合。已逐帧抽样与完整模型重算核对。该差值不是材料 Gc，也不能把每条键各自虚拟去除的差值当成互相独立的可加耗散。
