# Current-step detachment and background drag

Only existing official Python/library APIs are used; no native source/library modification. Fixed local LAMMPS commit and source/library hashes are in INTERFACE_READINESS.json. In bond_bpm_peri.cpp the bond list is invalidated and BondBPM::process_broken immediately removes atom bond entries. BondBPM::post_compute reduces atom->nbonds before Verlet post_force. Thus the every-step external callback checks current nbonds, calls gather_bonds collectively only when it changes, and reconstructs the current surviving graph. No old/future trajectory labels are accessible to the callback. All anchor bonds must survive. A clot component with no surviving interface connection to any fixed anchor is detached. Initial exact graph and audit writing were checked in MPI run 0, advancing zero physical steps.

The existing nativewall callback remains first; earlyflow then adds force in Newtons after the existing SI conversion. Native time step 0.5 us. Drag begins in the same post_force evaluation that sees the native breaking event, subject to valid current COM tetra membership. No velocity or position array is written. Verlet velocities read in post_force are half-step values: audit names this explicitly; dumps after final_integrate are full-step values.

For each detached component, compute current COM position and velocity from equal nodal masses. Query native P1 CFD at that COM, strictly inside a native tetra; outside queries produce no force or extrapolated fluid velocity. 1–2 nodes: F=M(u-v_COM)/100us (NUMERICALLY_UNRESOLVED_DEBRIS), not a physical hydrodynamic size. >=3 nodes: existing equivalent reference-volume sphere with Schiller–Naumann factor, same rho and mu. The task's '=3' is interpreted as >=3, consistently with the existing 1–2 vs >=3 model partition. Distribute total component force as m_i/M times F, preserving exactly the resultant and zero net drag torque about the COM. Internal relative modes are not separately damped by the COM approximation.

Remove old fix viscous; apply -500*m*v only to still attached nodes inside earlyflow. For detached nodes numerical damping is exactly zero, even on an invalid CFD query. Attached core never receives free-particle drag. This damping-state switch is a declared model change and may change break counts. Loading remains the original Gaussian prescription on frozen reference surface nodes.

Every detached node at every native step records step, immutable ID, membership, first detachment step, query tetra, validity, x, half-step v, component u, drag, numerical damping, actual native wall force, applied Gaussian force and force before earlyflow. All nodes additionally recorded at topology updates / output steps. No CFD extrapolation. NEAR_WALL_UNCERTAIN if any member center is within100um; CLOT_PRESENT_FLOW_UNCERTAIN if COM lies within an original material voxel circumsphere or within50um of retained material. These conservative flags cannot validate the absent clot-present flow.

Phase 2 must call the same instantaneous drag_law at the accepted full-step terminal COM state. Compare with a fresh evaluation at the same state, separating the last half-step force difference from a genuine law change. Existing rigid component transport retains member offsets and COM x/v; it truncates internal deformation/rotation and attached-body mechanics after2.33ms. It is not an assertion of pointwise internal-velocity continuity. Record the discarded internal velocity scale explicitly. Retain existing native-wall unilateral transport constraints and disclose the contact-model/integrator change.
