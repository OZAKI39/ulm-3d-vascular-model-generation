============================================================
1. 本轮唯一科学问题
============================================================

当前 small 3x3x3 tensile cube 中：

给定 phase s
    ->
ADR mechanical equilibrium
    ->
AT1 phase minimization
    ->
new s
    ->
再次 mechanical equilibrium

形成 fixed-point mapping：

    s_(k+1) = Phi(s_k)

稳定 case 能收敛。

失败 case 中：

    max phase increment

随 staggered iteration 放大，
中段观测 amplification ratio 约 1.93。

需要区分：

HYPOTHESIS A:
    coupled local minimum 存在，
    但 simple staggered fixed-point iteration 不稳定。

HYPOTHESIS B:
    当前 loading state 下，
    原 equilibrium branch 已失去局部能量稳定性，
    即没有附近的稳定 coupled local minimum，
    或最低能量状态发生 localization / branch change。

HYPOTHESIS C:
    phase active-set / threshold switching
    造成 non-smooth fixed-point map，
    目前的“1.93”不能解释为普通线性谱半径。

HYPOTHESIS D:
    当前数据不足以区分。

本轮只做定位。

禁止自动实现新 solver 修复。
