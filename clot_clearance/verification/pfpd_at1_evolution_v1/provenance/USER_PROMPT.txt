6. AT1 bond energy
============================================================

在 h=1、固定 BAQP kinematics 下：

定义：

    Y = Psi0_plus

本轮第一阶段只使用纯 tensile benchmark，
使：

    Psi0_plus = Psi0

避免自行发明 finite-strain tension/compression split。

定义：

    g(s) = (1-s)^2

    E_elastic_bond =
        g(s) * Y

    E_crack_bond =
        Gc/(c0*delta) * s
        = 2*Yc*s

    E_total_bond =
        E_elastic_bond
        + E_crack_bond

其中：

    Yc = Gc/(2*c0*delta)

当前 quadratic kernel：

    c0 = 0.25

必须从已有 normalization module 读取，
不要硬编码多个副本。

============================================================
7. AT1 constrained minimizer
============================================================

对于固定 Y：

未约束 stationary relation：

    -2(1-s)Y + 2Yc = 0

得到：

    s = 1 - Yc/Y

考虑：

    0 <= s <= 1

得到 trial state：

    if Y <= Yc:
        s_trial = 0
    else:
        s_trial = 1 - Yc/Y

施加 irreversibility：

    s_new = max(s_old, s_trial)

然后：

    s_new <= 1

在 coupled candidate 中额外要求：

    s_new <= s_c

否则触发 high-damage gate。

    s_new == s_old

    q(s_new) >= -tolerance

    0 <= s_new <= 1

D.
fixed-Y phase update：

    E_total(s_new)
    <=
    E_total(s_old) + tolerance

这是本轮最重要的 thermodynamic/software gate。

       mechanical + phase convergence

    stop
