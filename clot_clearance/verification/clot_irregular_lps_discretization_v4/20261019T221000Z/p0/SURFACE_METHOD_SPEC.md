# V3：受支持三角面与保守控制体积补充求积

科学状态：`CURRENT_SURFACE_APPROXIMATE_COUPLING`、`PRESCRIBED_SHEAR_MECHANICAL_SURROGATE`。本方法没有重建已验证的连续流体外壳，没有改变材料质量、原始键、LPS 能量、接触、积分器或材料卡。

Level 1 通过组合调用冻结 V2 `CurrentSurface`，保留其完整三角面、正 1/3 节点映射、开口／可达图和当前四面体遮挡判定。补充算法不会移除现有激活三角面。

Level 2 将原始每点体积 dx³ 解释为参考格点对偶立方体，面面积 dx²、中心偏移 ±dx/2。它只考虑在全部存活原始材料图中已与锚层脱离的分量。相邻参考单元仍在同一存活分量时不生成补充内部面。所有原始键与对偶面方片的交叉表预先计算，包含非近邻键及边角接触；只要仍有原始存活键穿过该片，便保留为未解析。没有恢复材料键或按空间距离合并碎块。

局部变形由当前存活原始邻域的参考加权仿射拟合得到，权重为参考键长平方的倒数。F 仅用于表面几何，不进入材料能量或重算 m。秩亏、反转、参考／当前条件数超过 100 的拟合不激活。面法向和面积由 F 的余子式映射得到；相邻参考单元的映射半厚度用于开口检查，1–5 µm 开口平滑窗沿用 V2。存在参考邻居却不能确认开口时不加载。

每个有效补充面使用中心一点求积。外向直线射线必须避开全部当前仿射对偶单元，并额外避开真实 L1 存活四面体边界；3 µm 外向探针也不能位于存活四面体内。秩亏单元作为参考对偶立方体外接球障碍保留，不能当作流体。这个外部可见性证明仅是保守准静态代理：被挡的射线不能证明不存在弯曲流路，参考外接球也不能恢复低维碎屑的真实水动力几何。

为避免重复面积，在参考空间中，对偶单元外接球与激活 L1 三角面外接球可能重叠时，整个补充单元被排除。这个条件比必要条件更严格；它会漏掉部分可受力面，漏算必须报告。参考体积面与原始三角表面属于不同离散近似，未声称它们共同组成无缝连续曲面。当前射线遮挡和内部桥接检查用于拒绝不可靠面，不用面积增量反向调整门限。

面中心满足 yq=Σ Ni xi，面速度采用同一组 Ni：vq=Σ Ni vi，节点力 fi=Σq Ni Fq。因此 Σfi=ΣFq、Σxi×fi=Σyq×Fq、Σfi·vi=ΣFq·vq，固定拓扑时逐面成立。L1 使用非负权重。L2 真实控制体积外侧面常处在支撑节点凸包外，非负标量权重无法同时复现该位置；因此采用有明确仿射含义、受限的带符号权重（单权重不小于 −0.25，绝对权重和不超过 2）。不满足限制时标为 UNRESOLVED，绝不以强制正权重牺牲力矩／功率守恒。上述门限是分辨率与外推限制，不是物理标定参数。

切向牵引保持 β Pt(u−vq)，β=40 Pa·s/m。驱动速度沿 +X 投影，不归一化切向方向；驱动关闭后 u=0，阻力功率为 −βΣ Aq|Pt vq|²≤0。原始 ID 接口保留，当前只支持已验证的单 MPI rank，所有权检查逐回调执行。原生线程和求解库不变。

材料图、参考梯度和交叉表使用缓存；只有完整失效键集合改变时才重建拓扑，坐标变化只更新几何。试态可以拥有临时计算缓存，但只有通过接受门限后 `commit()` 才更新曝光历史和已接受拓扑。拒绝试态不能改变 ever_loaded、累计面积、κ 或 d。重启从原生键历史重建拓扑，侧车恢复曝光历史并核对原始 ID、时间、步号和参考哈希。

每接受步外功始终按真实原生节点位移、端点节点力计算。新裂面和 L2 分量同样先映射成节点力后再计算功，不使用变拓扑虚拟面中心的跳变位移，否则会引入伪功。它们是总外功的诊断分项，不能再次加到总账本。

类别分别输出 ORIGINAL_EXPOSED、NEW_CRACK_ACCESSIBLE、OPEN_BUT_INACCESSIBLE、CLOSED_OR_OCCLUDED、DETACHED_EXPOSED、UNRESOLVED。没有有效面或部分候选面未解析的分量，分别标为 FLUID_LOADING_UNRESOLVED 或 PARTIAL_RESOLVED_PLUS_UNRESOLVED。节点覆盖是具有非零求积权重的原始节点比例，不是已解析连续表面积的比例；真实未表示面积仍未知。
