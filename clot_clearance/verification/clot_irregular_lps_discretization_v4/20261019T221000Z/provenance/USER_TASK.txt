# Codex 开发任务：V4 不规则LPS点云、性能优化与碎块稳定性研究

## 0. 本轮核心指令

本轮必须实际修改代码、执行必要验证、分析已有计算瓶颈，并在满足数值条件后执行一次新的原生动力学模拟。

**主要目标：将当前规则笛卡尔材料点阵改为可复现、体积守恒、非局部力学一致的不规则点云，同时优化计算效率，研究离散结构对裂纹传播和20–200节点凝聚性碎块形成及存活的影响。**

本轮不能通过人为切割、指定碎块形状或预先删除材料连接来实现目标。

### 必须保持不变的物理条件

- 原始材料几何：1.2 × 1.2 × 0.6 mm；
- 材料点数量：8125；
- 锚点数量：1875；
- 原始标称点距：50 µm；
- 非局部horizon：150.5 µm；
- 强弱材料相区：上一轮冻结的10个强区；
- 强相体积分数及原始材料ID的相区归属；
- 强弱材料参数；
- G、K、rho；
- 初始预制缺口的物理几何；
- LPS完整变分能量；
- 原生接触模型；
- 原生不可逆损伤演化；
- 1000 Pa名义表面剪切驱动；
- 0–3.6 ms物理时间协议；
- V3已建立的表面流体载荷方法。

当前数值与材料：

| 材料 | s0 | sc |
|---|---:|---:|
| WEAK | 0.100 | 0.120 |
| MIXED | 0.175 | 0.210 |
| STRONG | 0.250 | 0.300 |

G = 940 Pa

K = 100000/3 Pa

rho = 1000 kg/m³

**不为了提高碎块数量而调整材料参数。**

20–200节点是碎块结果评价区间，而不是不规则点云的尺寸要求。

# 2. P0：首先完成原生求解器性能剖析

**在修改材料点阵前先做这一步。**

当前V3单次3.6 ms模拟约需11.7小时。需要确定实际计算时间消耗，而不是仅通过节点数推测。

## 2.1 增加分项计时

分别统计：

1. 初始化、邻域生成和材料属性读取；
2. LPS内部力与完整能量计算；
3. 损伤候选计算；
4. 接受态不可逆历史提交；
5. rejected trial、rollback及重复计算；
6. V3表面识别和流体可达性；
7. 表面载荷映射与节点力；
8. 存活材料图连通分量计算；
9. 碎块谱系更新；
10. accepted-state内存快照及恢复；
11. 磁盘checkpoint和结果输出；
12. 其他未归类开销。

记录wall time、CPU time、调用次数、每次平均耗时和累计占比。

计时本身必须足够轻量，避免明显改变原有执行性能。

## 2.2 使用代表性短窗口

优先复用V3已有checkpoint或保存态。

至少覆盖：

- 基本完整材料状态；
- 已发生明显损伤和新裂面的状态。

仅运行必要的短时计时窗口。

不重新运行11.7小时的V3历史基线。

生成：

`PERFORMANCE_BASELINE_V3.json`

`FIG_01_NATIVE_TIME_BREAKDOWN.png`

`PERFORMANCE_BOTTLENECKS.md`

根据实际耗时排序决定优化优先级。

# 3. P1：优化计算效率，但保持原有物理语义

根据P0的实际数据选择最有价值的优化。

## 3.1 材料邻域

当前初始规则点阵使用150.5 µm截断半径。

将参考邻域生成改为能够处理一般三维点云的空间搜索。

优先考虑：

- KD-tree；
- cell-linked list；
- spatial hashing；
- 其他更适合当前C++求解器的固定参考邻域算法。

原始材料连接仍由参考构型决定。

断键后不得根据当前位置重新生成材料键。

必须保留：

- 原始材料节点ID；
- 原始锚点ID；
- 确定性的原始键身份；
- 原始参考长度；
- 相区属性；
- 不可逆损伤历史。

新点云生成的原始键数量可能改变，这是本轮需要测量的离散效应，不应强制与规则点阵完全相同。

## 3.2 表面识别优化

分析当前V3表面计算中：

- 哪些参考几何信息可以预计算；
- 哪些几何只需更新坐标；
- 哪些表面拓扑只会在接受态损伤变化时改变；
- 哪些流体可达性计算可以增量更新。

优先实现缓存和局部更新。

对于直接影响原生流体力的表面变化，必须在相应物理接受态及时更新。

不要简单规定每10–20步才更新一次受力表面。

允许降低纯诊断图表和不参与力计算的完整谱系输出频率，但不得丢失真实碎块出生与分裂事件。

## 3.3 碎块连通性

优化真实存活材料图的连通分量分析。

优先在损伤提交后进行必要的拓扑更新，避免无变化时重复扫描整个材料图。

保持现有精确节点成员集合定义。

## 3.4 Rollback和数据输出

检查内存快照是否存在不必要的全量复制。

在不破坏rejected-state rollback的前提下，减少重复复制不变的几何数据和原始键属性。

保留磁盘checkpoint、restart和历史FP64证据。

不允许用仅存在于内存中的状态替代必要的可恢复checkpoint。

## 3.5 性能结果

输出：

`PERFORMANCE_OPTIMIZATION.json`

`FIG_02_BEFORE_AFTER_TIMING.png`

报告：

- 原有耗时；
- 优化后耗时；
- 每一部分真实节省；
- 额外内存开销；
- accepted/rejected步数；
- 相同物理模型下是否保持数值结果一致。

不提前承诺必须提高多少倍。

# 4. P2：实现不规则LPS参考材料点云

这是本轮主要科学开发任务。

## 4.1 点云生成

以当前V3使用的规则参考材料点阵为基础。

保留原始材料节点ID、相区身份和试样物理边界。

对内部材料节点施加可复现的三维随机位移。

建议第一版：

`dx_nominal = 50 µm`

`jitter_max = 0.25 × dx_nominal = 12.5 µm`

`random_seed = 20261019`

随机扰动应为三维各向同性，并明确记录概率分布与实际位移统计。

12.5 µm是允许的单节点位移模长上限，不是每个坐标分量分别可以移动12.5 µm。

不允许无限制完全随机布点。

对样本外表面、初始缺口边界及固定锚点采取与实际边界几何一致的处理：

- 固定锚点保持原有锚定位置；
- 外表面不应因随机扰动形成非预期开放孔洞；
- 必要时对边界点使用切向扰动或固定位置；
- 不允许改变试样整体尺寸或预制缺口位置；
- 不允许引入非物理节点重叠。

设置必要的最小点间距与局部几何非退化检查。

如果当前扰动实现导致严重局部几何问题，修正生成方法，而不是通过修改物理材料阈值补偿。

## 4.2 规则和不规则点云使用同一材料场

当前强弱材料属于空间材料属性。

正式对照中保留每个原始材料ID的相区属性：

- WEAK保持WEAK；
- STRONG保持STRONG；
- MIXED键仍由两端相区关系定义。

强区数量和材料节点成员集合不变。

随机扰动只改变参考几何和由几何决定的邻接关系。

额外保存原始规则位置与新不规则位置的映射。

# 5. P3：重新计算不规则点云的体积与非局部参考量

**不能仅移动节点位置，然后继续把所有节点都当作相同体积。**

## 5.1 参考控制体积

根据新的参考位置重新计算材料点积分体积。

优先研究：

- 原始规则单元映射后的局部几何体积；
- 辅助四面体体积积分；
- 截断Voronoi单元；
- 其他守恒的非结构化点云体积求积。

对于当前规则参考格子，可优先评估固定辅助单元剖分、变形后计算单元体积并将体积分配给顶点的方法，以避免不必要的昂贵全局Voronoi重建。

这些辅助单元只用于几何求积，不意味着把LPS材料力学替换为FEM单元。

要求：

- 每个有效材料控制体积为正；
- 总体积与原始物理材料域一致；
- 不重复计入锚点体积；
- 初始质量计算与原有材料定义一致；
- 质量密度rho保持不变。

输出真实体积分布。

## 5.2 LPS非局部参考量

在不规则参考点云上重新计算：

- 每条原始键的参考向量；
- 参考长度；
- 非局部权重；
- 参考加权体积；
- 相应变分力学归一化量；
- 需要更新的离散形状张量或局部修正项（如果当前模型实际采用）。

保留现有完整endpoint-star能量形式及其力学定义。

检查不规则体积和邻接关系是否改变LPS力与能量的对应实现。

必须沿真实变分能量重新计算力，不允许直接把规则网格版本中的常数照搬到新点云。

## 5.3 原始键重新生成

根据新参考坐标建立：

`|Xi − Xj| ≤ 150.5 µm`

的材料邻域。

保留原有预制缺口的几何切断规则及材料类型定义。

由于原有截断半径接近3dx，轻微扰动也可能使部分原始邻居跨过截断边界。

必须统计：

- 原始键总数；
- 新增参考键；
- 消失的参考键；
- 邻居数分布；
- 参考键长度分布；
- 键方向分布；
- 强—强、弱—弱和混合相连接数量；
- 初始连通性；
- 初始预制缺口完整性。

不要将变化的参考键总数直接视为错误。

但是需要判断这种变化是否引入明显的数值方向偏置、异常刚度或局部稀疏区域。

新参考键采用确定性的端点ID对进行身份标识，保存旧规则键与新键的对应关系。不得假定重建后的数字bond ID与V3完全相同。

输出：

`IRREGULAR_REFERENCE_GEOMETRY.json`

`REFERENCE_BOND_TOPOLOGY.csv`

`FIG_03_REGULAR_VS_IRREGULAR_LATTICE.png`

# 6. P4：最少必要的离散力学检查

本轮只做与点云改变直接相关的重要测试。

## Test 1：参考几何

检查：

- 所有材料点存在；
- 原始ID唯一；
- 无严重节点重叠；
- 无非正控制体积；
- 总材料质量正确；
- 非局部邻域合理；
- 预制缺口正确；
- 初始完整材料没有非预期孤立点；
- 初始未加载状态不存在异常内力。

## Test 2：基本弹性响应

使用小型代表性试样，比较：

- 规则点云；
- 不规则点云。

进行一次小变形体积拉伸和简单剪切。

记录：

- 反力；
- 等效体积与剪切响应；
- 储能；
- 实际力与能量梯度；
- 离散各向异性。

不要求逐节点受力完全一致，但应有清楚、预先设定的可接受离散误差范围。

不得为了让测试通过而重新标定G、K或断裂阈值。

如果不规则离散引起显著弹性响应偏差，应先修正积分与非局部归一化，再考虑正式断裂模拟。

## Test 3：原生状态正确性

检查：

- accepted-state提交；
- rejected trial rollback；
- κ/d单调不可逆；
- 节点ID及键ID稳定；
- 表面力映射；
- 一次restart延续；
- 能量账本。

只执行必要的代表性测试。

不运行大量无关历史验证矩阵。

# 7. P5：短时原生性能与动力学试运行

完成P0–P4后，在新不规则试样上运行一次短时原生动力学。

建议从t=0运行到约2.0 ms。

目的：

1. 确认真实原生节点能够正确运动；
2. 确认不可逆损伤能够自然发生；
3. 检查裂纹是否出现异常网格依赖；
4. 检查表面载荷与真实节点力；
5. 检查非规则点云的求解开销；
6. 检查损伤事件是否导致过量reject和rollback；
7. 检查动能、储能、损伤耗散和残差。

注意：

**2.0 ms不是正式碎块结果窗口。**

不能根据短时模拟没有20–200节点碎块就判定本轮失败。

上一轮很多凝聚性碎块的产生与继续分裂发生在2 ms之后。

这一步只用于确认数值可行性和预估完整运行成本。

如有可能，从短时试运行的合法接受态checkpoint直接继续正式运行，避免重算已完成的部分。

# 9. P7：分析规则与不规则点云的真实裂纹和碎块

对比：

- `V3_H_REGULAR`：上一轮真实保存结果；
- `V4_H_IRREGULAR`：本轮新结果。

必须明确：两者材料属性与规定加载相同，但参考节点位置、参考连接和积分权重不同。因此结果差异反映整个离散方案的变化，不能直接归因于单纯的裂纹形状不规则性。

## 9.1 裂纹发展

统计：

- 首次软化时间；
- 首次完全断裂时间；
- 断键空间分布；
- 损伤网络形成；
- 裂纹方向；
- 裂纹路径曲折度；
- 裂纹是否与原始坐标轴异常对齐；
- 真实断键数量；
- 跨相原始连接存活；
- 新裂面开放与受力情况。

重点检验：

**不规则点阵是否真正减弱规则网格方向偏置，而不是只让视觉渲染变得不规则。**

## 9.2 真正的凝聚性游离块

只能使用：

`SURVIVING_ORIGINAL_MATERIAL_GRAPH`

判断连通分量。

统计：

- 1–2节点碎屑；
- 3–13节点；
- 14–19节点；
- 20–33节点；
- 34–113节点；
- 114–200节点；
- >200节点；
- 最大游离块；
- 目标20–200节点数量；
- 目标碎块质量；
- 游离总质量；
- 卸载后的二次碎裂；
- 内部存活材料键；
- 成员集合存活与后代变化。

由于不规则节点具有不同积分体积，同时提供：

- 原始节点数；
- 物理参考体积；
- 物理质量；
- 相当于50 µm规则节点体积的等效节点数。

历史目标仍用20–200个原始节点评价，但必须明确其与实际物理碎块体积不是完全相同的量。

## 9.3 碎块三维形态

对具有实际内部存活材料连接的碎块，计算：

- 参考体积；
- 等效球径；
- 主惯性轴；
- 长宽厚比；
- 回转半径；
- 内部存活键数；
- 局部凝聚性；
- 非规则边界程度。

区分：

`COHESIVE_BLOCK`

`THIN_SHEET`

`FILAMENT`

`SMALL_DEBRIS`

这些属于描述性形貌分类，不应修改真实材料图成员身份。

特别比较：

1. 碎块边缘是否不再显著沿坐标轴排列；
2. 是否自然形成不同方向的裂纹；
3. 20–200节点块是否增加；
4. 这些块是否能在卸载后继续存活；
5. 细屑比例是否降低。

不要只凭视觉判断成功。

# 13. 最终必须回答的科学问题

报告具体耗时、内存和主要优化来源。

报告客观方向性和拓扑指标。

必须使用真实存活材料图。

重点分析卸载后的二次碎裂。

**Q7：观察到的变化主要是数值离散效应，还是能够支持新的物理结论？**

只有一次随机点云样本，不能据此宣称统计稳健性或物理微观结构已经验证。

**Q8：是否值得下一轮继续采用不规则LPS点云？**

根据精度、碎块表现和真实计算成本提出建议。
