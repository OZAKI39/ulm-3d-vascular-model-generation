16. EXACT FTILDE ERROR IDENTITY
============================================================

This is REQUIRED.

For quadratic deformation,
the exact bond secant satisfies:

    eta_ij
      =
    F_exact(X_mid) xi_ij

exactly.

Because exact F is linear in position:

    F_exact(X_mid)
      =
    1/2(
        F_exact(X_i)
        +
        F_exact(X_j)
      ).

Define nodal errors:

    DeltaF_i
      =
    Fbar_i - F_exact_i

    DeltaF_j
      =
    Fbar_j - F_exact_j

and:

    D_ij
      =
    0.5(
        DeltaF_i
        +
        DeltaF_j
      ).

The current BAQP formula is:

    Ftilde
      =
    Fav
      +
    outer(
        eta - Fav xi,
        xi
      ) / |xi|^2.

Therefore the quadratic error must satisfy:

    DeltaFtilde
      =
    Ftilde
      -
    F_exact_mid

      =
    D_ij
    [
        I
        -
        n tensor n
    ]

where:

    n = xi / |xi|.

This is an exact projection identity.
