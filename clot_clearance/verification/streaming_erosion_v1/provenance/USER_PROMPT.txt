1. 科学依据和本轮允许借鉴的 Bajd & Serša (2013) 思想
============================================================

Bajd & Serša (2013) 的 clot model 中：
- fibrin bond degradation 可以有 deformation-dependent degradation rate；
- degradation 随 physical time 积分；
- mechanical flow deformation 可以促进 progressive bond degradation；
- bond degradation / connectivity loss 最终导致 fragment release。

本轮只借鉴：
    flow-induced deformation
        ->
    time-dependent progressive damage
        ->
    connectivity loss if D eventually reaches 1

不要直接复制论文中的：
- coarse-grained RBC particle model
- Kelvin-Voigt bond parameters
- spatial corrosion term
- alpha / beta numerical values
- epsilon > 2 rupture threshold
- Stokes drag fluid model

论文中的 corrosion parameters 是 phenomenological 且缺乏充分实验标定，
因此本轮所有 erosion parameters 必须明确标记为 DEVELOPMENT / UNCALIBRATED PLACEHOLDERS。

4. STREAMING_EROSION v1 damage law
============================================================

定义 bond tensile strain：

stretch_ij =
    |x_j - x_i| / |xi_ij|

epsilon_plus_ij =
    max(stretch_ij - 1, 0)

只使用 tensile part。
compression 本轮不直接产生 erosion damage。

第一版 rate law：

rate_ij =
    C_t_s_inv
    * max(
        epsilon_plus_ij / epsilon_ref
        - threshold_ratio,
        0
      ) ** m_t

damage update：

D_new =
    min(
        1,
        D_old + erosion_exposure_step_s * rate
    )

要求：
- irreversible；
- D in [0,1]；
- D_break = 1；
- active bond iff D < 1；
- integrity g = 1 - D；
- damaged bond 继续通过现有 integrity softening 进入 PD mechanics；
- D=1 才真正失去 connectivity。

不要把现有 fracture coupon critical_J 或 Gc_demo 直接用于这个 erosion law。
本轮必须明确说明：
Gc coupon calibration 不等于 streaming erosion calibration。

即本轮只测试 mean streaming。

不要使用 cyclic stretch amplitude。

每一个 erosion macro step：

1. 固定当前 D；
2. 在 mean field 下积分 mechanics；
3. 让系统经过固定的 mechanical relaxation window；
4. 在 relaxation window 最后部分检查 clot 是否接近准稳态；
5. 从准稳态 configuration 计算 epsilon_plus；
6. 用 erosion_exposure_step_s 更新 D；
7. 更新 integrity / shape / topology；
8. 进入下一 slow erosion step。

mechanical relaxation duration 必须是固定配置，
且不能随着 erosion_exposure_step_s 改变。

至少记录：

- kinetic energy；

- mean epsilon_plus。
