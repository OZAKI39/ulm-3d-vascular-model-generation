1. 本轮唯一目标
============================================================

建立并验证一个正式、成熟的
variational-inequality stationary solver candidate。

主方法：

    PETSc SNESVINEWTONRSLS

即：

    reduced-space Newton
    active-set solver
    for box-constrained variational inequalities.

目标不是：

    修改 fracture model

不是：

    改善物理结果

而是回答：

    PETSc RSLS 是否能够自动识别 phase bounds /
    active set，并恢复已知高精度 C5 stationary roots？

特别重要：

正式 solver 不允许预先知道：

    active bonds = [4488, 5059]

这些 ID 只能作为事后验证 oracle。

RSLS 官方算法核心：

- variables on bounds with correct residual sign
  are treated as inactive/fixed;
- their Jacobian rows/columns are removed;
- Newton is solved on the remaining reduced space;
- a line search updates the active/free variables.

7. PETSc VI residual
============================================================

    current normalized free-particle
    force residual

保持现有 sign convention。

phase part：

优先直接使用当前正式：

    q_scaled =
      q / max(Psi_plus, Yc)

因为：

    s = lower
    q_scaled >= 0

interior：

    q_scaled = 0

upper：

    q_scaled <= 0

这与 PETSc VI lower/upper sign convention
必须逐项核对。

新增 scalar tests 明确验证：

PETSc lower-bound semantics
与当前 AT1 KKT semantics 一致。

“试到能收敛为止”。
