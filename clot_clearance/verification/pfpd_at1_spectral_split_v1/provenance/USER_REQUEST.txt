3. 本轮选定模型
============================================================

当前仍使用：

    Saint-Venant–Kirchhoff

Green-Lagrange strain：

    E = 0.5 * (F.T @ F - I)

对称 eigen-decomposition：

    E = Q diag(e_a) Q.T

Macaulay brackets：

    <x>_+ = max(x,0)
    <x>_- = min(x,0)

定义：

    E_plus =
        Q diag(<e_a>_+) Q.T

    E_minus =
        Q diag(<e_a>_-) Q.T

并定义：

    trE_plus  = max(tr(E),0)
    trE_minus = min(tr(E),0)

SVK energy split：

    Psi_plus =
        0.5 * lambda * trE_plus**2
        + mu * trace(E_plus @ E_plus)

    Psi_minus =
        0.5 * lambda * trE_minus**2
        + mu * trace(E_minus @ E_minus)

必须满足：

    Psi_plus + Psi_minus
        = Psi0_SVK

到 numerical tolerance。

Second PK split：

    S_plus =
        lambda * trE_plus * I
        + 2*mu*E_plus

    S_minus =
        lambda * trE_minus * I
        + 2*mu*E_minus

必须满足：

    S_plus + S_minus
        = S0_SVK

intact state s=0：

    g(0)=1

所以：

    Psi(s=0)
      =
      Psi_plus + Psi_minus
      =
      Psi0

    S(s=0)
      =
      S_plus + S_minus
      =
      S0

因此 intact mechanics 理论上必须保持不变。
