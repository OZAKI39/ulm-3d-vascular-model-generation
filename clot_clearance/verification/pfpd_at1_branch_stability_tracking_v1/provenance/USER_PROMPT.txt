6. 定义 stationary branch state
============================================================

对于每个 prescribed engineering strain epsilon：

求状态：

    z(epsilon) =
        [x_free, s]

满足：

A. mechanical equilibrium

    force_free ≈ 0

B. phase KKT

定义与上一轮完全一致的 projected residual：

    r_s =
      s - clip(
            s - q_scaled,
            s_lower,
            sc
          )

其中：

    q =
      dPi/ds

且：

    s_lower

必须来自：

    previous accepted continuation load state

不是：

    同一 load 内部 stagger iteration
    已经增长后的 phase。

============================================================
7. Stationary branch solver
============================================================

本轮不要使用“energy minimum solver”
作为 branch tracker。

原因：

失稳后 stationary saddle 仍可能存在，
minimizer 会主动离开它。

建立诊断 branch solver：

    solve_stationary_branch_state(...)

使用：

    scipy.optimize.least_squares

求：

    R(z) =
      [
        scaled force residual,
        scaled projected phase KKT residual
      ] = 0

初始值：

    previous load branch state
    +
    simple displacement predictor

phase predictor 默认：

    previous s

禁止提前增加 phase。

如果需要更好 predictor：

只允许 secant predictor based on
two previous stationary states。

不要实现 branch switching。

9. Branch solve acceptance
============================================================

- least_squares converged
- finite values
- force residual <= predeclared tolerance
- projected phase KKT <= predeclared tolerance
- phase bounds satisfied
- irreversibility satisfied
- max(s) < sc
- pure-tension domain valid
- fixed boundary exact

才可接受。

Hessian negative
不影响“stationary branch state”
的接受。

这是本轮重点：

    stationary state
    != stable state

因此允许保存：

    STATIONARY_UNSTABLE

16. 定义 stability classification
============================================================

    OR active-set nonsmoothness prevents classification

不要用：
    solver convergence
代替 stability。
