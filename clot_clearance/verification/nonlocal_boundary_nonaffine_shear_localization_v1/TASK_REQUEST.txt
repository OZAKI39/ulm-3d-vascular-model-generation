============================================================
5. INDEPENDENT CLOSED-FORM SVK REFERENCE
============================================================

For lambda = 0:

    C = F^T F

    E = 0.5 (C - I)

which gives:

    E =
    [[0,   0,   k/2],
     [0,   0,   0  ],
     [k/2, 0, k^2/2]]

Since:

    S = 2 mu E

the exact first Piola stress is:

    P =
    mu *
    [[k^2, 0, k + k^3],
     [0,   0, 0      ],
     [k,   0, k^2    ]]

Implement this independently
from the general constitutive implementation.

The exact energy density is:

    W =
    mu/2 * k^2
      +
    mu/4 * k^4

Verify independently.

6. EXACT LOCAL BODY FORCE
============================================================

Let:

    k_prime
      =
    2 beta_s / L

Because the field depends only on Z:

    Div P_i
      =
    d P_iZ / dZ

Thus:

    Div P_x
      =
    mu (1 + 3 k^2) k_prime

    Div P_y
      =
    0

    Div P_z
      =
    2 mu k k_prime

The local manufactured body force is:

    b_local
      =
    -Div P

therefore:

    b_x
      =
    -mu (1 + 3 k^2) k_prime

    b_y
      =
    0

    b_z
      =
    -2 mu k k_prime

Save exact formulas and sampled values in:

    NONAFFINE_SHEAR_EXACT_REFERENCE.json
