# 三、P0：原生LPS加权体积与原子身份审计

## 3.1 本轮最重要的代码问题

当前原生LPS使用参考加权体积：

`wvolume[i]`

来计算：

- 非局部膨胀量theta。
- 体积弹性响应。
- 剪切相关力项。
- LPS储能和内力。

静态源码检查发现：

`wvolume`、`theta` 和 `winv` 等内部数组以LAMMPS本地atom index为索引。

其中：

- wvolume只在特定条件下重建。
- 正常执行会前向通信到ghost。
- 当前尚未确认它是否随原子排序、跨MPI迁移和restart正确保持与atom ID的关系。

LAMMPS默认可能每1000步进行一次空间排序。

目前生产输入中：

`atom_modify map array`

并不等于关闭空间排序。

因此必须检查：

**相同atom ID是否始终对应同一个参考加权体积m。**

不能仅凭代码中存在`forward_comm`就认为它已经正确处理本地原子重排。

同时，不要把“断键后不重新计算原始参考m”直接判为bug。

当前PVCE已经明确使用完整初始参考邻域的固定m约定。若原生求解器采用同样约定，断键之后保留参考m可以是预期设计。

真正需要排除的是原子身份错配，而不是为了断裂改变原有参考归一化。

## 3.2 先做纯源码审计

追踪：

1. wvolume何时分配。
2. wvolume何时初始化。
3. wvolume何时重新计算。
4. wvolume_setup何时复位。
5. Atom::sort是否移动对应内部状态。
6. MPI exchange是否迁移这些内部状态。
7. ghost数组如何更新。
8. 原生数组扩容后是否保持正确状态。
9. restart是否保存或恢复参考m。
10. 断键和邻居表更新后是否错误改变m定义。

输出每条路径的具体文件、函数和代码行。

必须明确区分：

- `SORT_IDENTITY`
- `MPI_MIGRATION_IDENTITY`
- `GHOST_COMMUNICATION`
- `ARRAY_GROWTH`
- `RESTART_IDENTITY`
- `REFERENCE_M_AFTER_BREAK`

若已有机制保证某一项安全，应给出实际证据并标记通过，而不是为了完成任务强行修改源码。

## 3.3 最小原生复现

构建一个很小的三维非均匀邻域LPS试样。

试样必须同时有：

- 内部材料点。
- 自由表面点。
- 角点。
- 不同参考邻居数量。
- 明显不同的真实参考m。

使用完全相同的原始参考点与键。

先独立按参考atom ID计算：

`m_reference_by_atom_id`

保留：

- 原始参考键。
- 各键初始长度。
- 各键体积积分权重。
- 参考节点体积。
- 原始atom ID。

不得以当前LAMMPS错误数组本身作为唯一参考。

执行必要的三个状态检查：

### T0：初始化

在尚无自然断键时比较：

- 原生m。
- 独立参考m。
- theta。
- 原生力。
- 独立LPS力。
- 独立储能。

### T1：强制原子重排

在隔离诊断输入中，采用可以真实触发Atom::sort的设置。

例如使用较短排序频率，并记录是否真的发生了非恒等排列。

比较同一个atom ID在排序前后的m。

不能只设置`atom_modify sort 1`就假定发生了排序；必须记录实际原子排列变化。

### T2：两MPI真实迁移

采用两个MPI进程和受控小幅运动，让部分真实atom跨处理器拥有域边界。

在不引入自然断裂的条件下检查迁移前后：

- atom ID。
- 归属rank。
- 参考m。
- theta。
- 原生节点力。
- 独立力。
- 储能。

坐标存在真实变化时，必须在相同物理坐标下比较参考计算与原生计算。

不能将不同坐标下的正常力变化误判为bug。

最后，检查该测试是否真实触发了MPI迁移。

必要时包含一次极小restart恢复检查，但不得展开大量restart循环。

## 3.4 数值验收

验收门槛必须在修复前冻结。

参考m是固定参考量，因此在同一参考模型下：

`m_i(t) = m_i(reference)`

对于所有仍存在的atom ID都应保持符合浮点误差的身份一致性，除非源码原本声明了另一种明确的更新模型。

力、theta与能量应与独立计算一致。

比较时同时报告：

- 最大绝对误差。
- 有明确定义参考尺度的相对误差。
- 出错节点数量。
- 错误是否集中于表面和角点。
- 错误第一次出现的排序或迁移事件。
- 是否存在ghost状态错位。

不得通过任意大的隐藏分母下限掩盖接近零的力或m。

# 五、P1：断键当步的theta与拓扑更新时间层

## 5.1 已发现的源码顺序

当前原生LPS大致执行：

1. 计算当前存活键对应的dilatation。
2. 进入bond force loop。
3. 判断键是否超过`s00`。
4. 对超过阈值的键调用`process_broken`。
5. 继续计算其他键的弹性力。

因此，一些仍然存活的键在断键同一步中，可能使用包含刚断开键影响的theta。

这是一项值得检查的时间层一致性问题。

但它**可能属于显式断裂算法的离散更新策略**。

不能仅凭计算顺序不同于另一种算法就宣布存在严重bug。

## 5.2 只进行一个最小断键试样

使用已有LPS小型试样生成器。

保持：

- G=940Pa。
- K=33333.333333Pa。
- s00=0.15。
- alpha=0。
- dx=50µm。
- horizon=150.5µm。

构建一个能通过受控变形触发少量断键的独立小试样。

只需要记录：

- 首次断键前接受状态。
- 首次断键时实际坐标。
- 当前存活键拓扑。
- 原生节点力。
- 当前theta。
- 断键事件及真实atom IDs。
- 同一坐标下、断后固定拓扑重新计算的节点力与theta。

重点比较：

`F_native_at_break`

和：

`F_recomputed_on_postbreak_topology`

记录：

- 最大节点力差。
- 力差空间分布。
- 键失效是否改变其他邻居力。
- 动量及力矩平衡。
- 本步能量变化。
- 是否出现明显非物理冲量。

注意不能将正常的断裂能释放全部当成数值错误。

需要区分由实际拓扑变化引起的物理力重新分配，与使用不一致时间层造成的算法误差。

## 5.3 何时允许修复

只有在以下条件成立时，才修改原生算法：

- 存在可重复的断键同一步内力不一致。
- 误差超出预注册的数值尺度。
- 该不一致不能用当前显式算法的既定时间离散解释。
- 可以提出明确的修复定义。
- 修复不改变材料失效准则。

可评估一种两阶段更新方法：

1. 根据当前接受状态确定待断键集合。
2. 同步提交当前时间层的断键。
3. 在更新后的存活键拓扑上重新计算theta。
4. 在同一更新拓扑上计算弹性内力。

但是，这只是候选修复方向。

实际实现必须检查：

- LAMMPS bond list的数据结构。
- MPI跨域断键一致性。
- `process_broken`调用次数。
- bond history。
- special bonds/contact更新。
- 力与能量定义。
- restart及事件日志。
- 时间积分器与断裂更新时刻。

不能因为方案看起来更直观，就忽略它可能改变当前显式算法的数值含义。

若只有小的、可解释的一阶时间离散误差，记录：

`FRACTURE_TIME_LAYER = EXPLICIT_SCHEME_LIMITATION`

不修改源码。

若确认实质bug，则只进行一次最小修复和必要复验。

不开展新的断裂机制研究。

## 6.1 当前确认的语义问题

现有部分统计使用：

`counts[counts<=2]`

`(counts>=3).sum()`

`counts.max()`

没有限制为游离组件。

因此这些指标可能包含仍附着的主体或附着小组件。

但是，某些历史统计本来就有意使用“全部组件”口径。

所以不能直接把所有旧字段统一改成游离统计，更不能静默改写旧结果。

首先追踪这些字段的历史定义及下游使用。

## 6.2 建立清楚的新指标

保留需要维持历史兼容性的字段和数值。

新增或明确以下统计：

- `all_tiny_component_mass_fraction`
- `detached_tiny_component_mass_fraction`
- `attached_tiny_component_mass_fraction`
- `detached_component_count`
- `resolved_detached_component_count`
- `largest_detached_nodes`
- `largest_detached_mass_fraction`
- `largest_attached_component_mass_fraction`

如果历史`largest_free_fraction`实际表示全部组件最大值，应明确标为legacy语义，不能在文档中继续解释为最大游离组件。

真正的最大游离组件必须由：

`free = ~attached`

筛选后计算。

类似地，200µm与300µm等效球径门槛继续只对真正的游离组件计算。

注意：

1–2个材料点仍属于数值未解析碎屑，不能因为统计修复就提升为有真实生物物理意义的小微栓。

## 6.3 最小单元测试

只需构造少量人工连通图，检查：

- 全部节点仍附着。
- 一个大附着主体加几个游离单节点。

- 同时存在附着小组件与游离小组件。
- 多个界面键断裂但主体仍连接壁面。

验证：

- 分量大小。
- 附着身份。
- 游离数量。
- 脱落质量。
- 尺寸门槛。
- 总材料点数量守恒。

修复后输出旧口径与新口径的逐项对照。
