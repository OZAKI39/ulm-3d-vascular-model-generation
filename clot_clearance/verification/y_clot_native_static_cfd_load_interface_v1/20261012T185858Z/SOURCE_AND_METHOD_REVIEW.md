# 原生静态 CFD 接口源码审查

本轮以服务器锁定源码和实际 `/proc/self/maps` 为准。诊断库为最终 owner/wvolume 双修复库，沿用完整 V3 C1 的同一 SHA；原生产库保留。本任务只新增 analysis/static_cfd_v1 Python 适配和审查代码，没有新增、修改或重编译原生 C++。

## 外力顺序与真实身份

`provenance/bond_bpm_peri.cpp` 355–464 行把 LPS 相互作用累积为节点力密度，原 `lammps_writer.py::force_conversion()` 的 si_force 在 post_force 阶段以 d_vfrac 转换为 N。`fix_external.cpp::post_force` 调用 Python 回调后仅对 i<nlocal、匹配 group 的拥有节点累加外力；MIN_POST_FORCE 也有接口，但本轮不调用 native minimize。原生不完整 PE 不作为目标函数。

本轮实际保存的 in.lammps 先注册 si_force，再注册 nativewall，最后 cfdload。回调以传入的真实 tags 查询完整映射，清空 callback 缓冲，再将已积分的 N 向量填入 owned 行。不对 ghost 添加、不乘第二次体积、不取代方向、不重映射。CFD 力只作用于原 580 个 ID。1347 未直接受载材料点和 1561 锚点保持外载为零。

## 约束、参考态、原生力评价

锚点的 4683 个坐标自由度保持原值；未注册 nve 或任何位移/速度积分 fix。没有清零锚点力的 setforce。原生锚点力保留为内部相互作用，约束反力由其相反数逐点恢复。此方法独立于合外力，不能把负外力直接定义成验收反力。

只在原始构型初始化参考 r0/m；之后使用 scatter x + run 1 pre no post no 评价力，计数步不代表物理时间推进。原显式 theta 顺序不变，本轮无断键，完整当前膨胀率可与独立梯度核对。2 MPI 下在参考坐标执行 balance 改变域边界，检验真实拥有权迁移；因坐标仍为参考值，该命令初始化不会引入变形后的新参考长度。

实际冻结参数为 G=940 Pa、K=100000/3 Pa、rho=1000 kg/m³、dx=50 µm、horizon=150.5 µm、原 bulk/interface s00 和 alpha=0。原键仍允许按阈值断裂，但所有独立优化试算及原生评价前检查真实伸长；超临界立即停止。原生双端 typed bond 身份、个数和度数逐状态检查。未把锚点间的 type 3 数值键误称为血栓本体。

## 静态方法与接触

复用 `macro_lab_v1.Energy` / `energy.cpp` 的完整 LPS U 和梯度。只对材料自由度优化 `Pi = U - ΣF·u`。优化变量及目标做数值尺度转换，物理单位和载荷倍率不变。L-BFGS-B 的目标微小变化不是验收条件；验收使用冻结的原生自由力、全局力/力矩、10 个接受迭代的位移/储能平台及独立梯度一致性。

原生 pair bpm/peri、1dx 候选和 Y 管壁接触回调保留。参考最小非键距离 70.7107 µm，壁净距 28.4499 µm；优化每次试算验证距离下界仍大于 pair 的 50 µm 和墙有效半径 20 µm。在被证明接触能为零的区域才能使用上述无接触独立能量；一旦触及可能激活的区域即停止，不偷偷忽略接触力。原生候选另外读取实际 contact neighbor 和墙力。无阻尼动力松弛、无碎片阻力、无流体重复作用。

## 力矩与能量语义

x0 固定取原映射元数据。参考构型外力矩是原映射守恒口径；当前坐标外力矩是有限位移中央内力的物理平衡口径，两者及其差分别保存，不更换参考点。反力在始终固定的锚点位置取矩。

常量 dead load 的外载势是 -F·u，F·u 是从零到该位移的常力功。半个 F·u 只用作小变形线性平衡的诊断；未模拟另一个升载过程。独立能量梯度用两个小扰动步长检查，路径积分检查内部保守功与 ΔU。native PE×volume 只披露为不完整诊断量，不用于求解/认证储能。Gc 未标定，无新的断裂耗能。
