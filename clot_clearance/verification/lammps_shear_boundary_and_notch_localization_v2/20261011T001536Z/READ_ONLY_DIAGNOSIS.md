# 新计算前的只读诊断与唯一改动选择

数据来自上轮服务器实际目录，已对实际输入、逐步history、几何、事件和关键状态核对85个来源身份。生产二进制和独立能量库匹配锁定哈希。

M2原拟合不变：名义G=781.247 Pa，名义应力/ROI对称剪切应变得到759.176 Pa。ROI/名义应变斜率约1.029，改应变口径不能消除偏差。M1的E、ν推得903.941 Pa，不能将这三组边界下测量拼成一致材料常数。峰值实际F_xz=.010584、F_zx=-.002358，存在转动与非均匀变形。上下夹具x反力相对不平衡约3e-14；独立力回算与原反力相差约1.7e-21 N。当前受力面面积变化约1e-6相对量级；600µm的参考面包括节点半单元边缘，不能偷换成550µm点中心凸包面积。中央局部键virial应力代理约7.79 Pa而横截面名义值约6.27 Pa，提示中央应变与全截面平均应力混用的空间影响；该局部应力分配本身不唯一，不能据此宣布局部常数已认证。

M5首断实际有两条对称夹具角点键，参考中点(275,±275,350)µm。首断接受时刻夹具区域最大临界伸长利用率1.000050，缺口区0.869405。对应端点仅45–46个邻居，加权体积约完整支持的36%；缺口前缘至夹具过渡仅2.33个horizon。已独立重建预缺口交点裁剪，未发现不应保留的跨初始缺口键。旧数据没有首断前一步的完整坐标，所以以上明确是首断接受态，不伪称断前态。峰值时缺口区已有238条断键，而夹具区50条；不能把末态87%离面断裂简单全部归因于夹具首断。

在此证据基础上，仅选择M2P横向周期剪切和M5B夹持层内线性轴向位移两个算例。后者取消原夹持层轴向应变为零的台阶，同时保留原夹持层、自由内部、切向自由、中心距、加载幅度和时间。能否改善缺口主导由真实结果判定，不强制断裂面。先作零步几何/积分组/周期键检查，随后每例只运行一次正式计算。规则见ANALYSIS_PLAN.json，预算和停止条件见CASE_REGISTER.json。

接口核对使用锁定源码，并参考 https://docs.lammps.org/fix_move.html 和 https://docs.lammps.org/bond_bpm_peri.html；没有更新原生库或将在线默认值替换项目参数。
