============================================================
5. VARIATION OF NODAL F
============================================================

Because:

    g_ij

depends only on reference geometry,

the exact variation is:

    delta F_i
      =
    sum_j
      (delta x_j - delta x_i)
      outer
      g_ij.

This linear variation
must be the basis of the force derivation.

Do not finite-difference F
inside the force implementation.

============================================================
6. BOND-ASSOCIATED KINEMATICS
============================================================

Retain the verified diagnostic construction:

For physical unordered bond:

    b = (i,j)

define:

    xi =
        X_j - X_i

    r2 =
        xi dot xi

    eta =
        x_j - x_i

    Favg =
        0.5 * (F_i + F_j)

    c =
        eta - Favg xi

    Ftilde_b =
        Favg
        +
        outer(c, xi) / r2

This formula passed
the PD2 quadratic diagnostic.

Do not replace it.

10. MATRIX-FREE ADJOINT FORCE DERIVATION
============================================================

Do NOT build an explicit:

    dFtilde / dx

fourth-order tensor for every bond/node.

Use an adjoint accumulation.

For each bond b=(i,j):

    R_b =
      I - n_b outer n_b

    P_b =
      dPsi0/dFtilde_b

    A_b =
      0.5 * m_b * P_b * R_b

    t_b =
      m_b * (P_b xi_b) / |xi_b|^2

The bond variation is:

    delta U_b
      =
    A_b : delta F_i
      +
    A_b : delta F_j
      +
    t_b dot (
        delta x_j - delta x_i
      ).

This identity must be derived in the report,
not merely coded.

============================================================
11. TWO-STAGE FORCE ACCUMULATION
============================================================

Use an O(number_of_bonds + number_of_directed_neighbors)
algorithm.

------------------------------------------------------------
STAGE A — bond accumulation
------------------------------------------------------------

Initialize nodal conjugates:

    G_i = 0

and energy gradient:

    gradU_i = 0.

For each physical bond b=(i,j):

    G_i += A_b
    G_j += A_b

    gradU_j += t_b
    gradU_i -= t_b

------------------------------------------------------------
STAGE B — adjoint of nodal gradient
------------------------------------------------------------

For each directed family entry:

    i -> k

compute:

    q_ik =
      G_i * g_ik

where:

    g_ik

is the PD2 gradient-weight vector.

Because:

    G_i :
    [
      (delta x_k - delta x_i)
      outer
      g_ik
    ]

    =
    (G_i g_ik)
      dot
    (delta x_k - delta x_i),

accumulate:

    gradU_k += q_ik
    gradU_i -= q_ik.

Finally:

    force_i =
      -gradU_i.

Do NOT loop over
all neighbors of i and j
inside every bond.

That would create unnecessary
O(B * family_size) cost.
