3. 核心科学问题
============================================================

当前模型基本是：

    g = 1 - D

并且 g 同时进入：

    material softening
    K
    F reconstruction

所以 very small D 也立即改变 kinematic reconstruction。

PFPD 论文则分开：

ENERGETIC DEGRADATION:

    g(s) = (1 - s)^2

KINEMATIC DEGRADATION:

    h(s) = 1                      if s <= s_c

    h(s) = ((1-s)/(1-s_c))^2     if s > s_c

论文典型 numerical examples 使用：

    s_c = 0.95

因此在：

    s << 0.95

阶段：

    energetic response may degrade

但：

    kinematic reconstruction should remain intact
    because h = 1

本轮第一核心假设检验：

    当前历史 erosion 状态的最大 bond D
    约为 3.3e-3，远低于 0.95。

如果仅采用“energetic degradation 与 kinematic degradation 分离”
这一论文原则，

那么 early damage 不应该改变 K/F reconstruction。

检查这是否能消除当前已经发现的
reconstruction-driven energy anomaly。

注意：

这只是 compatibility hypothesis test。

当前 D 不能直接声称等价于 PFPD 的 s。

5. 必须首先审计论文内部的 damage-law 一致性
============================================================

这是一个 HARD GATE。

当前 v1 论文写出：

    gamma_c(s) = s                (AT1)
    g(s) = (1-s)^2

并给出 stationary condition：

    -2(1-s) Psi_0
    + Gc/(c0 delta)
    = 0

定义：

    Yc = Gc/(2 c0 delta)

从这组三个公式代数上得到：

    s = 1 - Yc/Psi_0

仅在 Psi_0 >= Yc 时得到内部解；
低于阈值时 constrained minimum 应在 s = 0。

但论文后面 Eq. 3.25 写成：

    s = Y_history / (Y_history + Yc)

请不要自行决定哪个公式正确。

这个形式更接近：

    gamma(s) = s^2

时的 stationary relation，
而不是前文声明的 gamma(s)=s。

7.2 kernel normalization
------------------------------------------------------------

论文定义：

    omega0(X)
      = integral_H omega dV'

离散实现：

    omega0_i
      = sum_j omega_ij V_j

boundary particle 的 omega0 不等于 interior。

averaged bond kernel：

    wbar_ij =
      0.5 * (
        omega_ij / omega0_i
        +
        omega_ji / omega0_j
      )

使用论文 Eq. 2.13。

不要把现有 unnormalized bond weight
直接冒充 Eq. 2.13 的 wbar。
