3. MAKE CYCLIC DAMAGE ACTUALLY CONTROL BOND INTEGRITY
====================================================================

Audit the current cyclic-damage implementation.

For every PD bond ij maintain:

    D_ij in [0,1]

Define bond integrity:

    g_ij = max(0, 1 - D_ij)

The NOSB-PD pair interaction must be weakened consistently by g_ij.

Introduce a configurable failure threshold:

    D_break

For example:

    if D_ij >= D_break:
        bond_active_ij = false
        g_ij = 0

The default physical convention should preferably remain D_break = 1.

For the intentionally aggressive qualitative demo a separate configured value
may be used if necessary, but it MUST be reported.

Once a bond breaks:

    it must never heal.

Verify numerically:

    active_bond_count decreases,
    broken_bond_count increases,
    broken_bond_fraction > 0.

The new demo is not successful merely because particle damage changes color.

4. DISTINGUISH DAMAGE, EROSION, AND FRAGMENTATION
====================================================================

Implement three separate diagnostics.

A) DAMAGE

    local loss of PD bond integrity

B) EROSION / DETACHMENT

A particle is considered part of "attached clot" if it is connected by active
PD bonds to at least one anchored/base particle.

After every macro damage update perform a graph search beginning from all
FIXED_BASE / anchor particles.

Particles reachable from the base through active bonds are:

    attached_clot

Particles no longer reachable from the base are:

    detached_material

Define:

    attached_volume_fraction
    detached_volume_fraction

This detached-volume metric is the preferred first measure of
streaming-induced clot clearance.

C) FRAGMENTATION

Perform connected-component analysis of the active PD graph.

Each disconnected cluster receives:

    fragment_id

Report:

    total_components
    attached_components
    detached_components
    largest_component_volume
    detached_fragment_volumes

Damage alone is NOT fragmentation.

6. ADD POST-DETACHMENT HYDRODYNAMIC TRANSPORT
====================================================================

The present model applies a prescribed one-way streaming/background-flow field.

Use that existing field to continue loading free fragments.

Define:

    u_f(x,t) =
        u_background(x)
        +
        u_streaming(x,t)

For each mobile PD particle obtain the local prescribed fluid velocity.

Implement a configurable particle-centered hydrodynamic coupling inspired by
the fluid-to-solid forcing used in CFD-PD immersed formulations.

For the verification prototype use a clearly documented relaxation form:

    a_h,i =
        (u_f(x_i,t) - v_i) / tau_h

or equivalently

    f_h,i =
        rho_s * V_i / tau_h
        * (u_f(x_i,t) - v_i)

where:

    tau_h

is a configurable hydrodynamic relaxation time.

IMPORTANT:

This is a verification-level surrogate for post-detachment transport.
Do NOT claim that it is the final physical fluid-solid coupling law.

Put tau_h in configuration.

The architecture must allow replacing this surrogate later with the full
CFD-to-PD hydrodynamic force formulation.

Apply this hydrodynamic transport only to mobile particles.

FIXED_BASE particles must remain fixed.

7. DYNAMICALLY UPDATE WHICH PARTICLES ARE FLUID EXPOSED
====================================================================

The current code must not assume that only the ORIGINAL upper surface receives
fluid loading.

After fracture, newly created surfaces are exposed to the fluid.

Implement a simple dynamic surface-particle detector.

A reasonable first implementation is based on neighborhood deficiency:

    compare current active-neighbor count / weighted neighborhood volume
    with the intact bulk value.

A particle whose neighborhood is sufficiently deficient is considered
fluid-exposed.

Exclude FIXED_BASE particles.

Store:

    is_surface_particle

at every saved state.

The exact surface criterion must be configurable and documented.

This is important because newly formed fragments must continue to interact with
the prescribed fluid field.
