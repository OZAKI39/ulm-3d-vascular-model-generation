1. PHYSICAL MODEL TO IMPLEMENT
============================================================

The clot should be represented by a Lagrangian peridynamic particle cloud.

Preferred formulation:

    stabilized non-ordinary state-based peridynamics (NOSB-PD)

for a nearly incompressible hyperelastic solid.

The prototype should support a simple compressible Neo-Hookean material first.
The design must allow replacing it later with a first-order Ogden clot model.

Do NOT use bond-based PD as the final clot formulation because the blood clot is
nearly incompressible and bond-based PD has restrictive Poisson-ratio behavior.

A temporary simpler PD formulation is acceptable only for an intermediate unit
test, but the final demo in this task should use correspondence/NOSB-PD if
reasonably feasible.

============================================================
2. NOSB-PD CORE
============================================================

Represent the clot as particles i with:

    reference position X_i
    current position x_i
    velocity v_i
    particle volume V_i
    density rho_i
    damage D_i

Each particle interacts with neighbors within a horizon:

    delta ~= 3 * particle_spacing

Implement a neighbor list.

For each particle i, construct the shape tensor

    K_i = sum_j w_ij * (xi_ij tensor xi_ij) * V_j

where

    xi_ij = X_j - X_i

and compute a nonlocal deformation gradient

    F_i =
      [sum_j w_ij * (eta_ij tensor xi_ij) * V_j] * inverse(K_i)

where

    eta_ij = x_j - x_i.

Use a compressible or nearly incompressible Neo-Hookean constitutive model
to calculate the first Piola-Kirchhoff stress P_i.

Implement correspondence force states consistent with NOSB-PD, e.g.

    T_ij = w_ij * P_i * inverse(K_i) * xi_ij

and assemble internal force from the contribution of particle i and j.

Verify pair interactions carefully and document all sign conventions.

Include a stabilization mechanism to suppress correspondence zero-energy modes.

If a full published stabilization is too large for the first prototype,
implement a clearly isolated stabilization term behind a configuration switch
and document that it is provisional.

Do not silently ignore zero-energy mode stability.

============================================================
6. DAMAGE MODEL
============================================================

Implement TWO damage modes.

------------------------------------------------------------
Mode 1: instantaneous_stretch
------------------------------------------------------------

This is primarily a mechanical verification mode.

For every bond ij define stretch

    s_ij = |x_j - x_i| / |X_j - X_i|

Use two thresholds:

    s1
    s2

with an irreversible bond integrity variable mu_ij:

    mu_ij = 1                     if s < s1

    mu_ij decreases smoothly      if s1 <= s < s2

    mu_ij = 0                     if s >= s2

and enforce irreversibility:

    mu_ij(new) = min(mu_ij(old), mu_candidate)

Use mu_ij to weaken/remove bond interactions.

This mode should reproduce the qualitative behavior of progressive PD cohesive
failure.

------------------------------------------------------------
Mode 2: cyclic_accumulation
------------------------------------------------------------

This mode is the more relevant prototype for ultrasound-driven clot ablation.

Introduce a bond damage variable:

    D_ij in [0,1]

with:

    bond integrity = 1 - D_ij

Damage must depend on loading history.

Implement a simple empirical CYCLE-JUMP law such as:

    D_ij(N + DeltaN)
      =
    clamp[
        D_ij(N)
        +
        DeltaN * C_damage
        * <Q_ij / Q_ref - 1>^m_damage,
        0,
        1
    ]

where Q_ij is configurable and can initially be one of:

    bond stretch amplitude
    bond strain-energy amplitude
    cycle dissipated energy proxy

and

    <x> = max(x,0).

IMPORTANT:
This law is only a placeholder research law.
It must NOT be presented as experimentally validated.

Put all parameters in the input file:

    C_damage
    m_damage
    Q_ref
    DeltaN

The goal is to test whether repeated localized streaming loading can produce:

    progressive damage
    surface erosion-like loss of connectivity
    eventual fragment formation.

7. CYCLE JUMPING
============================================================

Do NOT explicitly simulate hundreds of thousands of MHz ultrasound cycles.

Implement two time scales:

FAST SCALE:
    resolve a small number of representative load cycles
    or use a supplied cycle amplitude.

SLOW SCALE:
    advance damage by DeltaN cycles.

Pseudo-algorithm:

    for macro_step in damage_steps:

        apply representative streaming cycle

        compute:
            stretch amplitude
            strain-energy amplitude
            or selected damage driver

        update damage by DeltaN cycles

        update bond integrity

        update particle connectivity

        write output

This is essential for keeping the prototype computationally manageable.
