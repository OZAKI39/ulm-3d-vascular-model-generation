2. REPLACE ARBITRARY Q_ref FAILURE SCALING WITH AN ENERGY-CALIBRATED LAYER
====================================================================

The current cyclic law is approximately:

    DeltaD =
        DeltaN * C_damage
        * max(Q / Q_ref - 1, 0)^m

and the previous fragmentation demo used an aggressively reduced Q_ref.

Keep the legacy law for regression, but add a new damage mode:

    energy_regularized_cyclic

The new mode should use a physically interpretable bond-level or particle-level
work/energy driver.

Suggested structure:

    W_cycle_ij

or

    DeltaPsi_ij

representing a non-negative cyclic mechanical work/strain-energy amplitude for
bond ij.

Damage may have a generic form such as:

    DeltaD_ij =
        DeltaN
        * C_E
        * <W_cycle_ij / Wcrit_ij - 1>^m_E

but Wcrit MUST NOT simply be a constant copied across discretizations.

Instead introduce an energy calibration procedure described below.

Do not silently invent a closed-form Gc-to-bond formula unless it is derived
and documented.

3. ADD A NUMERICAL FRACTURE-ENERGY CALIBRATION COUPON
====================================================================

Create a separate calibration problem:

    pd_fracture_energy_coupon

Purpose:

For each particle spacing / horizon configuration, calibrate the damage energy
scale so that creation of a prescribed macroscopic crack consumes an
approximately mesh-independent target energy:

    Gc_demo [J/m^2]

Gc_demo is a USER INPUT.

It is a demonstration parameter unless the user later supplies an experimentally
measured clot fracture energy.

Recommended calibration geometry:

    rectangular PD coupon
    pre-notch or symmetric weak plane
    displacement-controlled opening

Measure:

    external work
    stored elastic energy
    dissipated damage energy
    newly created crack area

Estimate:

    Gc_measured =
        dissipated fracture work / created crack area

Implement an automatic scalar calibration loop for the damage energy parameter
so that:

    |Gc_measured - Gc_demo| / Gc_demo

falls below a configurable tolerance, e.g. 5-10%.

IMPORTANT:

The objective is NOT to make crack force curves identical at every resolution.

The objective is to make the ENERGY required to create macroscopic crack area
approximately resolution-consistent.

Save calibration results separately for each:

    particle_spacing
    horizon_ratio

Never reuse an energy parameter calibrated for one discretization on another
without explicit warning.

10. MAKE SYNTHETIC STREAMING FIELD INTERNALLY CONSISTENT
====================================================================

The current model can prescribe traction and velocity independently.

For the NEW development demo this is not acceptable as the default.

    StreamingFlowProvider

    u_f(x,t)
    p_f(x,t)
    grad_u_f(x,t)

    du_dt

Compute fluid Cauchy stress from ONE field:

    sigma_f =
        -p_f I
        + mu_f * (grad_u_f + grad_u_f^T)

    t_f = sigma_f * n

Use the SAME u_f for post-detachment transport.

Therefore:

    loading
and
    transport

must originate from the same field.

Keep legacy independent traction/velocity providers for regression only.
