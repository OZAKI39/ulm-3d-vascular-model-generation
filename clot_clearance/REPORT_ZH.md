# clot_clearance 直管流程验证报告

本次在 `/home/lzy/projects/clot_clearance` 中完成独立原型开发与运行。主流程为：**直管解析背景流 + 规定局部微流牵引 → 三维 NOSB-PD 血栓变形 → 循环损伤 → 连通分量识别 → VTK/统计/动画输出**。

主示例产生轻度损伤，**没有出现断键、碎片或血栓清除**。另一个人工张开测试验证了断裂和碎片编号。两者的数据、名称和可视化分开保存，不把人工测试当作流动造成的血栓碎裂。

## 工程与论文依据

已核查现有 svMultiPhysics 源码中的固体、FSI、材料和 VTK 支持，复用已有 Python/Numba/VTK 科学环境。只复制 BraVa 的 P1 梯度辅助文件到本项目 `vendor/`，保留原文件字节；其他物理模块均独立实现。原始论文及参考身份文件先复制后使用。

提供的论文是 Karmakar、Burgreen、Antaki 的 2026 年**吸栓** PD–CFD 研究（DOI 10.1016/j.apples.2026.100347）。其 NOSB-PD、不可逆键损伤和牵引表达式用于方法参考；原论文的双向 OpenFOAM 耦合、广义 Ogden 材料、导管吸入和壁面碰撞未在本次复现。论文不提供超声微泡循环疲劳定律。逐式对应见 [PAPER_READING.md](references/PAPER_READING.md)，全部近似见 [MODEL_ASSUMPTIONS.md](MODEL_ASSUMPTIONS.md)。

## 本次算例

| 项目 | 设置或实际结果 |
|---|---|
| 直管 | 长6 mm，半径1.25 mm；解析 Poiseuille 背景 |
| 灌注/流体 | 18 mL/min；ρ=1056 kg/m³，μ=0.00345312 Pa·s；沿用 BraVa 参数 |
| 背景流 | 平均速度61.1155 mm/s，Re≈46.7244，压降6.4831 Pa |
| 血栓 | 1.5×1.0×0.5 mm，384个体积粒子，底层96个固定 |
| 离散 | 间距0.125 mm，horizon=3.01倍间距，12,804条无向键 |
| 材料 | 可压缩 Neo-Hookean；G=1000 Pa，K=50000 Pa，ν≈0.49007；演示参数 |
| 稳定化 | 非仿射残差能量惩罚，α=3；临时选择，非论文式(10)逐项复现 |
| 局部载荷 | 高斯切向牵引标度140 Pa；振幅比0.9；叠加直管背景牵引 |
| 时间 | dt=2 μs；显式步长估计上限3.393 μs；500 Hz代表性机械载荷 |
| 循环计数 | 8个宏步，每步ΔN=1000；假设载波1 MHz，仅用作独立计数时钟 |
| 损伤 | C=2×10⁻⁵，m=2，Q_ref=0.014；未标定的经验定律 |

直管场没有求解血栓造成的堵塞或绕流。血栓底部是圆管内部的理想化平面支撑区域；固定参考表面、法向和面积用于一次单向载荷映射。本轮未调用远程 BraVa 队列，也未启动新的 BraVa CFD 或微泡生产批次。

## 主示例结果

依据 [SUMMARY.json](results/straight_pipe_demo/SUMMARY.json) 和原始 `states.npz`：

- 完成8个宏步、8,000个代表载波循环，记录运行约85.70 s。
- 最终平均粒子损伤 **0.0268121（2.68121%）**，最大粒子损伤 **0.0659395**。
- 损伤超过0.05的粒子占 **12.5%**；这与平均损伤是不同统计量。
- 最后保存时刻最大位移 **5.94614 μm**；这是保存宏步的位移统计，不是所有代表周期内的峰值。
- **断键比例0，连通分量1，最大碎片体积分数1，脱离底座体积分数0**。
- 底层位移误差0；所有积分子步最小J约 **0.988230**；最大记录加速度约970.24 m/s²，未触发数值保护。
- 末帧材料应变能约7.4566×10⁻¹¹ J，稳定化能约3.1555×10⁻¹¹ J。稳定化贡献不可忽略，不能据此宣称材料响应已收敛。

1 MHz计数对应N/f=0.008 s，而实际求解的低频机械代理时间为0.018 s（含一个预热周期）。这不是显式求解8,000个MHz周期，也不能把0.008 s解释为预测的溶栓时间。

## 已运行验证

[A–F验收记录](verification/ACCEPTANCE.json) 为PASS。以下控制是96粒子小算例，与主示例分开：

| 检查 | 实际证据 |
|---|---|
| A 无载荷 | 最大位移约1.36×10⁻¹³ μm；零损伤，1个连通分量 |
| B 小均匀载荷 | 位移约0.59784 μm；零损伤，固定底层严格保持 |
| C 局部强载荷 | 平均损伤约0.227487；上层损伤高于底层，最大位移约77.8802 μm |
| 更强载荷控制 | 将人工标度160→180 Pa后，平均损伤约0.306489，高于前一控制 |
| D 更多循环 | 同一运行内各宏步累计损伤不减；另有损伤算子级ΔN控制 |
| E 零损伤率/禁用 | 即使变形存在，所有键完整性保持1 |
| F 人工张开 | 上半部分规定张开0.625 mm，阈值1.01/1.02，得到两个各48粒子的分量；未删除粒子，非流动致裂结论 |

18项自动测试全部通过，还包括：仿射梯度恢复、刚体旋转客观性、力与力矩守恒、离散能量有限差分与力一致、非仿射稳定化、负J和退化shape tensor报错、不可逆损伤、原目录拒绝覆盖、压力牵引符号、几何面积映射、直管通量/无滑移及文件域外拒绝。

文件适配测试覆盖CSV、VTU、legacy VTK的线性速度/压力场，以及CSV/VTP直接牵引。实际文件驱动也完成了粒子推进：[IMPORT_AND_DT_CHECK.json](verification/IMPORT_AND_DT_CHECK.json)。

- 静态解析牵引与其CSV导入产生的最大位置差约 **9.76×10⁻¹⁹ m**。
- 直管VTU的速度/压力经过梯度→应力→牵引→粒子推进，已完成。
- 96粒子、2宏步的dt减半控制：位移相对L2差约 **6.36×10⁻⁵**，最大键完整性差约 **6.11×10⁻⁴**。

这些是实现与小算例一致性检查，不能证明网格/horizon无关、MHz动力学准确或局部物理精度。首次验收汇总因NumPy布尔值JSON序列化失败；已修复报告脚本并依据原始完成结果重新汇总，未修改或重算控制轨迹，原错误日志保留。

## 适用边界与下一步

当前只证明这个最小流程可运行。合成微流、代理频率、经验疲劳定律、稳定化系数均未作实验标定。没有Ogden材料、裂纹新表面受力、变形随动牵引、黏附脱层、碎片与流体输运或双向耦合。连通但失去三维支持的粒子簇会明确失败，禁止静默求伪逆或删除粒子。

最小下一步是接入**一份真实微泡解析CFD输出的速度/压力体网格或血栓表面牵引快照**，先验证SI单位、压力参考、法向、覆盖范围、梯度及总载荷，再用复制的JSON替换StreamingProvider。现有BraVa稳态背景场不包含声学微流，不能直接改名为微泡微流结果。

原文件保护及输出完整性结果见 [FINAL_QC.json](provenance/FINAL_QC.json)：保护清单内2,640个原文件哈希不变；27个VTK文件核对通过；MP4共108帧、12 fps、9 s，完整解码通过。PNG/PDF及动画末帧已经视觉检查；离线交互页的文件链接已核对，但当前环境没有浏览器引擎，未完成自动浏览器操作测试。原始结果身份和全部原文件SHA记录保持独立；这份新原型没有覆盖或发布为正式BraVa流场。
