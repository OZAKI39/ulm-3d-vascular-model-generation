============================================================
2. 正式数学模型
============================================================

求解：

steady incompressible Newtonian Stokes

强形式：

-div(sigma) = 0

div(u) = 0

sigma = -p I + 2 mu epsilon(u)

epsilon(u) = 0.5 * (grad(u) + grad(u)^T)

其中：

u:
    3D velocity vector
    unit = m/s

p:
    gauge pressure
    unit = Pa

mu:
    dynamic viscosity
    unit = Pa*s

rho:
    density
    unit = kg/m^3

注意：

rho 不进入 steady Stokes momentum equation。

rho 仅用于输出 Reynolds number 等诊断。

不得错误地把 kinematic viscosity nu 直接放进上述 stress equation，
除非明确乘回 density。

Stage 2 solver 内部统一使用 dynamic viscosity mu。


============================================================
3. 正式边界条件
============================================================

边界：

Gamma_wall
Gamma_in
Gamma_out

壁面：

u = 0 on Gamma_wall

即 no-slip Dirichlet。

出口：

sigma n = 0 on Gamma_out

这代表 atmospheric gauge zero-traction outlet。

不要对 pressure field 施加：

p = 0 Dirichlet

不要 pin 任意 pressure DOF。

不要创建：

pressure_reference
pressure_pin
first_pressure_dof = 0

或任何等价行为。

入口：

不要指定 velocity。

不要指定：

parabolic profile
plug flow
uniform velocity
Poiseuille profile

只规定：

integral_Gamma_in u dot n dS = -Q_target

这里 n 是 fluid domain 的 outward normal。

Q_target > 0 表示“流入计算域的体积流量大小”。

因此：

inflow flux = -Q_target


============================================================
4. 全局 Lagrange multiplier lambda
============================================================

增加一个全局 scalar unknown：

lambda in R

物理定义：

sigma n = -lambda n
on Gamma_in

lambda unit:

Pa

lambda 是入口 uniform normal traction magnitude。

它不是人为输入 pressure。

它是 solver 为满足 Q_target 自动求出的未知量。

在 straight fully-developed circular pipe benchmark 中：

lambda 应接近解析 inlet gauge pressure，

并满足：

lambda ≈ Delta p
       = 8 mu L Q / (pi R^4)

因为 outlet traction gauge = 0。

一般复杂几何中不要简单宣称 lambda 就是局部 static pressure，
因为：

sigma n = -p n + 2 mu epsilon(u)n

lambda 的正式语义始终保存为：

inlet normal traction multiplier。


============================================================
5. 符号约定必须锁死
============================================================

正式约定：

n = outward unit normal

Q_target > 0:
    positive prescribed inflow magnitude

constraint:

integral_Gamma_in u dot n dS + Q_target = 0

因此：

integral_Gamma_in u dot n dS = -Q_target

入口 traction：

sigma n = -lambda n

正常正向圆管流动应满足：

Q_target > 0
lambda > 0

如果 benchmark 中出现：

Q > 0
lambda < 0

不要通过 abs(lambda) 隐藏问题。

必须 FAIL 并检查 weak-form sign。

理论平均速度：

U_mean = Q / (pi R^2)

u_z(r)
=

u_x = 0

=

p(s)
