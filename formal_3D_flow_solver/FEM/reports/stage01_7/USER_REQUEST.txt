10. 新的通用尺寸函数
============================================================

Stage 1.6 的问题之一是：

transition zone 太宽，
造成大量 near-rim interior points。

Stage 1.7 使用一个简单、自尺度、没有固定半径比例的尺寸函数：

h_i(d)
=
min(
    H_i,
    h_rim_i + g * d
)

其中：

d =
平面内到 frozen rim line segments
的精确最小距离。

h_rim_i =
当前 port 的 rim median edge length。

H_i =
optimizer 当前尝试的 interior maximum size。

g =
dimensionless grading slope。

Stage 1.7 第一正式算法固定：

g = 1.0

这是通用无量纲 grading rule：

离 rim 每远离 1 个长度单位，
允许目标 edge size 增加 1 个长度单位。

不要根据当前模型结果调 g。

如果该规则最终证明不可行，
本阶段 FAIL，
而不是偷偷修改 g。

============================================================

(l1^2+l2^2+l3^2)

不要要求：

median ≈ 1。

目标是：

够好且尽量稀疏。

14. 自动寻找 coarsest passing H_i
============================================================

使用 deterministic bracket search。

增长因子固定：

search_factor = 1.25

如果当前 H_i surface quality PASS：

尝试：

H_new = 1.25 * H_i

即进一步变粗。

继续直到：

第一次 quality FAIL

或：

H_i >= 2 * R_eq_i

或：

达到 maximum_surface_trials_per_port。

如果初始：

H_i = h_volume

已经 FAIL：

依次尝试：

H_new = H_i / 1.25

直到 PASS

或：

H_i <= h_rim_i

如果到 h_rim_i 仍不能 PASS：

该 port optimizer FAIL。
