10. 自动 geometry / topology QC
============================================================

对每个 mesh profile 都必须计算并保存：

A. Cell topology
----------------

tetrahedron_count
vertex_count
connected_fluid_components

要求：

connected_fluid_components == 1

B. Tetra validity
-----------------

所有 tetra coordinate finite。

所有 tetra volume > 0。

不得存在：

zero-volume
negative-volume
NaN volume
Inf volume

C. Boundary completeness
------------------------

提取 volume mesh 的全部 exterior facets。

要求：

每个 exterior facet 恰好属于以下一个：

wall
inlet
outlet_01
outlet_02
outlet_03

要求：

unlabelled_exterior_facets == 0
multiply_labelled_exterior_facets == 0

D. Port areas
-------------

重新从最终 FEM facet mesh 积分：

area(inlet)
area(outlet_01)
area(outlet_02)
area(outlet_03)

与 Stage 0 contract 对比。

不能只相信 source metadata。

保存：

absolute_error_m2
relative_error

如果 boundary triangles 被严格冻结，
应接近 roundoff。

如果不接近：
FAIL 并调查。

E. Port centroids
-----------------

重新由最终 FEM facets 计算面积加权 centroid。

与 source_contract plane_origin_m 比较。

注意：

plane_origin_m 是 Stage 0 的面积加权 cap 中心，
因此应该高度一致。

报告 displacement_m。

F. Port normals
---------------

重新从最终 oriented boundary facets 计算面积加权 outward normal。

必须首先可靠确定 outward orientation，
不能按 xyz sign 猜。

与 source_contract outward_normal 计算 dot product。

要求：

dot(normal_fem, normal_contract) > 0.999

若不满足：
FAIL。

G. Cap planarity
----------------

对每个 port 计算：

dot(x - plane_origin, normal)

的最大绝对值。

不得显著差于 Stage 0 的 cap planarity。

H. Source boundary fidelity
---------------------------

验证最终 FEM exterior boundary 与 frozen source surface 的关系。

至少报告：

surface area total
port areas
bounds
maximum boundary displacement if nodes changed

如果存在 surface remeshing，
额外计算一种可靠的双向几何距离指标，
例如 sampled symmetric Hausdorff-like distance。

不要仅比较 bounding box。
