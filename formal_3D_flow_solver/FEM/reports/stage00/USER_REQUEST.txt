本项目的最终物理模型为：

3D steady incompressible Newtonian Stokes

第一版不加入 RBC、不加入微泡、不加入 non-Newtonian viscosity、不加入 pulsatility。

实验型边界条件必须最终实现为：

PDMS wall:
    no slip

inlet:
    only prescribed total volumetric flow Q
    no prescribed velocity profile

outlet:
    atmospheric gauge pressure
    implemented as the appropriate natural traction condition

入口最终使用一个全局 Lagrange multiplier 来强制：

integral_Gamma_in u dot n dS = -Q

并把对应的入口 normal traction multiplier 作为求解结果保存。

不要退化成给入口指定抛物线速度。

FEM 离散目标为：

velocity: 3D P2
pressure: P1
flow constraint: one global Real DOF

对于 DOLFINx 0.11 的 Real element，采用 block/MixedFunctionSpace 或等价的显式 block assembly。不要把 Real element 直接放进普通 basix.ufl.mixed_element([...])。

所有长度、速度、流量、压力和黏度在正式 solver 内部统一使用 SI：

kg/m^3
