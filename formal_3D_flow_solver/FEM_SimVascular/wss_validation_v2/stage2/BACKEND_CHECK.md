# 线性代数后端核对（附加实验）

原三档方案与误差目标不变。GPU 最细网格执行约 20 分钟仍在初始非线性迭代，GPU 利用率为 100%，未出现发散。为确认 CPU 执行能否作为后续大网格的等价运行方式，新增独立算例，仅替换 PETSc 矩阵/向量后端：`aijcusparse/cuda` → `aij/standard`；KSP GMRES、ASM/ILU、容差、缩放、svMultiPhysics 可执行文件及 PDE/网格/XML 均不变。

粗网格 CPU 已实际求解，速度体积 L2 相对 GPU 差 2.26755e-16，压力 5.63499e-14，WSS 面积 L2 差 2.92992e-16，最大绝对 WSS 差 6.21725e-15 Pa。文件见 ../data/cpu_gpu_backend_check.json。CPU 总墙钟约14 s，GPU约40 s，均包含监视器轮询与保存。

最细 CPU 主步长及半步长已经建立独立副本。后端比较门槛在这些副本的结果出来前登记：匹配时间步保存解的速度/压力/WSS 相对 L2 差均≤1e-9（执行后端的一致性工作门槛，不是物理误差）。完整 CFD 仍需原稳态及质量/日志门槛。若 CPU/GPU 同网格同一步结果确认一致，可以使用 CPU 最细终态作为主三档空间比较；原 GPU 未收敛中间解不能代替最终 CFD，保留全部记录并明确状态。

这种更换没有修改离散方程或 WSS 恢复公式，但会改变浮点运算顺序，必须报告实际比较结果。不把 CPU/GPU 差作为空间精度误差估计。

附加执行变体：最细网格在单 MPI rank 下原 ASM 只有一个大 ILU 子域，CPU 后端首个线性系统也需约92秒，因此单纯更换矩阵后端没有解决细网格耗时。另建 pipe_nr16_cpu_asm16，仅加 `-pc_asm_local_blocks 16`，仍为 ASM overlap2 / ILU level2；残差和稳态标准不变。该变体只是线性预条件器分块，不改变 P1/P1 VMS 方程；采用前仍须匹配时间步场比较和独立真实残差审核。未完成的性能试验不会计入通过的空间网格结果。

8个 MPI 进程的 CPU 变体 `pipe_nr16_cpu_mpi8` 使用原 ASM 每进程子域、overlap2/ILU2；同一求解器、原网格与 XML、不改容差。全局结果由求解器主进程聚合写出，监视器仍核对原输入节点次序。它前两次实际线性求解合计约62秒，比单进程方案快。单进程 CPU 与单进程 ASM16 性能试验已主动停止，原因与终止进程组写入各例 reports/intentional_cancellation.json；没有把这些试验算作收敛解或空间验证失败。保留原 GPU 主求解和 MPI8 副本继续，稍后需按登记标准比较匹配时间步。
