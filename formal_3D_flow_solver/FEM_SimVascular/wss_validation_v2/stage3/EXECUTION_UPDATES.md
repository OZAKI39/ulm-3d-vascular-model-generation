# 阶段三执行配置补充（不改变物理、网格、dt或容差）

原H0与CPU8/ILU2从零复算的终态已实际比较：u/p/WSS相对L2差4.107e-15/1.178e-13/4.290e-15，最大WSS差4.476e-13Pa。CPU8复算第51步完成，4721秒、120次接受线性校正，无失败/遗漏/恢复重试。

中档GPU1首轮及fresh retry失败，归档`failed_attempts/vessel_medium_gpu1`。停止其监视器没有自动停止独立MPI子进程；后来按专用cwd精确停止，首个停止请求时的日志作为最终日志前缀另存，完整失败日志保留。该试验没有任何场进入科学比较。独立监视器已补充SIGTERM/SIGINT时终止本case的MPI/求解器进程，并在新实验上实际验证；不会操作其他工作目录。

随后中档CPU8/ILU2能收敛线性校正，但数百次迭代的成本很高。以下有界代数执行实验均在`execution_checks/`，同一二进制/PETSc/P1-P1 VMS/网格/XML/dt/残差目标，从零初始化；不把这些未达到稳态的快照当科学网格结果：

| 变体 | 实际结果 | 用途与限制 |
|---|---|---|
| CPU8/子域LU | 第5步u/p/WSS对CPU8/ILU2差4.429e-15/1.703e-16/4.682e-15，通过预登记1e-9门槛；前5步15次校正共393次KSP迭代，原ILU2为9086次 | 同场执行一致性；获得第5步后主动停止；不是稳态验证 |
| CPU8/ILU6 | 首次因子建立超过5分钟、每进程约0.9–1.2GB，仍无接受校正；主动停止 | 没有完成一致性检查，不采用 |
| CPU16/子域LU第一次启动 | OpenMPI默认slots不足，无CFD输出 | 保留`_no_slots`；显式oversubscribe/bind-none后重试；没有新增CPU配额 |
| CPU16/子域LU有效试验 | 第5步u/p/WSS对CPU8/LU差3.987e-15/2.870e-16/4.237e-15，满足1e-9；之后主动停止 | 证明此次分区/执行变化的同场一致性；不是稳态验证 |

当前中档`vessel_medium`已从零以CPU8、ASM overlap2、原生子域LU启动。此前未完成的CPU8/ILU2例归档`execution_checks/vessel_medium_cpu8_ILU2_stopped`。主中/细网格的网格和solver.xml逐字节保持一致，只有PETSC_OPTIONS和执行policy变更；原输入变体在各例reports保留。

细档准备CPU16/子域LU，并已通过上述同场检查。因LU内存随规模上升，独立监视器新增50GiB求解器进程RSS预算，超限会记录资源原因并停止该例，不把未完成场认作失败物理解。所有辅助代数性能实验已停止，不再与主中、细序列争用资源。

随后在细档CFD启动前登记`FINE_INITIALIZATION_ADDENDUM.md`：细档使用通过独立检查的中档实际CFD场作初值，之后仍真正求解并满足原连续稳态门槛。只有该初值变更可修改细档XML的两项initial-file路径；原零初值输入另存，其他物理/时间步/容差保持一致。此处早期“XML逐字节一致”是LU后端变更时的记录，不能替代之后的初值补充记录。

原门槛从未放宽。性能试验与主中档曾并行，墙钟时间不是隔离性能基准；只把实际迭代数、因子规模、同场差与已记录时间作为执行证据。
