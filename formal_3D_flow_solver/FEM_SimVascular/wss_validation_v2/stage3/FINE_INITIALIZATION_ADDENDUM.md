# 细档初始化补充登记（细档CFD尚未启动）

用户明确允许插值用于初始化，但不允许冒充重新求解。为减少重复的冷启动瞬态，细档采用中档**实际收敛并通过独立后处理检查的CFD解**作初值，之后仍在细网格上运行同一svMultiPhysics/P1-P1 VMS方程并达到原稳态、残差、质量及WSS门槛。主dt、几何、材料、入口、出口及原门槛均不变。原零初值输入另存，不删除。

插值方法：新节点位于中档四面体内部时，按原坐标求P1重心插值；因两档表面离散微差而位于外部的点投影至最近中档单元，记录点数/投影距离。仅用于初值；细网格壁节点按实际无滑移条件置零。不会将插值场用于任何网格敏感性统计或图。初值文件明确命名`initial_state/flow_guess.vtu`，最终科学结果仍为独立CFD输出`frozen_flow/`。

原生读取链：read_msh.cpp 760–820读取Initial_pressures_file_path/Initial_velocities_file_path中的Pressure/Velocity；vtk_xml.cpp 668–710按点序读取；distribute.cpp 444–483按本地节点映射分发；initialize.cpp 980–1005写入实际初始解。目标VTU逐点坐标/连接关系核对，输入清单绑定初值文件哈希。

CPU8/CPU16子域LU的同第5步场对比已实际通过1e-9门槛；细档执行配置继续为已登记CPU16/LU。此补充只改变初值，不减少最少步数、不改变连续3个5步间隔的收敛门槛，也不把中档解的插值误差视为细档误差。最终将另存初值与终态差，保留实际求解日志及迭代次数。

运行门：先等待中档execution PASS，再等待本地生产WSS/独立流量/控制体/日志检查全部完成后同步的independent_acceptance.json；验证其中源场哈希，再插值和真正启动细档CFD。不存在未经独立检查就将中档作为已接受细档结果的捷径。
