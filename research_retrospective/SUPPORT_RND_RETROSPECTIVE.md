# 支撑研发回顾：研究历史，不再作为生产路径

本轮将制造架构改为独立 ABS 血管芯、无底 PLA 浇注框架和培养皿底面。过去各阶段均未通过全部软件门槛，不将诊断候选称为合格生产模型。以下数值取自保留的阶段最终报告与 RFUS method_comparison.csv，不混用不同覆盖指标。

|阶段|方法与真实结果|未通过原因与结论|
|---|---|---|
|Bambu Organic|原生自动树；RFUS 同口径 1990 点复核下方覆盖 30.7538%，最长缺口 8.2898 mm；实际支撑挤出 771.14 mm³|稀疏接触与完整下托要求不等同；不能作为 100% 覆盖基准|
|V1|融合表面、层截面与中心线危险区间，显式底脚/尖端；实际 40 个尖端，覆盖 79.79%，最长缺口 7.24 mm，99 项测试|1 个受困组件，外部端口与仅内部根部策略冲突；切片成功而制造门槛未通过|

最终报告、summary、比较 CSV、保护哈希和测试结果留在原各阶段路径。候选 STL/VTP、3MF/G-code、QC 图序列、迭代和缓存根据本轮明确授权删除。cleanup_inventory.json 是逐文件删除账本，含 SHA256。历史文献、许可证、共享几何工具、Bambu 本地适配器和合成回归数据继续保留。

本项目目录不是 Git 工作树，git status、rev-parse、ls-files 均实际失败，见 git_audit.json。因此不存在可填写的恢复 commit；s1-8 及 support_v*、RFUS 源码全部保留，原测试仍运行。没有为了清理伪造 Git 历史或删除共享回归。旧报告中的输出链接仅为当时记录，不能再当作现存打印文件。

各轮“保护文件数”曾包含前轮研究输出。本次按新授权重新建立 production_protected_before.json，只保护生产、源码、数据、映射和共享资料；不把已明确授权删除的研究候选继续冒充永久输入。新生产路线不重新拟合血管，也不继续开发支撑算法。
