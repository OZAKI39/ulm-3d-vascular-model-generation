# Vessel inputs are not included

This directory is a placeholder for locally generated or separately supplied
vessel inputs. The synchronization includes code and reports only.

The microbubble pipeline expects matching `.swc` and `.vessels.npz` files under
a validated run directory whose name declares the geometry, such as
`<timestamp>_planar_2d_seed_<seed>`. Use the companion generator to create new
inputs, or obtain the matching historical files separately. No vessel datasets
were uploaded with this branch.
