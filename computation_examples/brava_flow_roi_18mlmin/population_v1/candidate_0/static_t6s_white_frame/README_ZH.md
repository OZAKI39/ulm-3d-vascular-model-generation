# Candidate 0：物理时间 6 s 的六视角静态图

已将外框及其极淡的面填充改为白色，保留黑色背景、蓝色微泡、透明血管、原有三维网格、毫米刻度、英文顶部信息和端口箭头。六张图使用完全相同的物理时间 **t = 6.000 s**、微泡位置和筛选名单，只改变相机角度；各视角分别适配完整坐标框与文字，避免裁切。

打开 `OPEN_RESULTS.html` 可查看六张独立 PNG/PDF；`CONTACT_SHEET.png` 为总览。完整图片位于 `figures/`，每张 PNG 为 1920×1080，保存 300 dpi 元数据。

## 筛选结果

| 范围 | 数量 |
|---|---:|
| 原始模拟轨迹 | 1565 |
| 已有全程隐藏名单：2 条求解失败 + 58 条数值风险 | 60 |
| t = 6 s 仍在血管内的微泡 | 406 |
| 其中属于已有隐藏名单 | 25 |
| 其余微泡中新增的低速隐藏 | 257 |
| 六张图实际显示 | **124** |

低速条件按用户确认的 **5.95–6.05 s 内平均三维速度大小 < 2 mm/s** 执行。这里对每段实际接受区间的速度模长按时间加权：

\[
\bar{s}=\frac{\sum_k\Delta t_k^{\mathrm{window}}\,\|\mathbf v_k\|}{\sum_k\Delta t_k^{\mathrm{window}}}.
\]

不是先平均速度向量再求模，也不是用首尾净位移代替路程。保存数组中的 `velocity[i+1]` 对应 `[time[i], time[i+1]]` 的运动；位置按同一段的真实运动插值到精确的 6 s。

有 5 条在时窗结束前退出或终止（ID 217、422、569、1504、1535），平均值只使用其有记录的生存区间，不在退出后补零、不外推。实际平均起止时刻和时长逐条保存在 CSV。

低速阈值和既有数值风险名单仅用于本次显示筛选，不能解释为这些微泡已被逐条证明不符合物理规律。原始数据、完整轨迹、原终态和原动画均保留；本轮没有求解流场或重新积分微泡轨迹。

- `data/display_selection.csv`：全部 ID、是否在 6 s 存活、平均速度、瞬时速度、实际平均时窗、位置及隐藏原因。

- `data/manifest.json`、`data/track_hashes.json`：输入来源、逐轨迹哈希、渲染参数和图片哈希。
- `data/QC.json`：六视角名单一致性、独立路程/速度核对、端口投影及文件保护检查。
