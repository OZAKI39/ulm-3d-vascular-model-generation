# 3. 先写清楚正确数学语义

对于 curved TET10 physical element：

## Geometry map
唯一物理几何映射：

```text
x(ξ) = Σ_A N_A^geom,P2(ξ) X_A
J_geom = ∂x/∂ξ
```

同一 quadrature point 的：
- physical position
- J
- detJ
- invJ
- metric/Kxi
- integration weight
都必须来自这一个 geometry map。

## Velocity field
P2 field basis：

```text
u(ξ)=Σ_A N_A^u,P2(ξ) U_A
∇_x u = reference derivatives transformed by J_geom^{-1}
```

## Pressure field
pressure 保持 P1/TET4 field basis：

```text
p(ξ)=Σ_i N_i^p,P1(ξ) P_i
∇_x p = J_geom^{-T} ∇_ξ p
```

P1 pressure field **不等于** P1 geometry。

momentum / continuity / pressure-gradient / stabilization mixed terms 不允许因为 field basis 切换而静默换另一套 geometry。

# 6. Phase C —— 最小 patch

目标：mixed P2/P1 fluid assembly 在 curved element 上共享 geometry mapping。

优先最小改法：

1. 每个quadrature point先由TET10 geometry计算一次：xq/J/detJ/invJ/Kxi。
2. velocity P2 basis仅计算参考形函数和参考导数，再用common invJ变换。
3. pressure P1 basis仅计算参考形函数和参考导数，再用**同一个common invJ**变换。
4. mixed integration weight统一使用`w_ref*detJ_geom`。
5. stabilization metric使用common geometry，不改stabilization physics/coefficients。
6. 不允许pressure path再次调用会重算/覆盖physical geometry的TET4 gnn。

若现有API不支持，可添加最小 helper：
- reference basis only
- transform with externally supplied common Jacobian

禁止：
- 重写完整FE library
- 重写PETSc assembly
- 重写fluid solver
- 修改production P1/P1算法

patch必须validation-gated，独立build/binary，保留diff/source SHA/build receipt/binary SHA。
