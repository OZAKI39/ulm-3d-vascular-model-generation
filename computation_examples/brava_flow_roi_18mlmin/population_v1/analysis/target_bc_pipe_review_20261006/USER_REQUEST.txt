# Codex 新一轮开发提示词
## 主题：目标 BC 执行路径审计 + 条件性一次 P2/P1 manufactured pipe GPU CFD

你现在继续开发当前 BraVa 3D 微泡持续灌注/轨迹项目。

上一轮已经完成：

- mixed P2/P1 curved **volume assembly common-geometry patch**；
- 两个真实曲面单元 central wall 143654 / inlet rim 35265 的 volume harness 已达到预声明数值门槛；
- continuity、pressure gradient transform、common J/detJ/invJ、stabilization metric 已统一；
- P1/P1 production local path 保持不变；
- strong Dirichlet 与 prescribed traction/Cauchy boundary path 已通过；
- 仍存在一个独立的 **weak Dirichlet curved mixed geometry** 缺陷；
- 因 Phase F 的通用 boundary gate，上一轮没有运行 P2 pipe/BraVa CFD。

当前报告状态：

`COMMON_GEOMETRY_FIX_NOT_EVALUABLE`

但是本轮不能把“库里 weak Dirichlet 有 bug”自动等同于“当前目标 pipe/BraVa 一定会走 weak Dirichlet”。

本轮首先只回答：

> **当前真实 manufactured pipe 和历史 BraVa solver.xml 的 BC，运行时到底 dispatch 到哪些 native boundary paths？**
>
> **如果目标 P2 manufactured pipe 根本不调用 weak Dirichlet，则上一轮 volume/common-geometry 修复是否已经足以允许一次严格受控 P2/P1 pipe GPU CFD？**

本轮最多运行：
- **1 次** P2/P1 manufactured pipe GPU CFD；
- **0 次** BraVa CFD；
- **0 次** particle trajectory；
- **0 次** population。

如果 pipe 目标 BC 确实调用 weak Dirichlet，则只允许修这一条 boundary path，重新通过 harness 后才可决定是否运行 pipe CFD。

# 6. Phase D —— 根据目标路径决定 weak Dirichlet 是否需要修

分类：

## Case D1：manufactured pipe 不调用 weak Dirichlet

若 pipe 的：
- inlet
- wall
- outlet

全部只调用已经通过的：
- strong Dirichlet
- prescribed traction/Cauchy
- 或其它已验证且不经过weak path的 natural path

则状态：

`PIPE_TARGET_BC_SET_CLEAR_OF_WEAK_DIRICHLET`

不修 weak Dirichlet。
不要为了“库更完整”扩大本轮。

继续 Phase E。

## Case D2：manufactured pipe 任一 target boundary 调用 weak Dirichlet

则：
- 不允许 pipe CFD；
- 只修 `set_bc_dir_wl` / 对应 weak path 的 common geometry；
- 不修改其它 boundary path。

### Weak path修复要求

pressure field 仍为 P1；
physical inverse / basis evaluation / gradient transform 必须基于 common curved TET10 geometry语义。

具体：
- 先通过 velocity/common geometry inverse 得到统一 reference coordinate；
- P1 pressure basis在**同一 ξ**上评价；
- 不允许再对 xql/TET4做第二次独立physical inverse；
- boundary quadrature x/J/normal/weight统一来自 common geometry；
- pressure field basis与geometry basis解耦。

必须重新跑上一轮：
- curved wall weak fixture
- curved cap weak fixture
- rigid outlet control
- strong Dirichlet regression
- traction regression

gate仍使用上一轮冻结的 numerical thresholds，不看结果后放宽。

只有 weak path全部通过，才允许继续Phase E。

若修不通过：
`WEAK_DIRICHLET_COMMON_GEOMETRY_FIX_FAILED`
停止P2路线，不跑CFD。

# 12. 必须做新的 P1/P2 error decomposition

对每组probe定义：

```text
e_P1_repr = I_P1(u_exact) - u_exact
e_P2_repr = I_P2(u_exact) - u_exact
e_P1_disc = u_P1_CFD - I_P1(u_exact)
e_P2_disc = u_P2_CFD - I_P2(u_exact)
e_P1_total = u_P1_CFD - u_exact
e_P2_total = u_P2_CFD - u_exact
```

向量范数不能简单百分数相减。

保存：
- norm
- squared norm
- cross term
- cosine between representation/discrete errors

特别回答：

### 0.377 µm
P1 representation≈9.76%这一已知项消失后，actual P2 total 是否明显下降？

### 149.195 µm
同样判断representation-supported failure。

### 29.839 / 59.678 µm
原本P1 representation很小、主要是discrete-solution difference。
P2 actual discrete error是否改善？

这是本轮最重要的科学判别。
