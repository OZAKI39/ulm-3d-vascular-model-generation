# 圆管完整 CFD 验证（三档主计算及半时间步复算均完成）

阶段二已经实际完成。已实际运行三档独立 CFD，并用修复后的生产入口恢复 WSS；同一网格的解析节点场作为另一个实验，不能充当 CFD 解。

## 方法和参数

使用原 svMultiPhysics 可执行文件（SHA256 `0e509fe21424b5b1f731c4b4f519839b0104bfb2aab0817b01556cc4054f7fc7`），P1/P1 VMS、常黏度牛顿流体、刚性无滑移壁、广义α谱半径0.5。R=4μm，L=40μm，U=0.002m/s，μ=0.00345312Pa·s，ρ=1056kg/m³。主序列 dt=1e-6s，零初始场。

入口给定解析抛物线的节点值，User_defined / Impose_flux=false；因此离散流量 Qh 与连续圆管理论值 Q=1.0053096491487337e-13m³/s 不完全相同。出口z=L设完整解析牵引 t=(-4μUx/R²,-4μUy/R²,0)，取 p(L)=0；它与对称牛顿应力相容。实际 XML 的 Add_BC Type=Trac，Traction_values_file_path 指向三分量 VTP。WSS侧壁与入口/出口截面分开标记。

中央比较区域 z=12–28μm，理论压降55.24992Pa，理论WSS6.90624Pa。速度采用体积L2，Duffy 4×3×3 Gauss积分可精确积分此处四次平方误差；截面压力/流量采用P1三角形积分；WSS为原始面片模长的面积统计，未平滑或缩放。

原登记工作目标：最细中央速度L2误差≤1%、中央压降误差绝对值≤1%、中央WSS均值误差绝对值≤5%。这些不是通用认证标准。

## 误差能说明什么

对于本轮规则圆环挤出网格，外壁面片法向高度为 h_n=Δr cos(π/Nθ)。解析速度赋值后，生产P1恢复应给出

`τ_P1 = τ_exact × [1 − Δr/(2R)] / cos(π/Nθ)`。

这是对已使用几何与线性插值斜率的解释，不是替换生产算法。该表达式与真实生产方法得到的解析节点WSS均值最大差4.44e-15Pa，实际对顶高度也一致。说明该解析场上的欠估与P1导数恢复/多边形几何相符，没有发现缺系数或单位错误。CFD场与解析节点场的误差不能简单相减成唯一“求解器误差”。

速度剖面很接近解析解时，导数仍有约百分之几的误差。最细圆管 h_n/R≈0.06247；真实血管出口半径约1.2μm，原网格近壁高度约0.26μm，相对近壁分辨率更低，不能直接把此圆管的2.83%误差移植到血管。

入口/出口总量守恒并不等于内部截面严格等流量。细网格中央截面比入口低0.1256%；全体积RMS(div)/RMS(grad u)=0.0804%，中央段为0.000187%。两者均随细化下降。这里没有把全局守恒写成局部逐点无散度。

最小 minSICN 随细化从0.12165降至0.03367，发生在靠轴心的规则环形网格；实际壁面父单元质量和近壁尺度另报。不能只凭全域最小形状质量阈值判定这个各向异性网格是否满足精度要求；实际误差与收敛趋势提供了更直接证据。

## 执行方式及时间步核对

粗、中主序列使用单MPI/GPU矩阵后端；最细使用CPU/8MPI。粗网格CPU与GPU终态WSS相对L2差2.93e-16；最细匹配第5步的速度/压力/WSS相对差分别2.81e-16、9.76e-17、5.02e-16，说明这次执行后端改变没有可见的场量影响。求解器二进制、P1/P1 VMS、材料、BC和残差标准保持一致；MPI分区会改变预条件器子域，因此单独留下了实际核对证据。详见 BACKEND_CHECK.md。

半时间步 `pipe_nr16_cpu_mpi8_halfdt` 使用完全相同网格、材料与BC，dt=5e-7s，零初始场，已在第51步正常完成，耗时1886.2秒，119次线性求解均通过独立日志核对，无遗漏、失败或恢复重试。主步长与半步长的速度、压力、WSS相对加权L2差分别为9.5421e-9、9.6886e-9、1.5282e-8；最大面片WSS差5.1142e-7 Pa。中央平均WSS由6.710508971变为6.710509035 Pa，中央压降由55.193733617变为55.193734131 Pa。这个时间步差远小于已测空间误差，支持本圆管比较由空间误差主导，不能外推成所有血管时间步均已验证。完整逐场比较见 ../data/pipe_timestep_comparison.json。
