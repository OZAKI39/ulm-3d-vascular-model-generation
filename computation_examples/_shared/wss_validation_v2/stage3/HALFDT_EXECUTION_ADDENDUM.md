# 独立时间步实验执行安排

在原网格CPU8复算仍运行、中/细CFD均未开始、GPU8试验明确失败之后，半时间步实验改用**原冻结H0已经实际使用的GPU单MPI后端**。本实验相对原H0 GPU1基线只改变时间步（另有总步数/保存频率等执行设置），不以GPU8失败的配置取代原设置。与CPU8基线复算可以使用CPU/GPU并行资源，避免闲置GPU；CPU8复算仍独立完成，以核对后续中/细网格的执行后端。

尚未开始的CPU8半步长只保留为未执行输入，不计为实际验证；新增实际算例vessel_baseline_gpu_mpi1_halfdt。时间步比较基准为vessel_baseline（原GPU1 H0），不是将CPU8与GPU1差异混入dt效应。CPU8与原H0的同dt场差另报；若未达到一致性，不能把二者混作同一对照。稳态、线性、非线性及科学精度门槛完全不变。中、细网格继续CPU8串行实际求解。
