# 用于最终报告的证据笔记（不是完成报告）

## 修复已经证明什么

阶段一生产入口恢复，7个核心函数 AST 与恢复历史文件一致（surface 的局部依赖导入除外）。材料改为明确 case XML，并用 case policy 的 μ 或 νρ 核对。H0 原始面片和显示节点最大差0 Pa，满足1e-9 Pa回归要求；解析张量测试通过。该结果证明可复现性与核心代数操作，没有证明复杂血管的物理/空间精度。

新求解 VTU 的 vtkPoints 默认 float32，监视器最初拒绝数据；已保留失败求解与旧监视器。修复只认可原输入精确坐标或精确 float32 序列化，梯度仍基于双精度原输入。速度/压力和单元节点集合另核对，不放宽为任意几何距离容差。

## 圆管分析必须保留的解释

R4μm、L40μm、U2mm/s、μ0.00345312Pa·s、ρ1056kg/m³，理论 WSS6.90624Pa。入口取解析节点值，因此不同网格的离散流量分别是理论流量的96.801976%、99.195319%、99.798505%；不能把这个几何/插值误差隐藏在归一化中。出口设置完整解析牵引(-4μUx/R²,-4μUy/R²,0)，不是普通零压力截面。中央取z12–28μm，理论压降55.24992Pa；速度用精确四次积分，WSS按面片面积加权。

粗网格 CFD：速度L2=4.7240458%，压降误差−0.9833656%，平均WSS误差−12.882458%。中网格：1.1743155%、−0.4861576%、−5.832219%。粗/中解析节点WSS误差−11.744966%/−6.048843%。两类误差不能简单相减成唯一的“求解器误差”，因为场、几何、边界和恢复相互作用。

每例三次连续5步间隔检查速度、压力、WSS相对变化<1e-7，入口和全边界质量误差≤1e-6，且实际线性/非线性日志独立核查。满足停止准则只是该离散方程收敛；物理误差工作目标仍是最细速度/压降≤1%、WSS均值≤5%。

## 后续不能误写

会议原图/版本哈希未提供，当前 H0 身份确认不等于复现会议原图。CPU/GPU 后端或预条件器分块核对不构成网格敏感性验证。未收敛运行必须明确标记。未完成的 stage3 / stage4 不能提前填入结果。

血管诊断图画原面片模长，统一0–55Pa，不做平滑/归一化/阈值删点；诊断裁出局部只是视野选择，原场不改变。真实ROI/人工延伸段的固定坐标统计应分别报告。生理假设适用性不能用很低的线性残差替代。

## 待按真实血管结果判断的机制（还不是诊断结论）

保留实际 vascular Flat+Zero_out_perimeter 入口及 Neumann 压力出口。入口边缘的非平滑速度条件、壁面Dirichlet与出口自然牵引交界，可能使靠人工端口的原始极值对网格敏感；不能据全局极值单独判真实ROI精度。圆管采用完整解析出口牵引，真实血管采用原有压力牵引，两者边界形式不同；不能把圆管工作目标通过当作已验证血管出口端部效应。空间结果应对照真ROI/延伸段和端口距离分析，不先预定结论。

固定网格正负压力响应中，WSS取模、分位数及阈值区域本身可产生不对称；即使速度近似线性，不能只凭WSS不完全反对称判程序错误。全域/J1平均值可能相互抵消而变化小，必须同时看P5/P95、区域面积和空间分布。时间步/迭代误差与空间误差分开，固定网格响应可分辨不等于连续或生理敏感度已验证。
