# F10I连边事件与求解误差诊断

## 定义及接受语义

球面间隙为`g = |x_j-x_i| - 2R`，接触罚力只在`g<0`时存在。原几何连边是`g <= 0.1R`，即178 nm；`h_edge=g−178 nm`。几何连边不是真实黏附、融合或接触。

从F10H的ALL_STEPS.json.gz逐接受步坐标重建全部496泡对距离，并与HDF5的固定ID、半径、101个输出帧及完整事件日志校核；实际事件时钟是物理步接受后的`time_origin+(step_count+1)dt`，与原记录逐项校核。初态不是新事件；不插入中间接受帧。10 µs为501帧、5 µs为1001帧（都含初态），原始1500接受步未重跑。真实事件匹配用pair、开关、该pair发生序号，不能按全局序号强配。

`EVENT_MATCHES.json`保留29行，含事件前后真实帧、表面间隙、该pair全接受时序最小绝对阈值差、区间差商速度、已保存末端速度投影、几何泡对弹簧力、重复开关标记与全局顺序反转索引。阈值恰等时保持原`<=`语义。绝对时间差在原10 µs限上只处理浮点时钟舍入，不增加物理容差。

## 团级持续性

复用原2 ms持续事件定义，基于真实接受图和固定ID连通分量追踪。全部成员集合为`{0,...,31}`；没有多分量、持续或瞬时split/merge，右删失0。不能创造分裂/合并以填图，不能将无事件算例标记为通用`PERSISTENT_TOPOLOGY_PASS`。

新任务级状态为`GROUP_LEVEL_NUMERICAL_EVIDENCE`，持久事件观察为`NO_PERSISTENT_SPLIT_OR_MERGE_OBSERVED`，持久事件预测精度为`PERSISTENT_TOPOLOGY_NOT_EVALUATED`。Rg、长短比、形状张量、质心、固定ID、Kabsch在同一实际时间比较，原限不变，数值见开发报告与`GROUP_TOPOLOGY.json`。原逐泡严格时间/顺序失败单独保留。

## 非线性接触误差的有界分离

原B2每次外层更新真实距离、法向、活动集，非负弹簧幅值`kc max(2R−d,0)`；每步冻结旧状态离散阻力矩阵A。原停止容差1e−13 m、最多24外层/20次Armijo。不是线性冻结接触法向版，也没有叠加PBD。

预登记固定状态为两步长各1.50、1.65、1.66、1.78、1.79、1.80 ms接受终点，加每条轨迹最大已存方程残差步，共14。单步重解使用保存的原起点和自由速度；它是局部方程测试，不是中途恢复连续轨迹。

独立参考逐pair实现非线性真实几何力、用Powell hybrid解位置方程；没有复用候选的接触B矩阵、梯度或Gauss-Newton矩阵。始终核验实际方程残差，不以库success标志替代。

- 1e−14 m：14/14收敛。
- 1e−15 m：13/14收敛；DT10_0141末次残差1.0025791843e−15 m，线搜索停止，保留为NOT_CONVERGED，不放宽容差或提高迭代上限。
- 紧容差末次结果最大位置变化9.75234e−14 m、力2.41981e−16 N、7–24间隙变化8.63169e−14 m；活动接触与边集合均不变。含失败末次迭代的汇总只是诊断，不能称14个紧参考全部通过。
- 独立根的最大位置方程残差1.03892e−22 m；紧结果最大独立位置差1.01186e−15 m。反力非负，所有真实分离pair弹簧力为零，法向/力/最差pair/残差在每个`variants.result`保留。

单步差异不能直接界定累计轨迹误差，因此只增加一条原初态2 ms同dt控制，容差1e−14 m。200步全部接受，最大方程残差9.93902e−15 m；固定ID差5.58789e−12 m=0.005588 nm，质心1.17878e−17 m，Kabsch2.38861e−12 m；23/23原前缀事件接受时间完全相同。与原5 µs轨迹的事件最大差仍130 µs。

这支持当前接触停止容差不足以解释130 µs；剩余主要可见机制是步长相关路径差与低斜率过阈值。没有足够证据细分每个受力/阻力冻结误差，没有建立连续解真值或绝对误差阶。2.5 µs为NOT_RUN，科学问题已得到有界解释，不继续无限加精度。
