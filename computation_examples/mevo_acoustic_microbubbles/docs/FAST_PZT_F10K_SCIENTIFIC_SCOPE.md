# F10K 科学适用范围与导航协议

本报告以 F5–F10J 实际代码、归档和 F10K 新数值结果为依据。机器矩阵为 `results/fast_pzt/f10k/analysis/SCIENTIFIC_SCOPE_FINAL.json`：`baseline_rows` 保留旧证据，`F10K_additions` 单独记录新增有限证据，所有条目 `training_ready=false`。

| 科学任务 | M0 完整逐泡快速模型 | B2 过阻尼隐式接触参考 |
|---|---|---|
| 数值与实现 | 原声力、F2 探索近场、独立 Stokes/局部润滑、PBD、Y 管 CFD、GPU 批量及后处理有回归证据 | 几何单边弹簧与离散接触迁移率、两/四/32 泡参考；新增 128/512 固定状态 CPU/GPU 一致性 |
| 团级运动 | 已测内部管腔 OFF/S/O 响应，可研究该模型下相对趋势 | 已测原 5 ms 和新增 3 ms 场景的同模型步长一致性 |
| 内部形态 | 步长敏感，密集初态可拒绝；不能把质心一致视为逐泡形态准确 | 位移/Rg/张量等门限通过，但严格连边仍 FAIL，`MORPHOLOGY_LIMITED` |
| 持续图聚合 | 历史保存事件，可作为候选而非物理真值 | 新增一个远壁 31+1→32、10/5 µs 一致正例；仅限该模型和窗口 |
| 持续图分裂 | F5/F8 存在历史事件，尚未作为跨模型真值验证 | F5 近壁候选被拒绝；仍 `PERSISTENT_TOPOLOGY_UNTESTED` |
| 近壁水动力 | 原三角面约束不代表集体壁面迁移率正确 | 内部管腔原型不准入壁面接触；`NEAR_WALL_UNCALIBRATED` |
| 长时间数据生产 | 数值批量能力存在，但独立科学样本质量和物理适用性受限 | 没有合格长轨迹生产实现，没有 B64 B2 准入 |
| 实验物理、AI | `PHYSICS_UNCALIBRATED`，`training_ready=false` | 相同限制，数值一致不改变物理校准状态 |

可以可靠复核的是特定离散模型、特定已测状态下的数值量与团级相对响应。不能宣称真实接触刚度、近场二次声力、润滑截断、近壁集体水动力、任意形态控制或预指定目标导航已经验证。M0 与 B2 互不充当物理真值。图连通阈值仍为 2.1R，持续门限仍为 2 ms，均不能解释为泡破裂或融合。

## 实际导航可用时间

重读 F10A 内部管腔六条完整保存轨迹：OFF/S/O、dt=10/5 µs、10 ms。保持原 CFD 与控制，声压 1 kPa 指初始泡群位置的局部压力中位数，不是每块 PZT 命令幅度。原始 CFD 为四面体 P1 插值，内部平均下游速度约 9.878 mm/s。没有用 10 ms 平均速度外推出新的轨迹。

原初始质心（米）约为 `[-0.001979318879546072, 8.864027327340948e-7, 0]`。本次离线诊断平面是 X0+20 µm，实际保存间隔为 50 µs，采用真实跨越括区间线性插值：时间落于 2.000–2.050 ms。插值只给出保存曲线上的过面估计，不能声称达到积分步级连续事件精度。

| 对照 dt | OFF 过面 | S 过面 | O 过面 | O−OFF 过面 Z 增量 | O 相对拟议目标 YZ 误差 |
|---|---:|---:|---:|---:|---:|
| 10 µs | 2.024982 ms | 2.024329 ms | 2.024330 ms | 20.3193 nm | 0.970790 µm |
| 5 µs | 2.024982 ms | 2.024329 ms | 2.024330 ms | 20.5277 nm | 0.970581 µm |

两步长的配对过面增量差为 0.2084 nm，声学作用方向为 +Z 且高于本对照步长差，但低于原 50 nm 实用作用门限。O−S 过面差约 35.94/36.07 nm。原 10 ms O−OFF 额外位移约 0.11625/0.11322 µm 继续保留，它不等于经过 20 µm 平面前能实现的位移。

针对该平面的控制机会约 **2.024 ms**。声场和 CFD 在实际保存的整个 **10 ms** 内仍支持泡群，离开声场的时间右删失；不能把 2.024 ms 写成声场本身的总有效寿命。全体 32 ID 活跃，初态和目标均经实际几何/场域查询。原 F10A 的同 X、+1 µm Z 响应诊断目标，以及 F8 近壁 X+20 µm、Z+0.25 µm 目标各自保留，不用本次新目标替换历史任务。

## F10L 建议预登记（尚未运行）

完整机器协议 `analysis/NAVIGATION_PREREGISTRATION.json` 保存实际初态、命令幅相、SHA、目标和停止条件。建议先采用内部母支管腔 F10A `extended_10_v1/O_1000/trajectory.h5` 第 0 帧，SHA `a5942896baeac56d69028e356dae0df611029db1d790772b7519f686d90de10a`，而非先返回近壁条件。

- 固定目标（米）：`[-0.001959318879546072, 8.864027327340948e-7, 1.0000000000001423e-6]`，目标平面 X=X0+20 µm，YZ 半径 0.2 µm。
- 从真实初态开始，首次质心过面、状态非法或 3 ms 即停止；先登记目标，不能运行后移到结果附近。
- OFF/S/O 同初态、原 CFD、固定 1 kPa 控制；dt=10/5 µs。OFF 同时关闭声学二次作用，S/O 保持原 F2 二次作用。
- 每源命令幅度上限 20 kPa、相位 [−π,π]；命令幅度平方和不超过原 S 的 8874431.345973747 Pa²（这不是声功率或电功率）；初态局部压力中位数 1 kPa，局部峰值≤1.01×S。实际四源命令全部保存于 JSON。
- 原 17.8/178 nm 接触质量预算；质心步长差≤10 nm；有用额外位移≥50 nm；YZ 目标误差≤0.2 µm；全体 ID 保持、最大连通团比例≥0.9。越界、丢 ID 或断团按协议报告失败，不裁掉失败帧。
- 当前固定 O 在该目标下预计失败。优先把这作为可证伪的控制能力基线，区分“力方向正确”“增量可分辨”“目标可达”，而非再次大规模优化以追求成功图。

之后若提出更长窗口、新控制目标或控制器，应先基于实际场域和受限声压建立独立协议。另一科学优先项是寻找远壁、有完整状态的持续分裂正例并处理瞬时连边步长敏感；不通过平移历史近壁团制造分裂。大型 GPU 工程放在这些适用范围工作之后，暂不做 AI 数据生产。
