## 2. 实际积分顺序与新增代码

依据真实F4/F5/F6、F3稳定归约和launch继承链核实：

1. 同一三线性复声压及梯度产生一次声力，再叠加F2二次声力。
2. 本步起点CFD查询、Stokes自由速度、两轮局部润滑和分量平均平衡。
3. 预测位置后立即执行wall（round0）。
4. 12轮中央PBD，第3、6、9、12轮后各执行wall；共五次wall机会。
5. 终端/声场边界处理、最终几何与扫掠检查、最终CFD查询、事件提交和掩码接受；原F8截面观察器读取真实接受步后推进时钟。

Y1控制始终固定，Y2保留原25ms活反馈和原优化预算，没有用保存波形替代反馈。

独立新增 `src/mevo_mb/fast_sim/f9_ledger.py`：`AuditSimulator` / `AuditFeedbackSimulator`，`audit_enabled=False`默认关闭。主要入口与后处理在 `scripts/fast_pzt_f9/`；机器阈值为 `configs/fast_pzt/f9/protocol.json`；因果数据接口为 `src/mevo_mb/fast_sim/f9_samples.py`。

每步每泡满足SI三维带符号账本：

`dx_accepted = dx_flow + dx_primary + dx_secondary + dx_mobility + dx_pair_contact + dx_wall + dx_boundary + residual`。

flow/primary/secondary是实际起点CFD和力经基准Stokes迁移率得到的自由位移；mobility记录局部迭代和分量平衡相对自由速度的差；PBD/wall取各次真实生产更新前后坐标差；boundary捕捉接受阶段其余位置操作；residual不塞入物理项。本轮四条完整轨迹boundary为零。

GPU float64每步归约团均值、逐泡累计和逐泡最大残差；256步有界buffer，最多256×N×5稀疏非零墙事件，每0.5ms原保存点批量传回。没有每物理步CPU下载。超容量显式失败，不截断。

墙事件保存真实step/time/dt/ID、前后位置、矢量、长度、间隙、轮次、前一段PBD矢量、原面ID和法向。面索引对应 `prepared_geometry.npz: faces[labels==1]`。

**元数据限制：**原生产kernel未改，审计以相同guard/缓存再次执行只读原wall_query获取面和法向；不是由改写的生产kernel直接发出元数据。每事件以实际前后差核对 `min(gap,0)*normal`，误差≤2.17×10⁻¹⁹m；CPU另从原顶点独立验证法向。没有重网格化。

主账本只含成功接受区间；失败/拒绝区间另存。自适应回滚、完整状态重启未准入；失败区间内临时GPU逐ID累计只用于诊断，不提供为成功样本。正式轨迹均无拒绝。账本是**同一数值轨迹的恒等式**，不是独立物理因果实验；减去wall不能还原“无墙真实轨迹”，因为后续位置、排列和受力都依赖它。
