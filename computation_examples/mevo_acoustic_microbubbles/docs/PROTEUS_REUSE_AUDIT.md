## Concrete model differences and dependencies

`simple_RP.m` explicitly references Marmottant 2005 Eq. (3), includes the gas radiation correction and shell viscous stress. `calc_surface_tension.m` clips the elastic law between zero and water tension; it does not add a rupture-history state. `getShellProperties.m` sets chi = 0.55 N/m and uses a Segers 2018 radius-dependent shell viscosity fit, `1.5e-9 exp(8e5 R0)` kg/s. These are **not** measurements from the requested SonoVue 2009 paper. The source warns outside 1–4 micrometres. The Segers polynomial branch references a file `fit_SigmaR_04-08-2017.mat`; the checked-in evaluated tables use other filenames, so direct execution requires checking that path, not assuming it works.

`calcBubbleResponse` uses MATLAB `ode45` (setting `BDF` in options does not turn ode45 into an implicit BDF solver), adaptive integration, pressure interpolation, timeout callback, and dimensional conversion. No Python/C/C++ radial implementation was found in the audited checkout. MATLAB >= R2019b, k-Wave 1.3 and its separately licensed binaries are the recommended upstream environment. Musubi/APES is needed only to generate new LBM flow data. vtkToolbox is required for the VTU-to-MAT workflow.
