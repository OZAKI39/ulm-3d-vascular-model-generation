# 实验室参数核对清单

原始来源为用户对新直管实验的描述；`MEASURED` 表示用户确认了该描述，
不表示已经取得带误差条的量具测量或声压校准。实际字段见
`configs/straight_tube_exp1/lab_parameters.yaml`，独立演示值见另外三个 YAML。

| 待核对内容 | 当前处理 |
|---|---|

| 管长、壁厚、管壁材料 | 实验值null；演示20 mm、0.1 mm；材料不假设 |
| 管内液体、管外水/凝胶/PDMS/agar/空气等 | 真实介质未知；仅均匀水演示 |

| 约3 mm的参考面、三个实际中心和法向 | 暂定发声面到外壁/端面 |
| 端部PZT在何端；两端开放/封闭/接注射装置 | 暂定X+端；两端开放，越界停止 |
| PZT频率、波形、占空比、电压、独立相位 | 实验值null；2.5 MHz、同相连续波仅演示 |
| 发声面/管腔水听器声压与电压对应关系 | 未校准；数值源Pa不等于局部Pa或电压 |
| 管材和耦合介质声速/密度/衰减；PZT背衬/边界 | 预留字段；未实现真实材料声学 |
