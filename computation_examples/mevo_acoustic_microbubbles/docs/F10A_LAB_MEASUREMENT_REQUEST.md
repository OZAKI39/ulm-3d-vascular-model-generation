# 请协助补充 PZT 与微泡实验信息

我们正在比较声音能否推动微泡团。以下信息用于让电脑计算接近实际实验；暂时没有的项目请填 `NOT_PROVIDED`，大致范围也可以，请注明估计或实测。

1. PZT 的型号、尺寸、数量、相互位置和中心频率是什么？能否提供布局照片或尺寸图？
2. 信号发生器的电压、频率、各路相位、每次脉冲长度、占空比和总照射时长是多少？电压是峰值、峰峰值还是 RMS？有没有功率放大器？
3. 是否用水听器测过声压？若测过，水听器型号是什么？
4. 声压记录表示峰值负压、峰值幅值还是 RMS？单位是什么？
5. 声压在哪里测的、用什么介质？有没有空间分布图、水听器校准文件和日期？
6. 用哪种微泡制剂？半径或直径分布、浓度和配制后等待时间是多少？请明确测的是半径还是直径。
7. 开声后多久开始聚集？多久能看出整团移动？移动距离大致多少？
8. 连续或重复照射后，是否看到微泡缩小、破裂或消失？大概在什么设置和时长下出现？
9. 有没有观察靠壁的运动？管道尺寸、液体类型和流速大致多少？
10. 可以提供原始声压波形、照片、视频、尺寸标尺、拍摄帧率或实验记录吗？

可选填写 `configs/fast_pzt/f10a/lab_measurements_template.json`。目前所有实验字段均为 `NOT_PROVIDED`。这不是已完成的硬件校准，也不是声压安全证明；请由项目负责人自行转发。
