## 原模型及批量隔离

仍使用 32 等径泡、R=1.78 µm、f=2.5 MHz、原 APECSS 八谐波表、四 PZT 原基底、一致三线性梯度、F2 成对近场、M0 Stokes＋两轮局部润滑、原十二轮中央 PBD、五次墙约束机会、原 CFD 四面体查询。物理步长 10 µs，时长 10 ms，每 50 µs 保存完整状态，共 201 帧。

`FullParticleBatch` 继承 `F6Simulator`，没有复制完整求解器。生产位移、相互作用和原质量计算逐步调用原实现。成对 kernel 的 `b*n+i/j`，局部润滑/PBD/最终几何的 `start=(i//n)*n`，有序分量平衡的组内循环已检查。所有 batch 成员各有真实固定 ID、位置、力、压力、自由速度、质量及连通事件。

只读几何、CFD、响应表及基底共享。一个 batch 共用合成声场、同步物理钟和控制日程；**不支持同 batch 完全独立或异步 PZT 控制**。`control_families` 按完整日程的规范 JSON SHA-256 分组，保持用户 sample_id、完整坐标及 split_group，再按最多 64 条分块；不同控制家族顺序执行。接口检查验证三家族、成员顺序、分块和重复 ID 拒绝。

事件缓冲为 `max(200000,20000*B)`，只下载实际使用前缀，事件保留 batch/泡对/开关/物理时间并排序；溢出仍是错误。时钟和控制共同是明确支持范围，不伪装成异步成员时钟。

**原设备错误位仍是整批共享的 fail-stop。**任一成员错误拒绝整批，不静默丢弃，不把别的成员标为合格。局部接触、CFD/墙诊断可归属到 sample_id；若原全局位缺乏局部证据，状态保持 `ABORTED_BATCH`，不虚构根因。实际软件故障注入把成员 `bad_C` 移出 CFD，得到其独立局部失败证据，A/B/D 为整批中止，全批坐标不接受更新。该故障检查不是物理轨迹。

## 串行与批量数值结果

先 B=1、4、16，再在 B16 数值通过且共享负载观测有明显收益后检查 B64。每个 B 都实际执行 B 条原 F6 串行轨迹和一次 B 条批量轨迹，没有复制输出冒充积分。四种基准初态为同一 F10A 初态在 Y 上平移 0、+0.2、−0.2、+0.4 µm，较大 B 循环复用；均为 `BENCHMARK_ONLY`，不构成独立训练家族。

逐成员比较 57 个数组/检查项：时间、完整 ID 坐标、压力、力、自由速度、CFD 状态、逐泡质量/接触、壁面/失活、Rg、张量、长短比、组件、Kabsch 形变和排序边事件。**零容差逐位相同，85/85 对照通过。**新完整 OFF/S/O 的全部 201 帧也逐位重现 F10A 原 10 µs 结果；B64 冷启动复核同样全部一致。初态变体是数值隔离检查，未称作独立科学重复实验。

此内部工况没有观察到连通团分裂/合并；泡对连边确实发生变化，原 O 163 条、S 196 条边事件全部保存。没有用“所有保存帧都是 32/32 连通”代替边事件核对。通过不代表 F10A 逐泡排列已得到步长收敛或物理校准。

## 纯运动分解

可选诊断 kernel 每个物理步从完整真实状态计算 `x_i=Xc+r_i`、`U_i=Ubar+Urel_i`，U 包括原分量平衡。原 predictor 仍使用原 U，两个分量不形成独立长期状态，不限制旋转、形变或分裂。

全 10 ms O 轨迹及所有比较数组与原路径逐位一致。最大重构残差：位置 `9.47e-22 m`、速度 `8.67e-19 m/s`。这一恒等分解没有速度收益；本次积分/质量约 0.630 s，另有首次新 kernel 编译/图捕获成本。它是诊断能力，不是刚体或多尺度动力学替代。

## 多速率实现与守卫

Q0=(声学1,CFD1)，Q1=(2,1)，Q2=(1,2)，Q3=(2,2)。声学缓存的是各泡复压力、八阶体积谐波、一致梯度及一次力。F2 泡间距离、闭合、二次力、润滑、PBD、壁面和接受检查仍逐步执行；因此缓存响应仍可能改变内部近场力，不能称完全等价。

跳过声学更新的候选步仍查询当前位置复声压，检查场域和有效响应区间，维护实际压力极值。跨声场单元或出现连边变化时刷新；距墙保守下界不足 100 µm 则拒绝。CFD 缓存只改变自由速度右端，**原最终提案 CFD 合法性查询仍每个物理步执行**。跳过当前查询时核查当前位置仍属于已验证四面体、有效位、活跃位、剪切和壁距；单元/连边变化时使用上一接受提案在当前 x 的已验证速度刷新。未知域外速度不会维持旧值或当成零。

PZT 任意控制事件令缓存阶段归零并清除相应图；dt 改变也重新开始阶段及图。图 key 加入缓存周期阶段，解决五步保存区间与两步更新周期错位；这只是原 CUDA Graph 的必要缓存有效性扩展，不是重新发明 Graph。

保存的 F9 近壁、F5 高剪切和分散状态由 `admit_cache` 静态拒绝，OFF 内部状态可做数值检查。实际设备故障测试覆盖表外压力、声场域外、过期 CFD 四面体、O/OFF/S 切换和 dt 改变。当前缓存只作为受限探索候选，不是已准入的通用接口。

## 预登记及实际拒绝

协议提交 `bcedae26b7bd79f33b6a3d2dfef277e93a4f7772` 早于全部批量/缓存实验。批量要求逐位一致；团级要求最大质心三维差及配对 Z 差均 ≤10 nm。形态单独要求最大 ID 差 ≤0.1R=178 nm、Kabsch RMSD ≤0.05R=89 nm、Rg ≤1%、张量/长短比 ≤2%、最大组件比例一致、边事件及时间完全一致。原残余重叠 ≤0.01R、单轮 PBD 修正 ≤0.1R 不变。

## 数据与 AI 接口

新 HDF5 保留原 `positions_m/time_s/particle_id/radii_m/metrics/edge_events`，并提供 `source/medium/flow/bubbles/control/trajectory/morphology/quality`。身份记录 batch_id、sample_id、batch_size、图开关/块长、两种更新 stride、有效控制、真实dt、逐成员质量、数值模式、源码及输入哈希、有效数及耗时吞吐。每个成员 `[time,batch,ID,xyz]` 可独立恢复。

保存力/压力/自由速度位于该保存帧最后一个子步输入时刻 `t−dt`，位置为接受时刻 t；初始力缓冲尚未计算，明确为零。CFD保存速度是接受提案查询，壁距记录为原每步合法性检查提供的保守下界，未冒充额外精确墙查询。这些时间/观测定义写在 HDF5 身份中。

所有重复、平移初态、控制分支、步长或数值模式保留同一 `split_group=F10A_translated_original_Y32`。`EXPLORATORY / PHYSICS_UNCALIBRATED / training_ready=false`。现有 HDF5 的耗时字段需连同 `RESOURCE_CONTENTION_AUDIT.txt` 和性能报告阅读：早期记录是共享负载观测；`exclusive_v1_batch/cold` 为独占复测，区别见清单的 performance_scope。两者均不构成稳定产量保证。
