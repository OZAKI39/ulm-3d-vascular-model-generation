# F10E：密集团逐轮接触诊断

本报告使用原始 `CONTACT_TRACE.json.gz`，单位与误差来源分别保留。残余重叠预算为 **17.8 nm**，单轮位置修正预算为 **178 nm**。预测侵入是自由／润滑运动形成的处理前提案，不与末轮接受预算混为一谈。

## 被动观察与首错语义

`ContactAuditBatch(ContactTrace, FullParticleBatch)` 复用原生产计算。窗口前仍从原始初态积分；窗口内用同一 kernel 序列，读回每轮 PBD 前后位置、实际修正向量、两轮润滑速度、一次／二次力、逐对力、八谐波、复压力、墙面操作、最终提案及错误。每个物理步检查一次原错误和原预算，首错立即停。只保留最后 32 个审计步，不增加积分步或额外声力。完整 C1 使用同一逐步原质量检查，但关闭逐轮读回。

C0 的 seed1104 准备第 224 步（2.230→2.240 ms，ID 24–28）和 O/1102 第 490 步（4.890→4.900 ms，ID 28–31）均触发 2048。四次原模式隔离的共同前缀、两次 C0 观察开关回归及 C1 短窗／完整关闭读回的共同前缀均通过。原 50 µs 保存之外，诊断文件保留精确子步；完整轨迹 HDF5 仍使用原 50 µs 保存频率，不将失败步加入接受轨迹。

seed1104 原拒绝区间结束提案不是首错时刻的同一个提案：错误后原图块中剩余一步还会运算。原 17.831265 nm 与新首错 17.830785 nm 的微小差异因此不用于否定已验证的接受前缀。原拒绝记录继续保留，未被覆盖。

## 相邻接触的重分配

O/1102 第一轮中，ID 0–6 重叠从 3.934691 增到 5.628403 nm，同时相邻 6–7 重叠下降；ID 0–8 从 0.300767 增到 12.843244 nm，同时 8–17 下降。准备1104 中 2–24 从 20.291982 增到 21.901656 nm，同时 2–11 下降。这些来自同一轮 Jacobi 同时更新后的真实位置，支持接触链耦合的解释，不能伪称顺序推挤算法或仅凭一个示例认定全部失败原因。

O/1102 修正路径最多的四个 ID 合计占该失败步约 17.78%；准备1104 为 24.87%。修正没有只集中到触发阈值的那一对。实际逐 ID 修正路径、每轮最差泡对和最多12个重分配示例保留于 `analysis/CONTACT_ANALYSIS.json`；原始全部位置和逐轮向量都在压缩轨迹中。

## 近场和润滑实际输入

两例墙面修正均严格为零，当前内部位置的失败不能归于墙面推回。O/1102 首错步的一次力最大约 9.321e−13 N、二次力最大 4.848e−10 N；准备1104 分别约 5.634e−13 N、2.524e−10 N。这些是不同泡的各类力范数最大值，不把二者之比冒充每一泡的力比例。

原二次逐对力保存完整方向与泡 ID。以原实际复压力和八谐波做独立 NumPy 参考计算，所有检查的最大绝对差约 2.6e−25 N，远小于力本身。F2 反馈闭合最小行列式模约 0.975，未接近 1e−6 的奇异拒绝值；O/1102 首错步耦合有效压力最大 2267.835 Pa，准备1104 为 1709.586 Pa。代数闭合不奇异**不意味着密集团近场声学准确**：仍是成对基频反馈、其他谐波保持原响应、几何平滑核；没有集体径向响应、多极展开或实验校准。

O/1102 有 42 个局部润滑泡对使用原间隙下限，准备1104 为 35 个。原两个松弛 Jacobi 局部迭代并未成为全局收敛求解：将实际局部速度代回相同法向阻力方程，再按各泡 3×3 局部块预条件，最大残差约为最大自由速度的 18.56% 和 15.19%。未预条件的残差因很大的阻力系数而被放大，报告中另行保留，不将其夸大成真实速度误差。

这项代数检查先从每轮实际输入重建原两次 3×3 更新，与 GPU 输出最大差约 1.7e−14 m/s。NumPy LAPACK 与 Warp 显式逆的舍入不同；只读参考核对使用 1e−12 m/s（1 pm/s）容差，**不是改变积分质量预算**。没有进行新的全局流体求解，也没有把该代数残差当作实测水动力误差。两轮局部近似、间隙下限和对角 PBD 度量的一致性仍是后续问题。

## dt 与轮数的有界结果

在同一 4.900 ms 物理时刻，C1 5 µs／12 轮侵入 56.460 nm、残余 11.721 nm；C2 10 µs／24 轮侵入 107.215 nm，第12轮残余12.513 nm、第24轮3.466 nm；C3 5 µs／24轮侵入41.406 nm、末轮0.947 nm。各设置历史已从共同原始初态独立演化，不能把跨方案差异全都归为同一瞬时状态上的单参数效应。

三种替代窗口都通过到5 ms。仅按登记顺序选择C1完整重放到10 ms，最大末轮残余13.116 nm、最大单轮修正28.967 nm，均通过原预算。C2/C3没有长期证据。本轮没有出现 F10B 3 kPa 案例那种“残余通过但单轮修正超限”的新失败；必须保留这两个标准的区别，不能将历史案例的机制直接套过来。

## 形态与准入限制

C1在与C0共同接受的4.850 ms前缀内，最大质心差0.882 nm，但固定ID位置最大差2.046 µm，跨方案Kabsch RMSD最大0.832 µm；实际接受边事件124→126。C2/C3也改变内部排列，C3最大ID差4.805 µm。所有保存帧仍是一个32泡团，只能支持“这些数值轨迹保持几何连通”，不能支持“内部形态不受算法影响”。

工程上的接触预算通过、内部形态收敛、声学／水动力物理校准是不同验收。C1仅是 `M0_DT5_PBD12_EXPLORATORY` 的一个完整数值样本，C2/C3仅短窗样本；均不是新默认或训练真值。
