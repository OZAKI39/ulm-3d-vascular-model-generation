# F10B 团级代理的范围与拒绝契约

版本 `f10b_centroid_v1`，独立模块 `src/mevo_mb/fast_sim/f10b_surrogate.py`。这是针对当前M0离散模型的工程近似，仍为 `MODEL_EXPLORATORY / PHYSICS_UNCALIBRATED`。没有独立初态或实验校准，`training_ready=false`。

## 方程及真实前提

G0只采样质心：`dXc/dt = u_CFD(Xc) + F_primary(Xc)/(6πηR)`。

G1取32个真实初始相对位置 `ri0=xi0−Xc0`，独立推进 `dXc/dt = mean_i[u_CFD(Xc+ri0) + F_primary(Xc+ri0)/(6πηR)]`。虚拟坐标只用于查询，标记 `FROZEN_TEMPLATE_ASSUMPTION`，没有旋转、逐泡动力学、PBD或二次力求解。未锁定原逐泡求解器的粒子，没有拟合位移倍率或添加目标速度。

复用原始四PZT底稿、严格四面体P1 CFD、原APECSS表和相量约定 `Re[P exp(+iωt)]`，一次力为 `−0.5 Re[V1 ∇P*]`。梯度来自同一个三线性复声压。生产参数是Tu图4插值：χ=.2932519822 N/m，κs=4.619149127e−9 kg/s，σinit=.036 N/m，R=1.78 µm，f=2.5 MHz；不是Tu表2的.30/3.2e−9。

在等半径、对角Stokes迁移率、全32泡活跃、无壁面/出口修正下，F2成对力等大反向；当前局部润滑的分量均值平衡保持自由速度均值；中央PBD等大反向位置修正保持质心。源码与保存账本/实际生产探针均核对。抵消是**直接带符号团均贡献**，不排除内部重排间接改变后续场采样。

RPY的构型相关迁移率行和不同，即使内部力总和为零也不保证团均速度为零。F7原结果保留；未把本近似推广到RPY，也未宣称自由空间RPY是近壁真值。

## 数值准入与当前结论

预登记协议在 `configs/fast_pzt/f10b/protocol.json`，提交 `a322c0c44` 早于全部预测。误差门槛未调整：末端Z≤20 nm、全程Z≤30 nm、末端三维≤50 nm，O−OFF与O−S方向为正，无数据域越界。

三控制OFF/S/O、同一F10A内部初态、独立10 ms预测中：G1全部通过；G0开声两例失败。`admit`返回的 `ADMITTED_FOR_SHADOW_TEST` 仅允许受控影子评估，不等于生产或训练授权。当前只有G1获得这组数据的 `surrogate_numerical_admission=PASS`；G0不应进入生产。

准入同时要求：

- 同一已验证32等径成熟初态/模板与控制白名单，M0，原CFD开启，预测时长≤10 ms。
- 原成熟历史：F5 290–300 ms的21帧均32/32连通，Rg相对范围0.11075%；F10A平移保留相对位置。此为过去历史，不读取未来预测参考。
- 初始泡面壁距≥100 µm、最大应变率√(2D:D)≤2/s、Rg在4–6 µm、32/32连通、实际局部峰值声压≤1.5 kPa。
- 表、场及CFD有效，全泡活跃，无出口或明确快速形变/分裂需求，未标记已知接触失败。
- 初始壁距减1.5倍初始最大流速×预测时域仍≥100 µm。运行时累计质心路径≤200 µm且小于初始壁距减100 µm，以距离的Lipschitz界保护冻结模板；每物理步检查场、CFD、表、声压、剪切及有限值。场边界按完整初始模板包围盒加半径内缩。没有墙投影或域外外推。

这组几何、压力、剪切门槛不是普适物理标准；通过门槛不等于任何新初态都已验证。白名单和历史证明由调用层核查，不能把任意输入的 `validated_initial=True` 当成自动泛化认证。数学上安全的是虚拟模板，不是未计算的真实形态。

## 必须拒绝

已有实际状态测试包括F9近壁、F5关声剪切分散末态、F7 RPY和F10A 3 kPa初态，全部 `SURROGATE_NOT_ADMITTED`。拒绝例只做静态判定，没有代理轨迹。F7实际无流，图表中的施加剪切为零；旧 `checks_v1` 误把同位置未施加的CFD剪切用于该行，`checks_v2` 修正并增加CFD-OFF拒绝条件，保留原记录，六条CFD-ON预测不受影响。

F5关声后真实Rg增长和分散没有被冻结模板覆盖；G1不生成任何Rg演化、合并、分裂或真实粒子位置。输出HDF5仅含时间、质心和身份/适用范围元数据，初始模板仅是静态假设。完整模型计时旁存的逐泡验证数据明确为 `FULL_PARTICLE_REFERENCE`。

## 多尺度切换边界

已实现独立候选和准入检查，支持从真实成熟初态开始影子预测。影子模式复用完整轨迹评估误差，本身不计为生产节省。没有双向生产切换、刚体锁定或模板重入为真粒子状态的接口。质心代理丢失内部状态，重入必须是明确的近似重建，再用独立短轨迹评估误差。

值得继续研究G1，但先解决输入准备复用和独立初态验证。当前单样本完整主体仅1.815倍，未达到2倍工程门槛；不应立即大批生成训练数据或升级形态控制。

## 文献用途

[Wajnryb等RPY论文](https://arxiv.org/abs/1307.7312)提供迁移率背景，不能替代本工程单独的质心抵消审计。[XPBD原文](https://mmacklin.com/xpbd.pdf)讨论PBD时间步/迭代数相关性，仅作方法背景，本轮没有实现XPBD，也没有将图形学方法视为微泡接触校准。本轮结论主要来自项目源码、原F9账本和新增有限对照。Marmottant/Tu的生产参数身份沿用F10A的物理证据与输入哈希，没有新算径向表或声场。
