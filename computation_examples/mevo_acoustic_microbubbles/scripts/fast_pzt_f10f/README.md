# F10F reproduction

Use the existing Python environment and PYTHONPATH=src:.
remote.py deploys committed source only to independent snapshots and unique
Supervisor labels, refusing an occupied GPU. checks and failure_checks are
bounded engineering regressions; trials uses the original two F10E case
identities after checking the registered engineering PASS.

analyze and figures read archived outputs; no solver run is needed to regenerate
the four PNG/PDF groups. archive verifies remote source and input hashes, copies
the small result tree and checks every file locally against SHA-256.
verify checks scientific accepted states, first rejection, protected history,
input hashes, visual review and progress preservation.

delivery is tied to the original progress document checksum; it appends once and
refuses to overwrite subsequent user edits. No historical default model changes,
long-run retry, new seed, SS12, batch admission or GitHub push is implicit here.
