# F6 retained evidence

This folder contains real newly executed F6 results, not relabeled F5 data.
Formal navigation source: `2caf8d8884c8b1cb2bde5dc7fb9ec5b5d0be30c2`.
The fixed F5 input/source baseline and historical old runs remain separate.

- `navigation_v1/`: frozen17-case protocol, full HDF5, actual controls and source
  identities, numerical/navigation summaries, complete campaign timing.
- `navigation_v1/analysis/`: separate numerical/scientific gate, timestep and
  causal contrasts, full data-interface validation, English PNG/PDF figures.
- `admission_v1_checks/`, `admission_v1_efficiency/`: final gradient/F5-prefix/RPY,
  adaptive-event/rollback and two-sample batch checks before formal integration.
- `preflight_v2/`: geometric targets written before static control screening;
  the final formal protocol also includes feedback, dt and split amendments.
- `reference_v2/`: independent pinned APECSS low-pressure radial/translation
  outputs, local switch protocol and convergence. `table_audit/` compares these
  with the actual unchanged production table and contains a third figure.
- `short_v*`, `diagnostics_v*`, `checks_v1`–`checks_v5`, `reference_v1`: retained
  pilots/failures and minimal diagnoses, not silently promoted to accepted data.
- `ENVIRONMENT_CURRENT.txt`: freshly measured server environment and input hashes.
- `HISTORY_PRESERVATION.json`: unchanged inherited sources and original article hash.
- `ARCHIVE_VERIFICATION.json`: exact closed server files and Git source hash audit.
- `ARTIFACT_MANIFEST.json`: complete local result inventory, excluding itself.
- `progress_document/`: user-requested research narrative backup, minimal diff and hashes.

The final numerical acceptance passes; target navigation is supported only for
the stated no-flow local-mobility feedback model (10/5µs). Slow-flow dwell misses
50ms, Y-CFD controls fail to reach, RPY changes the outcome, and old gradient dwell
also fails. All physical evidence is EXPLORATORY; correction stays UNCALIBRATED.

Failed checks include development-time domain-boundary/Warp compilation issues,
an APECSS build environment issue, and contact-budget failures at10/5µs. The
successful final admission and preregistered2.5µs controls are distinguishable by
their unique labels and execution SHA. A local plotting audit's initial Python
complex-scalar error is retained separately and affected no scientific trajectory.

Only third-party dependencies/build trees, caches and environment binaries are
omitted. The existing field/response/CFD inputs are reused via the F5 manifest;
their bytes are already present in the fixed baseline. There are no decorative
videos, random parameter campaigns or hidden force multipliers in this delivery.
