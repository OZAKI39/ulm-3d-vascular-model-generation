# 1. 本轮最重要的科学定义

## 1.1 研究的是群体形状，而非单泡振荡

这里的“形状变换”指微泡群的三维空间分布和二维 XY 投影形态。

不是单颗微泡在 MHz 下的快速半径振荡。

必须区分：

**A. 整体平移**

群中心移动，但相对坐标基本不变。

**B. 刚体旋转**

群体朝向改变，但各微泡相对距离保持不变。

**C. 各向同性压缩／膨胀**

整体空间尺度减小或增大，形状比例基本不变。

**D. 各向异性拉伸／压缩**

某个主轴方向的尺度相对另一个主轴发生明显变化。

**E. 剪切或非刚体内部重排**

群内部发生不能通过整体平移、旋转和统一缩放描述的变化。

**F. 局部聚集**

原本分散的微泡局部接近，形成新的几何邻近连接。

D、E 比单纯的 C 更接近真正意义上的形状控制。

不能把任何 Rg 减小都解释为成功的主动形变控制。

不能把群体旋转导致的协方差矩阵分量变化误判为形变。

# 3. 第二阶段：建立严格的群体形状评价系统

这是本轮必须首先完成的核心模块。

## 3.1 三维真值与 XY 投影

对 N 颗固定 ID 微泡记录：

\[
\mathbf c(t)=\frac1N\sum_i\mathbf x_i(t)
\]

以及去质心坐标：

\[
\mathbf y_i(t)=\mathbf x_i(t)-\mathbf c(t)
\]

三维形状协方差：

\[
Q_{3D}(t)=\frac1N\sum_i\mathbf y_i(t)\mathbf y_i(t)^T
\]

二维 XY 协方差：

\[
Q_{XY}(t)=\frac1N\sum_i\mathbf y_{i,XY}(t)\mathbf y_{i,XY}(t)^T
\]

必须同时保存：

- 三维群中心；
- XY 群中心；
- 三维 Rg；
- XY Rg；
- 三维协方差特征值；
- XY 协方差特征值；
- 主轴方向；
- 主轴长度；
- 长宽比；
- 群体空间尺度；
- 粒子间距分布；
- 最小中心间距；
- 几何邻近网络；
- 接触事件；
- 连通分量。

注意：

二维投影重叠不代表三维微泡发生接触。

若主轴对应特征值相近，主轴方向可能数值不稳定，必须标记 `ORIENTATION_UNIDENTIFIABLE`，不得将随机主轴旋转解释为真实主动旋转。

## 3.2 去除刚体运动

必须实现最佳刚体配准，例如 Kabsch/Procrustes 方法。

对同一批固定粒子，拟合从初始状态到当前状态的最佳平移和刚体旋转。

计算：

- 未配准位移；
- 去平移位移；
- 去平移＋旋转位移；
- Kabsch RMSD；
- 成对距离变化；
- 刚体配准后的残余内部变形。

如果配准后残余接近数值误差，应该归类为刚体运动，而不是内部形变。

## 3.3 分离压缩、拉伸和剪切

在初始位置具有足够空间秩的情况下，可以拟合局部或全局仿射变换：

\[
\mathbf y(t)\approx F(t)\mathbf y(0)
\]

对 F 使用极分解：

\[
F=RU
\]

其中 R 表示旋转部分，U 表示伸展部分。

分析：

- 各向同性尺度变化；
- 主方向伸展；
- 形状各向异性；
- 对称剪切应变；
- 旋转；
- 非仿射残差。

如果 F 的估计病态、初始位置退化或拟合质量不足，必须返回无效状态，不得强行计算主方向。

对于较大的非仿射重排，不能只用一个 F 概括所有内部动力学。

建议以协方差、成对距离变化、仿射形变、非仿射残差四类互补指标共同判断。

## 3.4 与视觉系统的状态接口

未来需要与 F10Y 视觉观测对比，但本轮仍然是仿真。

允许导出：

- `SIMULATION_3D_TRUTH`
- `SIMULATION_XY_PROJECTION`
- 兼容二维观察定义的群中心、Rg、Q、分布与相对运动。

不得把直接 XY 投影标成真实 Chronos 图像或真实可检测微泡。

没有成像 PSF 和焦深校准时，不应做虚假的光学准确度结论。

# 8. 第七阶段：研究主动形变是否真实存在

本轮不能只回答“Rg 有没有变化”。

必须建立动作—形状响应矩阵。

例如对每条完整轨迹计算：

\[
\Delta z=
[
\Delta c_x,
\Delta c_y,
\Delta R_g,
\Delta \lambda_1,
\Delta \lambda_2,
\Delta \theta,
\Delta s_{\mathrm{shear}},
\Delta e_{\mathrm{nonrigid}}
]
\]

这里的具体形态变量应使用实际数值稳定的定义。

对于 \(\lambda_1\approx\lambda_2\) 的圆形状态，主轴角度应标记无效。

应分开记录三维真值和二维 XY 投影。

## 8.1 主要研究问题

**Q1：同一种初始形状下，不同 PZT 动作是否产生不同形状变化？**

**Q2：对同一种动作，不同初始形状是否有显著不同响应？**

**Q3：是否存在主要改变群中心、很少改变形状的动作？**

**Q4：是否存在主要改变形状、很少移动群中心的动作？**

**Q5：是否有 PZT 动作能够使 X 拉长群变短、Y 拉长群变长，或者产生相反的各向异性趋势？**

**Q6：形变信号是否明显高于数值误差？**

**Q7：形态变化是否在多个独立初态上重复出现？**

**Q8：形变是否只有暂态，还是能够持续？**

所有答案必须建立在实际轨迹和对照数据上。

## 8.2 特别关注的控制目标

寻找两种不同声学动作：

\[
u_A,\ u_B
\]

使其群中心位移相近：

\[
\Delta \mathbf c_A \approx \Delta \mathbf c_B
\]

但内部形状响应明显不同：

\[
\Delta z_{\mathrm{shape},A}
\not\approx
\Delta z_{\mathrm{shape},B}
\]

如果能够找到，并且通过数值和独立初态验证，这将是未来位置—形状解耦控制的重要依据。

反过来，如果所有动作只导致相似的各向同性收缩，也必须正式报告：

`SHAPE_CONTROL_MODES_NOT_IDENTIFIABLE`

# 9. 第八阶段：形状可控性与动作灵敏度矩阵

当实际物理轨迹存在可辨识的形状响应时，进一步研究局部动作可控性。

## 9.1 有限差分响应

在合法幅值和相位邻域内，估计：

\[
J_{ij}
=
\frac{\partial \Delta z_i}
{\partial u_j}
\]

注意：

- 幅值和相位有不同单位；
- 相位是周期变量；
- 多 PZT 有共同相位参考；
- 不同参数需要合理归一化；
- 不能跨越非法动作范围；
- 数值扰动必须超过求解噪声；
- 不能仅靠单边有限差分得出全局结论。

需要检查：

- 局部响应矩阵；
- 奇异值；
- 有效秩；
- 条件数；
- 动作方向冗余；
- 对初始形状和时间窗的敏感性；
- 数值差分收敛性。

如果响应矩阵接近秩亏或病态，必须明确报告。

**局部响应秩不足，意味着目前的候选动作或观测时间窗可能无法分别驱动所有形状自由度。**

但局部矩阵不能证明非线性系统的全局可控性。

## 9.2 形状控制与位置控制解耦

尝试估计：

- 群中心响应子空间；
- 形状响应子空间；
- 同时改变位置与形状的动作；
- 形状变化较大但平移较小的动作；
- 平移较大但形状保持较好的动作。

可使用 SVD 和数值稳定的线性分析。

这些都是诊断工具。

最终控制效果仍必须由完整物理积分检验。

# 10. 第九阶段：有限的形状变换控制尝试

**这是条件性任务。**

只有当前面确实发现具有数值可信、可重复和可区分的形变动作时，才开展。

优先选一个现实的短时目标，而不是立即尝试任意复杂图案。

候选目标：

**T1：保持群中心基本不变，使 X 向细长群更加紧凑。**

**T2：保持群中心基本不变，使泡群长宽比发生指定方向变化。**

**T3：使紧凑群体向特定主轴方向产生可辨识拉伸。**

**T4：移动群中心，但尽量保持当前形状。**

**T5：先形变，再尝试反向作用，使部分形态指标恢复。**

不要求全部成功。

## 10.1 控制代价函数

可构造探索性目标：

\[
L=
w_c\|\mathbf c-\mathbf c^*\|^2
+
w_Q\|Q-Q^*\|_F^2
+
w_R(R_g-R_g^*)^2
+
w_u C(u)
\]

但应明确：

- 各项的物理单位；
- 权重归一化；
- 目标是否在当前模型中可达到；
- 是否可能通过纯旋转或纯平移虚假满足；
- 是否需要增加接触／邻近结构指标；
- 是否存在改变群体成员导致的指标歧义。

不允许通过删去不利指标制造控制成功。

## 10.2 优先采用简单动作设计

先尝试：

- 单段固定动作；
- 两段动作；
- 少量预登记动作序列；
- 有限随机搜索；
- 若有价值，可使用 BoTorch 进行有界黑盒参数搜索。

BoTorch：

https://github.com/pytorch/botorch

不要求立即训练强化学习。

不要求立即训练大型世界模型。

动作序列必须符合 F10S 已有 Schedule 的时序约束，不能超出最多八个合法连续分段等接口条件。

所有候选动作都要实际用完整逐泡物理求解器执行。

优化时不能将先前筛选用过的初始状态全部当作独立测试。

如果形变动作没有通过前述准入：

`TARGETED_SHAPE_CONTROL_NOT_RUN`

必须停止，不得为了交付 AI 控制结果而强行开始。

# 11. 初始连通群与分散体系必须分开分析

这是防止科学结论混乱的重要要求。

对于原本近接触的连通群，可以研究：

- 群中心运动；
- 旋转；
- 内部非刚体形变；
- 接触重新分配；
- 整体形状保持；
- 各向异性压缩或拉伸。

对于初始分散体系，可以研究：

- 相对靠近；
- 局部邻近关系形成；
- 几何连通分量变化；
- 整体分布压缩；
- 局部群体形成。

但是：

**整个分散体系的 Rg 收缩，不应直接称为一个已经形成的泡团发生形状变换。**

必须同时报告：

- 固定粒子集合的形状统计；
- 当前邻近网络；
- 最大连通分量；
- 如果研究某个局部群体，明确该群体成员如何定义；
- 成员随时间变化时如何处理。

对于仿真，可以利用固定 ID 做严格分析。

但不能将其解释为真实显微视觉已经具有固定 ID 追踪能力。

# 13. 使用服务器 CPU/GPU 的要求

F10AA 已经显示当前 N=32／64／128 时，GPU Cholesky 不一定优于优化 CPU。

因此，本轮应默认采用通过验证的 F10AA 最优后端。

**Warp GPU 声学计算＋优化后的 SciPy CPU 动力学与接触求解。**

- N=128 使用经过验证的多线程配置；
- 多个独立初态／动作任务通过多进程并行；
- 根据当前服务器负载调整进程数量。

不能为了展示 GPU 利用率，再次把已被证明较慢的 GPU 力学后端设为默认。

独立轨迹可以并行，同一轨迹物理时间必须严格顺序推进。

## 13.1 计算预算

首先检查当前 CPU/GPU、RAM、显存、现有任务及磁盘空间。

执行短时测速，预登记：

- 总服务器实验预算；
- 单条轨迹上限；
- 最大同时运行任务数；
- 数值失败停止规则；
- 后处理和视频成本。

建议首轮将正式物理计算墙钟预算限制在约 3600 秒以内，单条不超过 240 秒；这是规划上限而非必须用完的时间。

若服务器环境或历史预算规则更严格，应以更严格限制为准。

必须通过减少候选数量、优先级筛选和合理并行控制成本。

不要强制耗尽服务器资源。

# 20. 最终执行顺序

**第一阶段：审查与冻结**

检查 F10AA 最新后端，核对历史结果和数值门槛，创建 F10AB 隔离工作区。

**第二阶段：形状分析工具**

实现三维／二维形态指标、Kabsch、非刚体残差、各向异性变化、剪切与数值有效性测试。

**第三阶段：初始形状库**

建立紧凑、细长、斜向、多局部群与分散微泡合法初态。

**第四阶段：声力与动作筛选**

执行 OFF、单源、双源和少量相位组合的固定状态受力诊断。

**第五阶段：完整物理轨迹**

使用 F10AA 后端运行 0.5–2 ms 动作—形态响应，保留每一步数值验收。

**第六阶段：科学机理分析**

分开分析平移、旋转、整体收缩、各向异性拉伸、剪切及接触变化。

**第七阶段：数值确认与独立重复**

选择有限候选动作进行 dt/cache 对照及新初态重复验证。

**第八阶段：局部可控性**

估计有依据的动作—形状响应矩阵，分析有效秩、方向性与位置—形状解耦。

**第九阶段：条件性形变尝试**

仅在物理响应可辨识时，研究简单动作序列能否使泡群接近目标形状。

**第十阶段：科研交付**

生成全部科研图、MP4、真实轨迹、失败案例、完整中文报告和机器可读 Gate。

# 21. 最终成功标准

本轮最重要的成功不在于生成多漂亮的椭圆、条带或旋转动画。

真正需要证明的是：

**第一，所有微泡位置与形状演化来自原物理模型的完整真实积分。**

**第二，能够明确区分平移、旋转、整体压缩和真正非刚体形变。**

**第三，能够定量说明初始形状对声学响应的影响。**

**第四，能够辨别不同 PZT 动作是否产生不同内部形变模式。**

**第五，形变信号高于数值误差，并且在多个独立初态下得到验证。**

**第六，如果存在有效形变动作，能够利用少量实际声学动作演示有限的目标形状变化。**

**第七，如果不存在有效形变，能够通过力学、接触、声场梯度和可控性诊断解释其可能原因。**

**第八，不将均匀水代理的结果冒充真实 PDMS 声场或真实 PZT 实验结果。**

最后必须用一句话回答：

**在当前 2.5 MHz 四源均匀水声场代理下，是否已经存在经过数值验证、不同动作可区分、能够在有限时间内改变微泡群形状的控制自由度？**

如果答案是否定的，必须诚实地报告，并指出缺少的是声场空间梯度、动作独立性、物理时间尺度、模型机制，还是仅仅缺少足够的数值证据。

**不要提前训练大型世界模型、强化学习或 MPPI 来掩盖物理形变机制尚未确认的问题。**

请立即开始 F10AB 的实际科研开发、服务器仿真、科学分析、图表与视频交付。
