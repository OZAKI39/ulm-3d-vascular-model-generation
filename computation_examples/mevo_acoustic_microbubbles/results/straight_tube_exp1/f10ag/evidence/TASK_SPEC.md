# 3. 第一研究主线：X 双源三维声学吸引域

这是本轮最高优先级。

## 3.1 不只检查 X 方向的力零点

过去 F10AF 已发现 X 方向的恢复力零点。

但是：

\[
F_x=0
\]

不等于：

\[
\mathbf F=(F_x,F_y,F_z)=\mathbf 0
\]

更不等于三维动力学稳定。

必须检查完整三维声学力与受约束运动。

重点回答：

**微泡被吸引到某个 X 位置时，会稳定停留在某个条带区域，还是随后沿 Y/Z 方向移动并离开该位置？**

## 3.2 单泡和多泡研究分开

**单泡研究：**

使用 F1 声学力及该模型适用的阻力描述，分析声场的局部动力学结构。

不加入人为 F2 相互作用。

**多泡研究：**

使用完整 F1/F2、原始阻力以及必要的硬球接触。

不能将单泡吸引域直接当成多泡系统的真实聚集吸引域。

## 3.3 局部稳定性

对已定位的 X 恢复位置，在合法三维空间中估计动力学漂移场：

\[
\dot{\mathbf x}=\mathbf v(\mathbf x)
\]

及其局部 Jacobian：

\[
J_v=\frac{\partial\mathbf v}{\partial\mathbf x}
\]

分析：

- X 向稳定性；
- Y 向稳定性；
- Z 向稳定性；
- 耦合位移方向；
- Jacobian 特征值；
- 可能的鞍点；
- 中性方向；
- 墙面附近作用。

需要区分：

`X_TRANSVERSE_RESTORING`

`FULL_3D_ATTRACTOR`

`TRANSVERSE_ATTRACTING_PLANE`

`SADDLE_OR_UNSTABLE`

`NUMERICALLY_UNRESOLVED`

如果仅 X 方向恢复，而沿 Y/Z 运动没有约束，不得宣布已经发现完整三维稳定陷阱。

对于条带面，可以研究是否具有横向吸引和面内相对中性运动；不应机械地要求所有方向都有单点稳定性。

## 3.4 三维吸引域

在合法声场内，选择多个三维初始位置。

从这些位置执行有界动态积分，建立：

- 初始位置；
- 最终位置；
- 吸引到哪条 X 恢复区域；
- 是否离开合法空间；
- 是否碰到壁面；
- 捕获是否成功；
- 捕获时间；
- 是否在观察时间内保持；
- 对初始 Z 的敏感性。

输出三维吸引域图谱。

必须区分：

**单泡声学力近似吸引域**和**多泡完整动力学确认的捕获区域**。

前者只是筛选依据。

# 4. 第二研究主线：条带形成需要多长时间？

## 4.1 研究形成时间，而不是假设形成

F10AF 中，最大逐泡位移为十几至几十微米，而条带间距约为 304 µm。

不能据此直接宣布 1 秒会形成条带。

本轮应研究不同初始位置距离恢复区域的实际迁移时间。

特别注意靠近力平衡位置时速度可能变小。

不能使用固定速度乘以时间进行长时间外推。

## 4.2 捕获时间的定义

先预登记捕获距离和保持时间。

例如可以研究：

- 距离候选条带中心 30 µm；
- 距离候选条带中心 20 µm；
- 距离候选条带中心 10 µm。

这些是候选诊断阈值，需要在正式实验前结合泡径、声场尺度和数值分辨率冻结。

对每个起始位置记录：

- 首次进入捕获区域时间；
- 是否持续保持；
- 是否再次离开；
- 实际完成时间；
- 是否被右删失；
- 所需物理计算成本。

对于尚未到达的微泡，不允许填写一个线性外推的捕获时间。

## 4.3 不同初始距离

构建多个合法初始状态：

- 距离恢复位置较近；
- 距离恢复位置中等；
- 距离恢复位置较远；
- 跨多个恢复区域的随机分散云。

初始状态必须在三维中无硬球重叠，并符合现有腔体和声场范围。

**人为预先靠近条带的初态，只能用来验证局部捕获，不等于声场已经从全局随机分散状态形成条带。**

## 4.4 真正的条带形成 Gate

必须至少区分：

`FIELD_PERIODICITY_PASS`

`LOCAL_CAPTURE_PASS`

`MULTIPLE_BAND_OCCUPANCY_PASS`

`STRIPE_STRUCTURE_FACTOR_PASS`

`STRIPE_PERSISTENCE_PASS`

`STRIPE_DYNAMICS_CONFIRMED`

正式条带结果不能只依靠 Rg 下降。

需要同时检查：

- 至少多个候选带被粒子实际占据；
- 位置分布出现超出随机初态的周期增强；
- 结构因子具有可信峰值；
- 粒子在条带附近保持；
- 多个独立初态重复出现；
- 结果超过数值误差；
- 条带间距与实际力学稳定位置有合理关系。

保留 F10AF 已预登记的结构因子阈值及周期数要求；若需修改，必须在新实验前另行预登记并同时报告原标准下的结果。

# 6. 第四研究主线：为什么四源相位没有产生旋转？

这条研究线独立于条带形成研究。

## 6.1 先复现 F10AF 负结果

`Y-, Y+, X-, X+`

检查：

- 环向受力；
- 去均值力；
- 实际相对速度；

- 刚体旋转比例。

## 6.2 局部切向力与真实切向速度

必须区分：

\[
F_\theta
\]

与：

\[
v_\theta
\]

声学力可能具有局部切向分量，但阻力耦合、其他方向受力和微泡相互作用会改变最终速度。

对多个环半径和三维高度计算：

- 平均切向声学力；
- 平均切向速度；
- 净径向流入或流出；
- 切向响应随半径的变化；
- 角速度正负；
- 是否存在方向反转；
- 是否存在局部相反环流。

特别检查已有 F10AF 报告中切向响应随环半径改变符号的现象。

## 6.3 初始群体结构

使用：

- 原始随机分散云；
- 合法的近环形分布；
- 合法的局部紧凑群；
- 多个独立随机种子。

如果使用人工环形初态，必须标记：

`PRESCRIBED_RING_INITIAL_CONDITION`

这只能证明当前声场能否驱动已有环形分布旋转，不能证明声场能够自己形成环。

## 6.4 旋转确认

至少检查：

- 去平移后的角速度；
- 累积角度；
- 旋转方向；
- 旋转持续性；
- 刚体旋转与非刚体剪切；
- 局部群体轨迹；
- 正反相位的公平比较。

保留历史刚体旋转比例 0.8 的强判据用于前后比较，并单独记录可能存在的非刚体轨道运动；两者不能混合为同一个通过条件。

如果群体内部粒子互相绕行，但整体不是刚体旋转，应分类为相应的相对环向运动，而不是强行宣布整体旋转成功。

## 6.5 不允许虚构声流

当前原始模型为零背景流且没有声流。

`STREAMING_NOT_MODELED`

# 7. 第五研究主线：声流、浮力与近壁机制的独立预检

本轮可以开展物理模型扩展可行性研究，但不要求立即完成真实 PDMS 流固耦合。

## 7.1 声流

研究现有声场条件下，是否有足够的物理理由认为声流可能对群体旋转和长时间运动产生重要影响。

应查阅权威文献及已有成熟开源求解工具。

可以评估：

- 基于经过验证的一阶声场估计的二阶平均流动；
- 流体黏性；
- PDMS 边界影响；
- 壁面附近的流动；
- 流动与微泡运动耦合。

若选择使用 FEniCSx、OpenFOAM 或其他成熟开源工具，必须先确认对应方程、边界条件和数值验证能力，而不是只因为工具名称常见就安装。

正式声流模型必须采用独立 opt-in 实现、源码身份和模型标签。

不能把没有验证的二维涡旋速度直接加到现有高保真求解器中，并称为真实声流。

## 7.2 浮力

对微泡半径 1.78 µm 的当前模型，可以开展受力时间尺度估算。

但长时间浮力和近壁速度需要考虑：

- 液体黏性；
- 泡径；
- 壳与气体密度假设；
- 流道方向；
- 近壁阻力；
- 合法的微泡几何。

如果新增浮力，先做独立无声学作用的物理基准。

没有经过验证时，不得宣称顶部聚集自然形成。

## 7.3 多泡径与壳模型

现有微泡统一半径 1.78 µm。

对于真实造影微泡，粒径及泡壳参数通常并不完全相同。

可以对有限的泡径和壳参数分布进行预检，但每类参数必须匹配：
