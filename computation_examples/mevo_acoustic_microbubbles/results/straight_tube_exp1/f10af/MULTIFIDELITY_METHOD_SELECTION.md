# Multi-fidelity method selection

SMAC3 is suitable for mixed/discrete controls and successive allocation; BoTorch qMFKG is suitable for a small continuous action space with cost-aware fidelity choice. Both official libraries are installed and executed. Scientific screening sensitivity is unidentifiable without HF-positive patterns, so formal multi-fidelity pattern search was not admitted. Offline API replay consumes frozen measured 2 ms records only. Sobol receives eight actual full-physics 20 ms trials without LF rejection. Prior CMA-MAE serves as a preserved historical reference, not an apples-to-apples performance claim.
