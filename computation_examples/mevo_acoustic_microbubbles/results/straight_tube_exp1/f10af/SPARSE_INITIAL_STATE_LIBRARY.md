# Sparse initial-state library

11 frozen states: 32/64/128/200 wide clouds, three independent N64 clouds, loose N64, historical compact N64, contact-transition N32 and prescribed top N32. Seeds, actual extents, heights, true spherical gaps and cavity checks are recorded. Top placement is prescribed, not naturally risen. Its dynamic cache was not built. The loose state was stored but not dynamically studied; synthetic stripe/grid/ring tests never enter the scientific state library.
