# Reuse audit

直接复用四路 Segment/Schedule、固定相位时钟、WaterSequential、F2、APECSS表、GPU声场与墙面查询、原pair-normal阻力及Sequential QP。原求解器文件与F10Q数值门槛的SHA被冻结；服务端另与最后F10S执行快照核对。F10Y源码和历史结果不修改。

F10Z Campaign仅重载构造函数；实际积分使用原F10S Campaign.run。进程内将旧runner的BASE指向独立F10Z目录，使它读取本轮预登记哈希，所有轨迹仍由self.out隔离。没有复制或改写逐步积分、力、接触算法。轨迹保留旧runner的模型名称；执行commit及新增run ID指明当前F10Z实验。

原单连通网络保持Gate只适合原始人为成团状态。分散态仍报告该Gate的结果，但不将初始多连通分量视为几何非法，也不把它改名为PASS。另行保存完整连边事件、步长/缓存下的端点网络与事件时间差。

物理上仍使用既有表的1000 kg/m³、1500 m/s、平移阻力黏度0.001 Pa·s和径向有效黏度0.002 Pa·s参数；“均匀水”首先指声场代理，没有重新标定介质黏度、壳参数、近场相互作用或接触物理。F2是两两单极反馈假设，不是全体径向耦合或经过校准的近场解。
