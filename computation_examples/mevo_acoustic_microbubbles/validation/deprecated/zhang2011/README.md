The [archive index](INDEX.json) records actual paths and SHA-256 identities for the forensic report, failed-case HDF5, reproduction matrix, digitisation and literature notes. Original Stage 2 / 2.5 result directories and reference implementations remain untouched. The index is generated by scripts/stage3/finalize.py.

No parameter/sign/window tuning will be pursued to force agreement. This literature trend is not an admission gate for Stage 3. Historical implementation consistency checks remain useful regression checks; they are not proof of the disputed published trend.
