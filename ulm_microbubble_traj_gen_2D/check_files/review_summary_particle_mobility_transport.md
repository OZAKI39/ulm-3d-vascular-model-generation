# 微泡迁移率推进模型实现 Review Summary

生成日期：2026-07-14

## 1. 本次实现目标

本次实现将默认微泡推进方式由单纯的被动示踪

\[
\dot{\mathbf x}=\mathbf u(\mathbf x)
\]

扩展为基于参考文献正文、补充材料以及 `references/Revised v5.md` 的有限尺寸微泡迁移率模型：

\[
\mathbf U_i
=
\mathbf U_{H,i}
+
\mathbf M_i^{\mathrm{eff}}\mathbf G_i^{\mathrm{coll}}.
\]

实现内容包括：

- 根据每颗微泡的半径、局部黏度、球面到壁面间隙及向内法向，逐位置计算近壁/自由空间混合迁移率。
- 使用补充材料中的近壁阻力系数、剪切等效力和剪切等效力矩，计算二维平移速度及绕 `+Y` 轴角速度。
- 使用同一帧不可变粒子快照计算成对软排斥力，避免粒子遍历顺序影响结果。
- 默认采用同步显式 Euler；保留可选严格 Heun，预测点会重新插值场、重新计算迁移率并重新计算全部碰撞。
- 保留已有连续路径检查、接触点二分和切向滑移，使微泡可以达到零壁面间隙附近，但不能穿透固体壁。
- 保留固定帧内有效微泡数量、连续补充和永久唯一 ID；失活微泡的状态数组槽位不复用。
- 将“微泡实际速度”和“采样到的背景流体速度”分开保存，并增加旋转、碰撞和近壁诊断。
- 保留旧被动示踪推进器作为兼容和回归基线。缺少 `particle_dynamics` 配置段时仍默认使用旧模式；项目默认 YAML 显式启用新模式。

需要特别区分：论文主要给出单颗刚性球靠近平面壁时的低雷诺数迁移率；全血管平滑拼接、多微泡碰撞、同步积分和连续补充属于在论文模型基础上的工程扩展，结果元数据中已明确记录。

## 3. 核心逻辑变化，按调用链说明

1. `generate_microbubble_trajectories.py` 读取 YAML 后进入 `runner.run_generation`。
2. 原有血管读取、网格构建、栅格化、连通性检查和流场求解保持不变。只有通过物理收敛检查的流场才能进入粒子阶段。
3. `particle_advection.advect_particles` 根据 `motion_model` 分发：
   - `passive_tracer`：原样调用旧推进器；
   - `mobility`：先调用 `build_particle_hydrodynamic_fields`，再进入同步迁移率推进器。
4. 新推进器先复用原有容量规划、随机直径和入口采样逻辑。每个可能出现的永久 ID 预先分配自己的半径和多个入口候选位置。初始粒子和补充粒子优先使用与现存微泡不重叠的候选；若二维入口确实无法容纳，则选择最大压缩量最小的候选并显式计数。
5. 永久 ID 直接索引永久状态数组。粒子终止后该位置、角度和生命周期槽位不会交给新粒子；新粒子总是获得递增的新 ID。固定长度的帧输出 lane 只保存“当前这一 lane 对应哪个永久 ID”，不承载或复用物理状态。
6. 每一帧先取得所有有效粒子的不可变位置快照，然后批量插值背景速度、完整速度梯度、黏度、球心到固壁距离、向内法向和局部血管半径。
7. 对每颗微泡计算：
   - 表面间隙 `h = d_wall - R`，水动力公式使用 `max(h, 0)`；
   - 局部基底 `t=(-n_z,n_x)`，满足 `t × n = +Y`；
   - 主体流平移速度和半涡量角速度；
   - 近壁带符号剪切率、等效剪切力和力矩；
   - 冻结于 `xi_near` 的近壁渐近矩阵，以及到自由空间矩阵的三次平滑拼接。
8. 基于同一快照和每颗微泡的有效平移迁移率计算所有成对碰撞。每一对只计算一次并同时累加等大反向力；同心退化情况由两个永久 ID 决定可重复方向。
9. 将总碰撞力变换到局部切向—法向坐标，经迁移率矩阵得到附加平移和旋转速度，再与背景水动力速度相加，得到实际微泡速度。
10. Euler 使用一次完整 RHS。Heun 在预测位置重新执行第 6～9 步，包括重新计算邻域和碰撞，不复用第一阶段结果。
11. 所有候选位置生成完成后，统一执行已有连续路径采样、壁面接触二分和切向滑移，再统一提交。出口/越界粒子在下一存储帧前终止；若启用补充，则在同一输出 lane 放入一个拥有新永久 ID 和新状态槽位的入口微泡。
12. `ParticleTrajectories` 中的 `velocities_um_s` 现在表示实际微泡速度；`fluid_velocities_um_s` 单独表示原流场双线性插值。保存层写入 schema v2、新诊断数组和模型元数据，原有可视化仍可读取公共必需键。

## 4. 行为变化：改动前 vs 改动后

| 方面 | 改动前 | 改动后（默认 YAML） |
|---|---|---|
| 平移速度 | 完全等于局部背景流速 | 背景水动力速度 + 迁移率作用下的碰撞附加速度 |
| 微泡尺寸作用 | 仅用于入口/壁面几何约束 | 同时进入间隙比、Stokes 迁移率、剪切载荷、碰撞距离和相对迁移率 |
| 近壁行为 | 采样流速后由几何层防穿壁 | 先进行近壁水动力修正，再由原连续几何层作最终防穿透 |
| 旋转 | 不计算 | 保存绕 `+Y` 轴角速度和累计旋转角 |
| 多微泡相互作用 | 无 | 使用迁移率缩放的短程软排斥；当前无远程多体水动力耦合 |
| 更新顺序 | 粒子逐个计算并立即提交 | 同一帧快照计算全部速度，之后统一提交，避免 lane 顺序偏差 |
| 时间积分 | 显式 Euler | 默认同步 Euler，可选严格 Heun |
| 速度输出语义 | 背景流体速度 | 实际微泡速度；背景速度另存 |
| 补充与身份 | 永久 ID 递增、不复用 | 保持不变，并明确保证永久状态数组槽位也不复用 |
| 入口重叠 | 允许放回采样且不报告粒子重叠 | 多候选筛选；无法无重叠放置时采用最小重叠候选并告警/记录 |
| 配置兼容 | 无模型选择 | YAML 缺少新段时仍走旧模式；当前项目默认配置显式走新模式 |

## 7. 可能的回归风险

1. **入口二维装填密度。** 当前默认 50 颗有限尺寸微泡同时从较薄的入口区域初始化，真实流场 smoke test 出现 33 次最小重叠回退。代码不会隐藏该问题，但较大的初始碰撞力会形成启动瞬态。应重点评估入口轴向注入窗口、目标二维浓度或三维/2.5D 出平面分层。
2. **默认时间步尚未满足新模型的收敛准则。** smoke test 的最大单步位移相对最小网格/半径/碰撞层尺度约为 102.64，远高于建议的 0.2。当前实现告警但不自动改变用户配置，也没有加入全粒子同步动力学子循环。正式科研结果必须进行固定碰撞松弛时间下的 `dt, dt/2, dt/4` 收敛试验。
3. **单平面壁假设。** 分叉、强曲率、窄管和两个壁面距离接近的区域不严格满足论文的单平面壁前提。实现只给出双壁警告，没有发明未经文献验证的双壁叠加公式。
4. **速度梯度和壁面法向的网格依赖。** 近壁剪切来自二维有限差分，壁距/法向来自 EDT。低网格分辨率、分叉中轴或距离梯度退化会影响结果；退化次数已记录。
5. **碰撞是工程扩展。** 参考论文主要讨论单颗粒子，当前成对软排斥、碰撞层厚度和松弛时间需要独立敏感性分析，不能当作论文直接验证的参数。
6. **当前邻居搜索为 `O(N^2)`。** 对默认 50 颗/帧性能很好，但若将有效粒子数提高几个数量级，需要加入并与参考结果逐对验证无固定容量溢出的 cell list。
7. **下游速度语义变化。** schema v2 中 `record_velocities_um_s` 是微泡实际速度。若外部脚本过去把它当作流体速度，应改读 `record_fluid_velocities_um_s`；现有项目可视化公共字段仍兼容。
8. **Heun 的边界事件。** Heun 会在经过连续几何约束的预测位置重新计算 RHS；非常大的单步位移跨越出口或复杂分叉时，仍应通过减小时间步验证事件时刻精度。
9. **结果文件体积。** `store_full_diagnostics=true` 会增加每条记录的多个数组；容量检查限制记录数，但长时间、大粒子数运行仍需关注磁盘和内存。
