# 收录范围与排除项

本快照针对当前血管 A → ROI → 1D/0D Network-H0 → 3D FEM → 微泡主线，以及当前保留的独立 RBC 模型、轨迹和展示。所有排除动作只作用于同步副本；未删除原工作区、服务器或旧 Git 分支。

## 保留

- 当前配置、源代码、测试、网格、冻结流场、现存有效时间步、求解与积分日志、报告、CSV/JSON、Excel、图件和视频。单文件不大于 50 MiB 的现存有效科学数据均保留。
- 500 条正式轨迹、500 条配对点示踪及身份/完成回执；受 `retained_science.sha256` 约束的 7,760 个文件全部按字节保留，包括仍被该契约覆盖的少量旧名称记录和服务器来源说明。
- 当前管网 40 个受保护输入；当前 A 的 SWC、TIFF 图像/掩膜、ROI、表面及三个相关几何处理结果目录。
- 最新完整 `wss_audit/`：中文报告、代码证据、原始数值摘要、输入、诊断脚本、日志及四张图。
- WSL 本轮清理和路径迁移的回执，用于解释当前布局，不恢复已经删除的旧工程内容。
- 服务器当前 H0 算例、dt1ms 微泡任务、出生样本来源、独立 RBC 工程/结果及 FEM 构建配置的只读 SHA256 清单。相同字节映射到已有快照文件，缺少的唯一内容另行补入。

## 排除

| 内容 | 原因与复现线索 |
|---|---|
| `.git`、Python 虚拟环境、缓存、字节码、IDE 缓存 | 不是科学源文件；保留依赖配置和版本证据 |
| `external/SimVascularDistribution/` 的已安装运行包 | 官方大型安装内容；现有网格报告保留下载及校验信息，求解器源码保留 |
| 服务器编译目录、可执行文件、库、PID/socket、临时目录 | 可由源码和构建资料重建；FEM 二进制只记录 SHA256/尺寸 |
| 服务器 `.tar.gz/.tar.zst/.zip` 部署包与重复 frozen_bundle | 重复运输归档；对应当前文件及来源映射已保存 |
| 流线 `input_data/streamlines/data/candidates.npz`（约 41.6 MiB） | 中间候选种子；已接受的流线、绘图输入和渲染代码均保留 |
| `vascular_printing/third_party/vascularmd/Output/`（约 108 MiB） | 第三方示例生成的网格/OpenFOAM 输出，与当前 A-H0 数据无关；第三方代码和许可保留 |
| 非当前 A 的完整影像数据库、独立打印实验的历史结果 | 不属于本次主线；原数据库和独立工程未改动 |
| 已被用户要求清理的旧开发阶段 | 当前本地已不存在，不从旧 Git 提交重新恢复；旧分支保留历史 |

本地规则设置了 50 MiB 单文件筛选线，当前正式流场和轨迹没有文件因该限制而排除。完整本地排除记录见 `excluded_local.json`；服务器具体排除记录见 `server_inventory.json` 的 `omitted`。不把父目录排除的字节数与未展开子树的字节数混为精确总量。

原工作区 `.gitignore/.gitattributes/.ignore` 另存于 `original_git_rules/`，避免旧 LFS/换行过滤器改变科学文件字节。第三方求解器的测试夹具、示例资源及 Windows 安装包原本包含 950 个未下载的 LFS 指针，全部来自 `external/flow_solver_source/`，不属于当前血管求解数据。这些指针的完整文本、源路径、目标路径及 SHA256 保存在 `upstream_lfs_pointers.json`，不再以独立 LFS 占位文件入库；其真实上游内容没有下载。原因是 GitHub 在首次推送时以 GH008 拒绝目标仓库不存在的 LFS 对象。处理只发生于同步副本，当前正式网格、流场、轨迹及原工作区均未修改。运行所有第三方上游测试需要另取相应上游 LFS 资源。

兼容链接调整为仓库内部相对链接，记录见 `symlink_map.json`。仅用于非当前可选共享数据的空目录留有 `SNAPSHOT_SCOPE.md`；不能理解为完整数据库已上传。
