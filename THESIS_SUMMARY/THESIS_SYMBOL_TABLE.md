# 论文内部符号表

本表用于一致性审查，正文仍在每个关键公式之后解释变量，不要求读者先阅读本表。

| 符号 | 含义 | 单位 | 首次核心公式 / 约定 |

| \(\mathbf{x}\)、\(\mathbf{x}_k(t)\) | 位置、微泡 k 的轨迹 | m | 2；下标表示身份 |

全篇单位转换：1 µm = 10⁻⁶ m；1 nm = 10⁻⁹ m；1 ms = 10⁻³ s；1 fL = 10⁻¹⁸ m³ = 1 µm³；1 mL = 10⁻⁶ m³。数学常数 π、整数索引、权重和形状比均无量纲。

历史原图符号未重写：r 对应正文 η，方向向量 p 对应 s_R，g 或 h_geom 对应原始 h，R_eff 对应 R_ij，s（平滑坐标）对应 ξ。图中 q 若表示姿态参数，与本文体积流量 Q 不同；正文无需读者理解其存储表示。该映射仅为阅读历史图使用，不改变原图数据。
