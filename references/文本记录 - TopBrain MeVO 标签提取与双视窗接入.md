# 基于 TopBrain 原生解剖标签的 MeVO 区域提取、物理空间重建与双视窗验证

## 摘要

为减少 BraVa 脑血管网络提取 MeVO 区域时对人工边界标注的依赖，本研究将 TopBrain 公开训练数据接入现有项目，并建立独立入口。研究使用指定的 TopBrain 2025 v2 官方数据，对压缩包完成断点续传、MD5 校验、解压和病例配对。双侧 MCA 区域严格由原生 M2、M3 标签并集得到；ACA 与 PCA 则分别保持派生和粗粒度来源状态。全部几何通过 NIfTI affine 映射至物理空间，原始图像与分割不作改写。新入口复用原双视窗的坐标轴、相机和交互辅助函数，冻结既有 human、BraVa、mouse 及 VascularMD 源码。真实 MRA 001 的右、左 MCA 分别包含 18 835 和 36 476 个体素，真实 GUI 完成 ROI 及病例切换。159 项不同软件测试通过。对全部 25 个 MRA 病例的双侧中心线进行保守检查后，尚未发现无需拓扑复核即可导出严格树状 SWC 的区域，因此未伪造真实建模结果；合成 MCA 则完成了 SWC、官方参数化模型及 VTK/STL 全链验证。结果表明，真实标签提取与交互检查已实现，而真实中心线用于后续制造仍需独立解决数字骨架拓扑问题。

**关键词：** TopBrain；MeVO；NIfTI；解剖分割；中心线；VascularMD；可重复性

## 1 引言

中心线的位置、半径和分支关系不能单独确定脑动脉的解剖分段。此前基于 BraVa 的方法使用人工近端和远端标志点限定区域，能够保留原始图数据，但对尚未完成标注的样本无法给出可信的 MeVO 分区。TopBrain 提供具有解剖名称的体素标签，为直接提取部分目标区域提供了不同的数据基础[1]。

本项目将目标固定为双侧 MCA 的 M2+M3、ACA 的 A2+A3 和 PCA 的 P2+P3。TopBrain 的标签粒度与这些目标并不完全一致：M2、M3 可直接区分，而 A1A2、P1P2 和 P3P4 为组合标签。因此，研究重点是忠实保留标签的原始含义，同时评估分割能否转化为后续模型所需的有向树。

## 2 材料与方法

### 2.1 数据获取及来源保护

下载对象固定为 Zenodo 记录 16878417 中的 `TopBrain_Data_Release_Batches1n2_081425.zip`，并非分割 Docker 或 TA36 模型。下载前文件系统约有 865 GB 可用空间。实际压缩包为 1 958 849 592 字节，MD5 为 `b703ea31cd1f0e7115a5d3e6e61f59b3`，与官方值一致。解压时核对成员路径及 CRC，不假设压缩包顶层名称。最终建立 `data/TopBrain` 软链接，并将大数据目录和软链接排除在 Git 跟踪之外。

实际得到 25 个患者的 MRA、CTA 图像及其对应标签，各类文件均为 25 个。患者编号为 001—008、010—018 和 020—027。原始 License.txt 完整保留，来源记录包括 DOI、压缩包校验值以及每次运行所用图像、标签和标签表的摘要。

### 2.2 几何一致性与单位

图像和标签按病例编号及模态进行唯一配对，读取 shape、dtype、affine、spacing、方向及 qform/sform。若几何不一致则拒绝处理，不以自动缩放或重采样掩盖问题。体素中心通过完整 affine 转为世界坐标，保留旋转和原点，不根据视觉效果手工翻转左右。

真实数据中，标签 header 的空间单位为 unknown，而配对图像明确为 mm，二者几何一致。为避免将已知的配对物理信息丢弃，适配层明确继承图像单位，并将这一决定写入 provenance；双方单位冲突或均未知时仍拒绝处理。内部统一为 mm，仅在显示适配层转换为 μm。导出 mask 保留体素选择及原 affine，原始 NIfTI 不变。

### 2.3 解剖区域与可信度

MCA 严格区域为同侧 M2 OR M3，属于 EXACT_TOPBRAIN_LABEL。这里的 exact 指与发布标签定义一致，并不表示测量或解剖判断绝对无误。实现中不添加形态学修补，不根据直径或分支代次重新限定范围。

ACA 派生通过 ACom 和 A3 与 A1A2 的接触确定路径，只有组合段连通、无环、接触唯一且路径归属明确时，才将下游部分与原 A3 合并。缺失接触、多条可能路径、第三 ACA 或切点两侧等距归属均触发复核。该结果始终为 DERIVED_FROM_TOPBRAIN_LABELS。

PCA 可依据 PCom 尝试派生 P2，但无法由合并的 P3P4 标签获得独立 P3。因此候选名称明确包含 P3P4，状态为 COARSE_TOPBRAIN_LABEL；默认不进入 SWC 流程。第三 ACA 单独保存，不以空间位置决定左右归属。

### 2.4 中心线、半径与图校验

中心线使用成熟的 Lee 三维细化实现[2]。骨架点在物理空间建立 26 邻域图，局部半径由具有真实体素间距的欧氏距离变换获得。该半径属于分割体素估计，没有施加平均、强制渐细或打印尺度补偿。

MCA 使用真实 M1 与严格区域共同细化，再按原生标签取严格子图，减少近端直接截断造成的端帽效应。M1/M2 接触用于定位近端候选，树形校验通过后才按近端至远端定向。若需要上游建模上下文，只沿实际 M1 骨架加入指定长度，并单独保存 modelable 文件。SWC 的 TYPE 采用中性值 0，解剖类别另存映射表。

本研究保留全部原始骨架邻接关系。多连通分量不被静默丢弃，环路不通过任意删边转成树。失败区域仍保留可用的未定向 VTP 供检查。后续官方建模复用已有 VascularMD 公共流程[3]；原生 mask 的 marching-cubes 表面与官方参数化表面分别命名，不能相互替代。

### 2.5 界面复用与缓存

新入口负责参数、病例加载和显示调度，新增逻辑集中于八个 TopBrain 模块。双视窗继续使用 1800×900 窗口、黑色背景、原字体、坐标轴及相机辅助函数，左图保留 Y 轴向上。左侧显示动脉背景及 ROI 框，右侧默认直接显示原生标签表面，并标出病例、模态、解剖来源和 QC 状态。

原 R/S、A、C 及左键框选语义保留；新增方向键切换 ROI、PageUp/PageDown 切换病例和 F12 截图。重计算均在 GUI 回调之外进行。结果缓存由源文件、标签表、参数、模块摘要及依赖版本共同决定，复用前核对产物摘要。

### 3.3 合成模型及界面验证

合成病例 999 的双侧 MCA 各保留 819 个 mask 体素、62 个严格中心线节点和 1 条分支；指定 5 mm 上游范围后，各加入 4 个来自 M1 的实际骨架节点。严格 SWC 与独立 modelable SWC 均通过往返检查，官方模型、VTK 和 STL 实际生成。该结果仅证明接口链条，不作为真实 TopBrain 患者的解剖结果。

实际图形环境中，MRA 001、002 均建立双视窗并完成 ROI 切换；001→002 的病例切换也成功。运行时记录确认 Trackball 相机、两个 viewport、1800×900 尺寸、黑色背景及左图视上向量 (0,1,0)。CTA 001 完成离屏渲染。默认入口成功打开真实数据并返回 0；请求不合法真实 SWC 的执行返回待复核状态，mask 显示仍可用。

### 3.4 测试与完整性

159 项不同测试全部通过，包括 50 项 TopBrain 测试及 109 项旧流程回归，没有最终失败或 skip。新增测试包含实际 MR/CT、重编号标签表、非平凡 affine、已知半径圆柱、遗漏标签、断裂和环路、ACA 歧义、PCA 限制、缓存与源文件保护、SWC、官方表面和显示坐标。日志中保留了 64 次来自 scikit-image 与 NumPy 接口的弃用提示。

早期运行发现三类问题：标签单位未填写、显示包围盒重复缩放，以及 GUI 回调过早销毁窗口。它们分别通过配对单位 provenance、单次换算检查和先终止事件循环后释放窗口解决。最初病例切换发生过退出码 139；修复后实际两病例 GUI 测试退出码为 0，原失败日志没有被删除。

对 189 个基线文件核对后，仅本轮授权重开发的 s1-3 改变。s1-2 前后 SHA256 均为 `3361cea44a97e8bfa907ff1504b0f977e329d35eb59cb9f57cc1b3a2a55cd729`。旧公共渲染器、BraVa 配置、mouse 流程及 VascularMD 上游源码均未修改。未纳入 Git 的旧 s1-3 已保留单份、摘要一致的备份。

## 4 讨论

原生解剖标签解决了 MCA 区域选择的来源问题，但不自动保证其离散骨架满足 SWC 的树结构要求。特别是 26 邻域图在局部分叉体素簇中可能产生小环，不能仅凭图环数诊断真实血管闭环；反过来，也不能未经论证就用最小生成树消除全部环路。当前实现选择完整保留和明确阻断，因此真实模型输出受到限制。这一限制不会影响已经完成的原生标签提取和检查。

ACA 和 PCA 的组合标签仍然限制了本项目目标的精度。真实 001 的相关接触条件未通过，软件如实保留不可派生状态，没有把 A1A2 称为 A2，或把 P3P4 称为 P3。未来若加入经过验证的中心线连接整理或影像支持的解剖边界，应作为独立、可追踪步骤重新验证，而不改变本次严格 mask。

## 5 结论

TopBrain 官方训练数据已完成下载、校验、挂载和真实病例接入。新 s1-3 能以原有风格显示真实 MeVO 解剖标签，保持旧工作流和源数据不变。真实 mask 及其表面输出已经可用；真实 SWC、VascularMD 和制造表面尚受骨架拓扑复核约束。合成全链和软件回归均通过，不能据此声称真实区域已达到 CFD 或制造要求。
