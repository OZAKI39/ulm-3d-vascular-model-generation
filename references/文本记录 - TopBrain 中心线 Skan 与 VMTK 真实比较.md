# TopBrain 原生 MeVO 区域中 Skan 与 VMTK 中心线方法的真实数据比较

## 摘要

本研究以 TopBrain 2025 v2 公开训练集的 MRA 001 左侧大脑中动脉 M2–M3 区域为对象，在保持原始解剖标签、物理坐标和既有显示界面不变的条件下，比较 Skan 0.13.1 与 VMTK 1.5.2。两者均完成官方二进制部署和三次真实运算。Skan 保留严格掩膜骨架的几何覆盖，但仍有 16 个未解决环，且未得到满足既定近端规则的端点。VMTK 官方准确中心线流程产生了可检查输出，但存在 5 个连通分量、2 个环及明显的管腔外连线与覆盖遗漏。两者均未通过全部生产门槛，故本轮结论为 **CENTERLINE_BACKEND_UNRESOLVED**，未指定生产后端，未强行导出真实 SWC 或制造表面。原有 159 项回归测试和新增 17 项测试全部通过；这些测试证明执行和拒绝逻辑符合要求，并不将不合格中心线转化为合格结果。

**关键词：** 脑血管；TopBrain；MeVO；Skan；VMTK；中心线；拓扑验证

## 1 研究目的与材料

本次研究的目的，是检验成熟公开算法能否在不人工删除血管分支、不实施全图最小生成树、不改变严格解剖掩膜的条件下，为现有 VascularMD 工作流提供合法输入。研究材料来自 TopBrain Challenge Data Release，Zenodo record 16878417，DOI 10.5281/zenodo.16878417。原始压缩包和许可文件沿用已完成的数据接入；本轮没有重新下载或改写原始影像与标签。[1]

研究范围固定为 MRA case 001 的 **L-M2 OR L-M3**。标签整数由实际 ITK-SNAP label map 解析，分别为 19 和 20，而不是以提示词中的固定编号代替解析。严格区域包含 **36,476** 个体素和 **1** 个 26 邻接连通分量，体素间距约为 0.296875 × 0.296875 × 0.599994 mm。连通分量为 1 仅说明体素区域相连，不能证明其中的中心线是一棵无环树。

锁定的严格掩膜文件 SHA256 为：

`2d90a805f43d4ffda1c459bbf401a37978970913bad9aa1050c344aebb06dea9`

工作数组 SHA256 为：

`61f0877f098b8460ea55d1f585d5a39fa996525fa88951d500ec33fb51058698`

两个后端的每次运行前后均核对这两类校验值，全部一致。最终物理坐标使用完整 NIfTI affine；裁剪只减少计算范围，其偏移保存在输入和输出元数据中。

## 2 方法

### 2.1 软件环境与方法独立性

主环境 Python 为 **3.13.11**，解释器路径为 `/home/lzy/projects/ulm_particle_3d_particle0/.venv/bin/python`。主项目使用 VTK 9.7.0；VMTK 1.5.2 的官方 PyPI 依赖要求 VTK 9.6.2。受约束的安装预演确实返回依赖冲突，因此在 `outputs/topbrain_centerline_benchmark/environment/` 建立独立 Python 3.13.11 环境。两个后端均从官方 **PyPI binary wheel** 安装，分别固定为 **Skan 0.13.1** 和 **VMTK 1.5.2**，许可证均为 BSD-3-Clause。[2–3] 没有修改主环境，也没有执行源码编译。主环境 pip freeze 前后逐字一致。再次执行安装工具后，两者直接复用并验证通过。

环境使用 NumPy 2.5.3、SciPy 1.18.1、scikit-image 0.26.0、NetworkX 3.7、nibabel 5.4.2、PyVista 0.49.0 和隔离的 VTK 9.6.2。Skan 的 Skeleton、summarize、skeleton_to_nx 以及 VMTK 的 vmtkscripts 均实际导入成功，VMTK CLI 帮助命令退出码为 0。VascularMD 沿用既有固定提交 `770feb8fbfb591d6d43f966db57b1465010b9a13`，未修改其上游代码。

Skan 从严格二值区域的 Lee 骨架出发，调用官方局部分叉处理和逻辑 MultiGraph 转换；各路径保留体素坐标、世界坐标、原生标签和各向异性 EDT 半径。项目没有另外实现分叉聚合、degree-2 链追踪或删环算法。

VMTK 从同一个严格区域的未平滑三角表面独立出发。近端开口只改变表面工作副本，位置由 L-M1/L-M2 接触区确定，中心世界坐标约为 **(−39.657, 16.034, −37.984) mm**，半径 **0.315 mm**，影响 **7** 个表面三角形，形成一个边界区域。随后依次调用官方 network extraction、由网络末端确定 source/targets、准确中心线、branch extractor 和 centerline merge。没有人工打开远端，也没有使用 Skan 结果指导 VMTK。

VMTK 原始网络以重复 point ID 保存相同端点。数据交换只通过官方 VTK 零容差处理恢复精确重合点的公共身份，不合并空间近邻，不删除分支。原生 Network 中的 Radius 和 Topology 原样保存在 VTP 中；实际版本的 Marks 是内部工作表面属性，并未作为 Network 输出。[4] 最终比较只使用 **VMTK_CENTERLINES** 这一种 VMTK 候选；原生近似网络另外保存用于解释失败，没有混合两种输出。

### 2.2 参考数据与评价规则

历史 RAW_LEE_BASELINE 包含 **1,678** 个节点、**1,713** 条像素邻接边、**133** 个原始统计分支、**83** 个分叉节点、**15** 个末端、**36** 个环，长度 **789.501 mm**。该历史流程先对 M1 与 ROI 的并集细化，再取 ROI 内节点。为避免两方法输入不同，本次另存严格 ROI 上的 Lee 几何参考：**1,675** 个节点、**1,710** 条边、**36** 个环、长度 **788.733 mm**。原始像素分支数与后端逻辑分支数含义不同，不能据此直接判断优劣。Lee 仅作为独立几何参考，不被当作解剖真值。

覆盖度使用参考点到候选线段的最近物理距离，分别评价 M2 和 M3；在 **1.199988 mm** 范围内的比例均须至少达到 95%。管腔包含性使用表面的物理有符号距离，容差为 **0.0296875 mm**，要求至少 99% 的原生中心线点及沿线段加密检查点位于管腔内。加密检查最大间隔为 **0.1484375 mm**，只用于评价，不改变导出路径。

近端根节点要求在唯一的 M1/M2 接触区附近存在一个明确的现有末端，最大距离为 **1.799983 mm**。如果接触区只对应中心线内部位置，本次不自动切断分支或补造上游血管。连通且无环、半径为正、几何覆盖和位置合格、运行稳定、合法 SWC 以及 VascularMD 可读取，均为生产选择的必要条件。

## 3 结果

| 逻辑节点 | 57 | 22 |
| 逻辑分支 | 72 | 19 |
| 分叉节点 | 43 | 7 |
| 末端 | 14 | 13 |
| 连通分量 | 1 | 5 |
| 环秩 | 16 | 2 |
| 总长度（mm） | 776.088 | 457.308 |
| 半径最小／中位／最大（mm） | 0.297 / 0.840 / 1.484 | 0.187 / 0.438 / 1.369 |
| M2 参考点覆盖率 | 100.00% | 11.30% |
| M3 参考点覆盖率 | 100.00% | 17.03% |
| 原生中心线点管腔内比例 | 100.00% | 90.62% |
| 沿线段加密检查管腔内比例 | 99.97% | 20.67% |

| 三次进程峰值 RSS（MiB） | 470.7 / 470.2 / 472.0 | 582.0 / 582.3 / 585.1 |

以上性能是分别重新执行算法的实测值，包含首次基准调用及后续缓存已升温的调用；不代表严格清空系统缓存后的硬件性能。两后端的三次逻辑拓扑 checksum、点坐标 checksum、分支数和总长度均完全一致。

| 双向几何距离（mm） | 均值 | 中位数 | P95 | 最大值 |
|---|---:|---:|---:|---:|
| Skan：候选 → 严格 Lee | 0.000 | 0.000 | 0.000 | 0.000 |
| VMTK：候选 → 严格 Lee | 0.977 | 0.221 | 2.067 | 28.990 |
| Skan：严格 Lee → 候选 | 0.000 | 0.000 | 0.000 | 0.000 |
| VMTK：严格 Lee → 候选 | 5.659 | 5.346 | 12.739 | 16.128 |

M2 与 M3 几何参考分别包含 982 和 693 个点。Skan 的覆盖为 100%，说明它保留了严格 Lee 骨架的位置；这不能抵消剩余 16 个环所造成的 SWC 拓扑问题。最近的中心线采样点距 M1/M2 接触区仅 **0.664 mm**，但该点不是逻辑末端；最近现有末端距接触区 **20.702 mm**，未满足当前根节点规则。因此不能将这一失败解释成“近端区域没有中心线”。

VMTK 原生近似网络成功生成，零容差恢复公共点身份后为 **1** 个连通分量、**64** 个逻辑节点、**86** 条逻辑分支、**49** 个分叉节点、**15** 个末端、**23** 个环，长度 **690.745 mm**，且包含一个零半径点。准确中心线流程也产生输出，但未通过质量验证：三次均报告 **12,992** 条线性系统无法分解警告、**1** 条包含 533 个退化三角形的网格警告，以及 **8** 条目标未到达警告。原生准确路径、官方分支输出、官方合并输出及适配后的坐标与路径均保留；已确认异常直线存在于官方输出，适配层没有另行连接分支。

原生采样点包含性与沿线段包含性的明显差异说明，只检查少量端点可能掩盖穿出管腔的长弦。VMTK 候选的近端末端距离为 **0.775 mm**，该项通过，但连通性、无环性、覆盖度和管腔包含性未通过。其半径使用原生 MaximumInscribedSphereRadius，同时记录严格掩膜 EDT 对照；没有通过替换或平滑半径来掩盖位置错误。

### 3.2 生产判定与导出状态

最终 `selected_backend = null`，状态为 **CENTERLINE_BACKEND_UNRESOLVED**。Skan 未通过近端末端与无环门槛；VMTK 未通过单连通分量、无环、覆盖和包含性门槛。合法 SWC 与 VascularMD 可读性在真实病例上被前置质量门槛阻止，不能将其记为成功，也不能声称 VascularMD 已实际尝试建模后失败。

本轮没有人工删分支、全图 MST、手工补线或修改严格掩膜，没有改动生产入口及默认中心线方法。因此真实病例的 **SWC 路径、VascularMD 平滑 SWC 路径、建模 VTK 路径和 STL 路径均为空**。比较目录中的 VTP/VTM 是诊断产物，严格掩膜表面也不是 VascularMD 模型或制造完成证明。后续需要对残余连接和近端结构进行人工检查，或提出新的、有明确授权的方法学步骤；本轮未实施人工修复。

新增的分支到 SWC 适配器已在明确标识的合成 Y 形数据上完成无平滑导出：39 个 SWC 节点、3 条分支，既有 VascularMD 读取通过。该检查仅验证适配器的序列化和共享分叉身份，不替代真实 TopBrain 病例。

### 3.3 回归、界面与保护验证

原有 **159** 项测试全部通过，新增 **17** 项测试全部通过，合计 **176** 项，失败和跳过均为 **0**。新增范围涵盖 Y 分叉、分叉像素簇、各向异性 affine、原生路径和标签保留、真闭环拒绝、单管与 Y 管的 VMTK 网络、闭合与开口表面行为差异、准确单管中心线、SWC 导出、严格门槛和真实三次运行。

真实 MRA001 双视窗界面启动、ROI 切换、分组切换和自动关闭正常完成，继续使用 1800×900 黑色双视窗、既有 Trackball 交互及左侧 Y 轴竖直方向。独立比较图不属于原有 GUI 的修改。

本轮记录的 **193** 个已有受保护文件校验均不变，主环境依赖快照完全一致。s1-2 SHA256 仍为：

`3361cea44a97e8bfa907ff1504b0f977e329d35eb59cb9f57cc1b3a2a55cd729`

## 4 讨论与结论

本例说明，减少像素邻接环、生成可显示的曲线，以及得到可供树状建模使用的中心线，是不同层面的结果。Skan 的官方分叉处理解决了一部分局部邻接冗余，但仍有未解决环和近端端点问题；不能仅凭外观连续或覆盖完整就导出 SWC。VMTK 的血管专用算法和严格物理坐标对齐也不保证该输入的数值求解有效，必须结合原生警告、双向距离、远端覆盖与沿线段包含性作判断。

因此，本次比较完成了部署、真实运行、验证和明确拒绝不合格候选的闭环，但尚未达到真实 SWC→VascularMD→VTK/STL 的后续成功条件。该结论只适用于本病例、当前未平滑严格表面及所记录的官方参数，不能推广为两个软件在所有脑血管数据上的性能结论。原生解剖显示继续可用，原数据、完整中间结果和未通过原因均可复核。
