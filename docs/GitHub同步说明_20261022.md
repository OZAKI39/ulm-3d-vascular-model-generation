当前两种新朝向只调整刚体姿态，直径仍为 1.60 mm，P1S / 0.4 mm / ABS；其 3MF 没有支撑实体和刀路，但包含用户切片时使用的可编辑支撑参数。历史支撑研发结果保留原状态，不能把几何检查或软件切片成功解释为实物制造验收。

## 保留与排除依据

完整保留开发代码、配置、测试及必要输入、日志报告、关键几何和当前交付；检查图通常保留。导出规则见 [export_github_snapshot.py](../tools/export_github_snapshot.py)。每个复制文件记录 SHA256；被排除的文件记录路径、大小和理由。

未同步虚拟环境、编译产物、软件安装包、第三方示例输出、批量原始影像、无关参考数据集、重复历史 ZIP、可重算的逐层刀路和几何缓存，以及低价值的较大中间网格。单文件上限为 45 MiB；关键 STL 不按普通中间网格的 2 MiB 阈值排除。当前未切片工程和测试依赖的历史小型 STEP 均保留。

这是一份精选开发快照，不是原磁盘的逐字节备份。部分历史报告中的路径仍指向被省略的大文件；原报告与来源哈希未改写。排除只是没有上传，原文件仍保存在工作区。没有用 Git LFS 指针代替当前交付文件。

`sync/20261022/included.json`、`excluded.tsv` 与 `selection_summary.json` 提供逐文件清单和体积统计；`snapshot_pytest.log`、`source_preflight.json`、`remote_source_comparison.json` 提供本次验证记录。记录中保留了初次检查遇到的缺失 STEP 和 Windows 挂载盘读取错误；补齐小型回归输入并改用随项目保存的打印预设后，再运行最终检查。

## 在新机器使用

```bash
git clone --single-branch --branch sync/vascular-printing-project-20261022 \
  https://github.com/OZAKI39/ulm-3d-vascular-model-generation.git vascular_printing
cd vascular_printing
python3.13 -m venv .venv
.venv/bin/python -m pip install -r sync/20261022/requirements-server-current.txt
export VASCULAR_BAMBU_PROFILE_ROOT="$PWD/migration/20261009/external/bambu_profiles"
./run_python.sh -m pytest -q tests/test_straight_core_orientation.py \
  tests/test_straight_core_print_quality.py tests/test_channel_manual_delivery.py
```

环境清单是现有独立 Linux 服务器环境的版本快照，不包含解释器或系统动态库。图形显示及 CAD 组件仍需操作系统依赖；原服务器的具体安装记录在 `migration/20261009/`。生成当前未切片工程不应自动调用切片器；复核历史原生切片时才需要另行安装 Bambu Studio。`tools/bin/bambu-studio` 仅是入口脚本，软件本体未上传。

读取已交付工程或可视化已有 BraVa ROI，不需要下载全套 TopBrain。需要重新提取 TopBrain 标签时执行：

```bash
./run_python.sh tools/topbrain_prepare_dataset.py --download
```

工具使用 Zenodo record `16878417`、DOI `10.5281/zenodo.16878417`，固定 ZIP 为 `TopBrain_Data_Release_Batches1n2_081425.zip`，期望 MD5 为 `b703ea31cd1f0e7115a5d3e6e61f59b3`。许可、实际 labelmap 和来源清单保留在 `data/external/TopBrain/`。仓库中的 `data/TopBrain` 链接不代表原始影像已随仓库下载。

历史 JSON 内的绝对路径保持原样，以保留证据；新工作区优先使用入口脚本和配置中的相对路径。迁移脚本中固定服务器路径的部分是当时的部署记录，不要直接当成通用安装器执行。
