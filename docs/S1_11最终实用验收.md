# s1-11 最终实用验收与复核

本页保留 **X1 Carbon / 0.2 mm 的历史实用验收**。当前默认目标已改为 [P1S / 0.4 mm / ABS](S1_11_P1S_04_ABS.md)，以下历史命令必须显式指定打印机。历史流程继续使用 `s1-11_vascular_core_support.py`，采用有次数上限的实际承托与拆卸验收。原始血管不变，模型仅作记录在案的刚体打印坐标变换。

```bash
cd /home/lzy/projects/vascular_printing
./run_python.sh s1-11_vascular_core_support.py --printer x1c-0.2
# 复用全部已有切片和候选，不再执行原生切片：
./run_python.sh s1-11_vascular_core_support.py --printer x1c-0.2 --stage review
```

`--max-iterations` 只接受 1–3，分别限制修补和拓扑轮次；不会针对每个姿态重新给出三轮额度。已有结果复用，READY 后冻结并停止优化。`NEEDS_ADJUSTMENT` 的退出码是 2，表示制造条件未通过，不是 Python 异常。`--stage legacy-closure` 只重看旧闭合流程，禁止将旧门槛的结果当作本轮验收。

## 输入与处理逻辑

冻结输入来自 s1-10 当前已接受血管芯、对应 SWC 和端口数据。上游文件在运行前后逐项校验。已有 O002 基线和两个备选重新读取实际 G-code；没有新增姿态搜索。最新保存的 X1 Carbon、0.2 mm、ABS、0.10 mm Standard Vessel 配置导出到本轮目录，只在导出副本关闭 Auto Support，用户配置不改写。

下表面采样下方存在可用的真实支撑挤出才算结构承托。间隙过近单独记为表面及拆卸风险，间隙过远仍算真实缺承托。孤立数值边界只有在两侧相邻样本及同一个连续挤出区域均提供证据时才可豁免；相邻多点缺口不能豁免。

支撑自身检查区分附着且不扩展的微小层差与浮空岛、空气起始、过深悬空等宏观失败。拆卸检查执行真实布尔切割、实体连通分解、有限刀片与血管相交检查、3 mm 工具接近和逐步更新障碍物的刚性取出扫掠。负向空腔壳不计作独立支撑。规划剪口数、切后实体数、实际可达剪口数、最终能取出的组件数分别记录。

薄连接既要在 G-code 中保留，也要清除其周围原幕墙并实测独立薄颈截面。只有前者通过不能标作 C3 生产通过。顶面残片若仅从几何上分离、尚无已认证的 bulk 剪切路径，必须保持诊断标记，不能编写为已成功拆除。

## 代码职责

|模块|职责|
|---|---|
|`core_support_practical_pipeline.py`|读取候选、轮次控制、缓存、验收、交付与冻结|
|`core_support_practical_audit.py`|真实缺承托/间隙分类、数值例外、宏观支撑、血管起始与警告|
|`core_support_practical_geometry.py`|只修真实缺点、原血管保护、实体和内部空腔分解|
|`core_support_practical_topology.py`|少量实际材料图割、无效切割剔除、C3 局部几何|
|`core_support_practical_removal.py`|薄颈实测、接触长度/包覆/力臂、工具可达及顺序取出|
|`core_support_practical_review.py`|18 张检查图、20 问中文报告、拆卸检查指南|
|`core_support_slicing.py`|保留旧审计，同时提供真实 Bambu 切片、G-code 和原生工程验证|

旧 `closure_v2/` 和 `tests/test_s1_11_vascular_core_support.py` 中原有测试均保留，用于历史可追溯性。当前测试另覆盖结构/间隙拆分、真正孤立的数值边界、材料图割、C3、顺序可达性及新的 READY 条件。
