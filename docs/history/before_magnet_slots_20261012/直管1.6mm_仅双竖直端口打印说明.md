# 1.6 mm 直管：仅保留两个上方端口

2026-10-12 新增版本，适用于 **Bambu P1S / 0.4 mm 喷嘴 / ABS**。它是独立的附加版本，原有 Y 形和三端口直管的配置、模型与打印包继续保留。

本版只保留竖直向上的 INLET 与 OUTLET1，去掉水平 OUTLET2。原来出口 1 下方的三通改为半径 2.40 mm 的相切圆弧上弯，形成一个连续的 U 形通道，不留下水平盲端，也不需要后续切割 PDMS 来打开水平出口。两个上方端口的轴线仍在 x=-17 和 x=12 mm；底部中心线高度仍为 z=2.30 mm。为接入右侧圆弧，低位直线段范围为 x=-14.60 至 9.60 mm，长度 24.20 mm。

| 项目 | 当前 CAD 值 |
| --- | --- |
| 通道芯直径 | 1.60 mm |
| 通道最薄 PDMS 底层 | 1.50 mm |
| PDMS 腔体净长 × 净宽 | 36.60 × 9.60 mm |
| PDMS 设计浇注高度 | 9.60 mm |
| 盒壁厚 / 内部 ABS 底板 | 2.00 mm / 0 mm |
| 盒体外包围盒，含安装座 | 49.80 × 21.80 × 10.40 mm |
| 跨盒托臂下表面 / 到盒沿净距 | z=13.40 mm / 3.00 mm |
| 支座顶部 / 血管芯端口顶部 | z=17.80 mm / z=18.40 mm |
| CAD 净浇注体积 | 约 3.29 mL，不含转移等损耗 |

高度都从外部浇注底板上表面 z=0 起算。盒体仍只有四壁，外部有安装脚和燕尾座，内部没有底板。支座通过外侧燕尾立柱和横向锁键固定；托臂悬在盒沿上方，支座及血管芯允许超过 15 mm。独立底板厚度不计入上表高度。

9.60 mm 沿用现有 ABS 尺寸余量：成品宽、高目标下限为 9.00 mm，使用未实物校准的 2% 收缩预算与 0.30 mm 尺寸误差余量，按 0.20 mm 向上取整。预算下限为 9.60×0.98−0.30=9.108 mm；它不等于已经实测的成品尺寸。打印工程不再叠加缩放补偿。

## 打印与装配

同盘共有六件：血管芯、无底框架、两个支座和两枚锁键。打印工艺为 0.20 mm 层高；芯和支座启用普通贴合支撑，只有血管芯使用两层 raft。先清理临时支撑和配合面，在盒外将支架侧向接入芯的肩台，再把整组沿燕尾槽向下插入，最后装入横向锁键。框架放到平整浇注底面上，从外侧密封四壁下沿；液面以盒沿下方约 0.80 mm 为参考，并复核实际液厚。

本版使用新芯与缩短后的新框架，不与旧水平延伸芯混装。端口位置及支架接口参数仍沿用现有方案。完成浇注、固化和 ABS 牺牲芯去除后，通道只有两个上方开口，无需对横向端面做开放切割。
