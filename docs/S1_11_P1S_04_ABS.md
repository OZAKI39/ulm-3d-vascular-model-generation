# s1-11：P1S 0.4 mm / ABS 血管芯与支撑

本次按用户指定的范围，只重新生成血管芯和显式支撑。当前入口默认使用 P1S，历史 X1 Carbon 工程原位保留。本流程不改变 s1-2、s1-3 的可视化，也不生成外模或 C 插片。

## 输入与处理逻辑

下文 `R=outputs/topbrain_brava_transfer/nn_production/BG001/RMCA`。

血管输入是 `R/all_abs_sacrificial_casting_system/compact_c_retainer_v2/mold_2mm_clearance_5mm/vascular_core/BG001_RMCA_frozen_ABS_core.stl`，原始 SHA256 为 `84f1989392fb8d210432750a8022a830943b9bff890b044aa9d310822b619ce0`。关联 SWC 与端口由已有 `core_support_inputs` 读取。沿用历史已记录的 O002 刚体变换，不缩放、不增粗或修剪血管。

新适配模块 `vascular_processing/core_support_p1s.py` 解析实际 P1S 0.4 mm 机器配置、共享 `0.20mm Standard @BBL X1C` 工艺和保存的 `Bambu ABS Vessel` 材料。工艺名称包含 X1C，但其官方兼容列表包含 P1S，实际机器配置与启动/结束 G-code 均来自 P1S。层高为 0.20 mm，常规及支撑线宽为 0.42 mm，名义支撑间隙为 0.20 mm；支撑生成使用两线宽，即 0.84 mm。ABS 温度等配置完整保存在输出目录。

流程依次执行：保护源数据与历史文件 → 解析完整配置继承 → 按新线宽和层高生成支撑 → Bambu 原生切片 → 从真实挤出刀路检查支撑承托、血管保留及拆卸结构 → 输出模型与检查记录。最多尝试三轮真实缺口修补，并使用现有第 3 版拓扑拆分方法；变差的候选不替换较好的结果。

自动支撑在导出副本中关闭，因为工程已包含明确建模的支撑。工程中的两个正常部件是血管芯与支撑，组合为同一对象以保留高度关系。用户保存的 Bambu Studio 配置不被改写。

## 运行

```bash
cd /home/lzy/projects/vascular_printing
./run_python.sh s1-11_vascular_core_support.py --printer p1s-0.4
```

复核已完成的本次交付（不启动原生切片）：

```bash
./run_python.sh s1-11_vascular_core_support.py --printer p1s-0.4 --stage review
```

`--stage prepare` 只导出配置并保护源文件，`--stage geometry` 生成基线几何。`all`、`closure` 和 `slice` 均执行切片与验收流程。`--output` 可指定独立新目录；已有目录若配置改变会拒绝复用。原生切片失败保留日志，已成功完成的候选可复用。退出码 `2` 表示输出已生成但制造验收为 `NEEDS_ADJUSTMENT`，不等同于程序崩溃。
