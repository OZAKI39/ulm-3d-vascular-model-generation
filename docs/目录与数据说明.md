# 目录与数据说明

## 日常最常用的位置

| 位置 | 内容 |
|---|---|
| `deliverables/candidate_0/` | 正放模型与开启支撑的真实打印文件 |
| `deliverables/candidate_15/` | 侧放模型与开启支撑的真实打印文件 |

| `migration/20260926/` | 本次迁移清单、哈希、日志、代码路径适配及清理记录 |

`deliverables/` 是指向正式输出的快捷链接，模型没有被复制成另一份需要分别维护的数据。

## 正式输出链在哪里

生产数据位于：

```text
outputs/topbrain_brava_transfer/nn_production/BG001/RMCA/
├── refined_roi/                  近端解剖修正和血管区域
├── manufacturing_roi/            制造半径处理与早期打印候选
└── compact_manufacturing_roi/    MINI / BALANCED / RICH 与后续制造
    ├── print_fixture_design_all_ports_aligned/  已验收四端口血管芯
    └── final_abs_casting_mold/   当前一体式五面 ABS 倒模件
        ├── final/               最终 STL、3MF、G-code
        ├── reference/           血管芯与独立完整盒体参考
        ├── diagnostic/          未来 PDMS 体积与诊断记录
        ├── QC/                  可视化检查图
        ├── tables/              间距、端口、姿态和切片表格
        ├── bambu/               每次真实切片的文件、配置和日志
        └── candidate_0_and_15/   两种姿态的独立文件包
```

原始报告可能提及同级其他历史目录，它们仍保留，用于说明数据、参数和验收来源。先前的开放框架已不作为当前生产目标，但相关源码仍被当前倒模流程调用，相关验收记录也用于回归，因此不能按日期直接删除。

## 原始数据和第三方工具

`vessel_model/` 保存 BraVa、小鼠血管及其他血管模型数据；原始 SWC 与处理后的 SWC 分开保留。`data/external/TopBrain/` 保存官方 ZIP、解压数据、许可文件和下载记录，`data/TopBrain` 是工作入口。原始数据与许可文件均未重新下载或修改。

`third_party/vascularmd/` 是已固定的 VascularMD 源码及其兼容记录，`Ultraliser/` 是共享表面重建工具。它们的 Git 历史一同保留。Python 环境仍由相邻工作区共享，未复制安装包。

## 哪些东西留在旧项目

`/home/lzy/projects/ulm_3D_vascular` 继续保存 CFD、Network H0、流场求解、相关输出、报告和原仓库 Git 历史。共享血管代码和数据的旧位置仅保留兼容链接，实际文件位于新目录。

部分历史 JSON、CSV、日志和报告记录旧绝对路径。这些记录保持原文，由兼容链接支持读取，不能删除所有旧链接后仍期待旧记录自动可读。当前迁移完成的是本工作区内的独立打印目录；它不是已经脱离共享环境和历史链接的跨电脑安装包。两个 `candidate_*.zip` 则包含独立的模型与打印文件，可以单独复制使用。
