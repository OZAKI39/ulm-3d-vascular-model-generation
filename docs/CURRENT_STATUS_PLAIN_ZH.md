## “生成外形的工具崩溃”是什么意思

这个工具叫 Ultraliser。可以把血管骨架想成几根细线：它负责给这些线加上粗细，做出三维血管外形；后面才用这个外形划分计算网格、计算血液怎么流。

安装检查时，我临时画了几个很小的测试模型。两个模型让这个程序报错退出：

- 一根直管：例如 A—B—C 三个点只有 AB、BC 两段。程序错误地按“三个点就计算三段”执行，最后还想计算 C 到下一个点，但下一个点不存在，因此退出。这是程序把循环终点写错了。
- 一个很规则、左右对称的 Y 形分叉：重新定位后发现，程序在整理表面时没有找到预期相邻的一块小面片，却仍然读取这块不存在的面片，因而退出。这个直接原因已查明；为什么该输入会产生异常的连接关系，还没有查到最早发生的步骤，不能认定“只要对称就必然出错”。

另一个不完全对称的分叉小模型成功生成了完整外形。它通过不代表前两个错误已经修好。

这两次失败发生在临时测试模型上，现有小鼠血管外形、保存的流场和微泡结果都没有因此损坏。继续读取和分析已有结果不需要重新生成外形。如果以后要从血管骨架重新生成外形，这个工具仍有遇到上述问题的可能，需要针对实际输入检查。

完整证据见[安装与清理报告](SOLVER_INSTALL_AND_CLEANUP_ZH.md)。
