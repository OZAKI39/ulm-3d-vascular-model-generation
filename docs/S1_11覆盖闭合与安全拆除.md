# s1-11：实际承托闭合与安全拆除

> 本文保留为 `closure_v2` 历史方法记录。当前默认入口、验收规则和输出目录已更新，使用时请阅读 [s1-11 最终实用验收](S1_11最终实用验收.md)。下面的八轮循环与数学 100% 门槛不再用于当前生产判断。

本轮继续原有 s1-11，不创建 s1-12。输入仍为 s1-10 已冻结的 BG001 RMCA 血管芯、补偿和平滑 SWC、端口记录以及当前保存的 X1 Carbon / 0.2 mm / ABS / 0.10 mm 配置。血管、端口、模具、固定件和既有 s1-10 数据均不修改。

## 使用

```bash
cd /home/lzy/projects/vascular_printing
./run_python.sh s1-11_vascular_core_support.py --stage closure
```

省略 `--stage` 同样进入本轮闭合流程。每条既有姿态与 gap 路线默认最多 8 次局部修补。命令支持续跑；已有实际切片结果用于恢复，不会重新搜索全部 48 个姿态。`--stage review` 只汇总已有结果；`--stage legacy-review` 保留上一版报告入口。

输出目录：

```text
outputs/topbrain_brava_transfer/nn_production/BG001/RMCA/
  vascular_core_support_production/closure_v2/
```

必须先查看 `safe_removal_summary.json` 的 `status` 和 `production_selected`。未通过所有门槛时生产候选保持 `null`，`selected/` 只保存诊断模型。退出码 2 表示制造检查未通过；实际运行异常另存 `runtime_error.json`，不能用异常代替收敛判断。

## 处理逻辑

1. 读取最新报告、逐点覆盖、逐层多边形、候选比较及拆除和空移记录，备份至 `reports/baseline/`，记录冻结源文件哈希。
2. 使用既有 O002 与两个备选姿态，比较已有 0.20 / 0.25 mm gap 候选。每次只修正实际未通过位置，依次尝试顶面延长、侧移、局部三线宽和短竖直补片。
3. 尺寸由当前线宽或层高决定。修改前检查是否可能破坏其它采样点的间隙，修改后必须真实调用 Bambu，重新检查所有位置。预检查不能代替真实刀路判断。
4. 若候选同时不劣于当前缺点数和缺口面积，才用于下一轮；回退不会删除失败记录。只有连续两次实际检查的缺点数和缺口面积均不改善，才允许提前停止。达到默认轮数上限也会明确记录。
5. 中心线、端口、逐层区域全部 100%，且支撑自身未支撑区域为零后，才能冻结承托几何并尝试可剪连接片。任何拆除改型都再次真实切片；覆盖降低或连接片丢失时回退。
6. 安全拆除采用有限虚拟切面、实际连通组件、3 mm 圆柱探针及刚体扫掠。尚未剪掉的材料仍是障碍物，每次移除后更新障碍集合。软件不允许通过血管弯曲获得路径。

没有合格生产候选时，诊断展示按三类覆盖率中最低的一项排序。因此诊断模型可能在某个指标上比原基线更差，不能作为替代原基线的已验收模型。若多个间隙路线都真正闭合，则逐个检查拆除安全性，通过全部门槛后才比较力臂、包覆、接触长度与材料量。

顺序检查使用实际 STL 法线，接触点取真实下表面采样点；大组件的力臂采用这些接触位置中的最大值。截面积只计算当前分支所在的闭合截面，排除同一平面切到的其它血管。`--stage review` 会保留早期运行异常并继续读取后续成功切片，避免漏掉中间失败之后的有效证据。

原始支撑二进制 STL 若因浮点精度丢失极细接缝，可以改用双精度 ASCII STL，必须通过重新读取后的闭合体检查；不改变尺寸，也不扩大覆盖容差。无论文件编码为何，都使用同一真实切片判据。

## 输出与用途

|文件或目录|用途|
|---|---|
|`support_closure_iterations.csv`|每次实际切片的缺点数、缺口面积、自身悬空、是否接受和父候选|
|`candidates/*/local_repairs.json`|每个局部修改的目标、尺寸、拒绝原因和源哈希|
|`candidates/*/bambu/`|Bambu 原生 3MF、实际命令、日志和刀路|
|`coverage_final.json`、`layer_coverage_final.json`|最终诊断候选的逐点及逐层证据|
|`support_self_final.json`|支撑自身实际逐层检查|
|`safe_removal_segments.csv`、`removal_load_paths.csv`|接触分支、弧长、施力位置、力臂与包覆风险|
|`weak_links.csv`|弱连接尺寸、实际血管截面及面积比；未认证时保留为空|
|`final_contact_pieces.csv`|实际剪切后剩余接触组件的大小及风险|
|`bifurcation_removal_audit.csv`|分叉附近接触块及移除方向|
|`safe_removal_sequence.json`|逐轮剪切和移除记录；覆盖未闭合时生产方案为空|
|`QC_SAFE/`|17 张实际检查图；失败点显示红色，不伪造全绿|
|`selected/`|独立血管、独立支撑、拼接审阅 STL、两个独立 part 的 `X1C_project.3mf`|
|`vascular_core_support_safe_removal_report.md`|中文运行结果与停止原因|
|`SAFE_SUPPORT_REMOVAL_GUIDE.md`|按实际组件列出的操作限制；无生产候选时不提供虚构操作步骤|
|`validation/`|源保护、合成刀路回归及检查数据|

## 开发接口

- `core_support_closure.py`：局部修补、真实覆盖循环、回退和停止条件。
- `core_support_safe_geometry.py`：覆盖闭合后的可剪连接片试验及切片回退。
- `core_support_safe_removal.py`：顺序可达性、未剪材料、组件释放、载荷路径及硬门槛。
- `core_support_safe_fixtures.py`：11 类新增合成模型及两线宽／三线宽连接片的实际切片试验。
- `core_support_safe_review.py`：QC_SAFE、中文报告和拆除限制指南。

永久回归继续保存在 `tests/test_s1_11_vascular_core_support.py`，原有测试保留。新合成 STL 位于 `tests/data/vascular_core_support/safe_removal/`。

```bash
./run_python.sh -m pytest -q tests/test_s1_11_vascular_core_support.py
```

面积比、几何力臂和刚体移除路径都是代理指标，不等于 ABS 断裂力、真实拆卸力或血管不会损伤。即使所有软件检查通过，也只能进入人工复核与实物工艺验证。
