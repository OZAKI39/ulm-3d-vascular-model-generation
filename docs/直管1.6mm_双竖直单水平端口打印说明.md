# 三端口直管：ABS 血管芯与 PLA 无底夹具

2026-10-12 当前版。**只有血管芯为 ABS；盒体、外置磁铁槽、燕尾支座与锁键均为 PLA。** 使用 Bambu P1S / 0.4 mm 喷嘴，模型保持既有尺寸，只交付未切片工程，由您自行切片。

入口及出口 1 竖直向上，出口 2 水平延伸并完全内埋，距封闭端壁 3 mm，倒模后手动切开 PDMS；共 6 个组件。

芯径 1.60 mm，最薄 PDMS 底层 1.50 mm，PDMS CAD 浇注高度 9.60 mm。盒壁 2 mm，盒内无底板；外侧安装脚与燕尾连接保留。跨盒托臂高出盒沿 3 mm，盒体顶高 10.40 mm，支座顶高 17.80 mm，芯端口顶高 18.40 mm。两侧磁铁盲槽内径 6.40 mm、深 2 mm、底厚 1 mm。

原有 9.60 mm 腔体余量保持，不将历史 ABS 收缩率作为 PLA 参数。当前未对 PLA 实物尺寸、配合或浇注效果作验收。

## 文件与使用

项目本地根目录为 `/home/lzy/projects/vascular_printing`，服务器为 `/workspace/vascular_printing`。当前输出：

```text
outputs/straight_channel/D1p6_PDMSmin9_ABScore_PLAfixture_bottomless_dovetail_raised3mm_magnets_3dm_P1S04_internal_end_unsliced/
```

在 Bambu Studio 分别打开 `Straight_3Port_P1S_04_core_ABS_project.3mf` 与 `Straight_3Port_P1S_04_fixture_PLA_project.3mf`，核对材料和支撑后自行切片。两个工程仅包含对应材料的独立零件，没有打印刀路。请勿将浇注装配态整体送入打印。

同目录保留装配和分件排版 3dm、生产 STL、血管芯 STEP、几何检查图和 `manual_slicing_summary.json`。3dm 为毫米单位的封闭网格，每个组件带有材料属性。完整 ZIP 在 `deliverables/`，文件名含 `ABScore_PLAfixture` 与 `unsliced`。

```bash
cd /home/lzy/projects/vascular_printing
./run_python.sh generate_straight_channel_casting.py --config config/straight_channel_1p6_p1s_abs.yaml
```

默认生成模型、未切片工程和压缩包；`--stage project` 仅从已检查的模型重新导出工程，`--stage slice` 已禁用。服务器使用 `run_server_python.sh`。

详细材料设置、路径和装配方法见 [ABS 芯 / PLA 夹具自行切片说明](ABS血管芯_PLA夹具_自行切片使用说明.md)，磁铁槽来源见 [磁铁槽说明](三版模具_外置磁铁槽使用说明.md)。先前全 ABS 版本的详细研发记录保存在 [历史说明](history/before_manual_slice_ABS_PLA_20261012/直管1.6mm_双竖直单水平端口打印说明.md)，不能用于选择当前打印文件。
