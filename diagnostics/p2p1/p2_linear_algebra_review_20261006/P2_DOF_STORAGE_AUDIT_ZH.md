# P2/P1 代数存储审计

223,119 个额外槽位是六类边中点的压力占位，对应唯一 P2 边数。它们不构成独立压力基函数，不是需要删除的 P2 速度自由度。

`read_files` 选用两种场空间；原生单元装配仅使用四个压力基函数。`fs::thood_val_rc` 将边压力残差置零，压力块对角置1、其它压力块位置置0。`Integrator` 在解更新阶段为输出恢复边节点压力插值。这些都不增加数学上的压力空间。

原始 mesh ID 经 rank-local O1、所有权 O2、`plhs.ltg` 转为 PETSc node ID；标量行列为 `4*node+component`。`petsc_create_vecmat` 对每个单元的十节点邻接采用完整 4×4 blocked preallocation，AIJ CUDA 后端继续保留这些标量位置。强 Dirichlet 的 `MatZeroRowsColumns` 同样保留结构。结构项不等于实际非零系数；图构造中的数值零矩阵不能证明实际装配中某项必为零。

compact reference 是对同一节点 CSR 图施加每节点 4 或 3 个分量的严格限制。节点邻接块数没有减少，减少的是块内标量槽位；不能称为删除了 36M 个完整 4×4 块。理论删去 36,344,511 个标量结构项（32.51045%）、223,119 行（21.509%），CSR value/index/row payload 少 437,026,608 bytes（约0.407 GiB）。这不是整个进程或 LU 峰值节省比例。

参考 NPZ 以节点 CSR、分量数与混合前缀偏移无损表示标量图，避免为了参考图再次分配全部 75M 标量项。包含角点 pressure-pressure 结构位置，不把 native mixed 稳定化开关产生的数值零误写为结构删除。未修改生产编号、装配和输出。

## 首个真实P2系统的补充测量

在PC缩放之前，111,793,312个结构项中实际非零 61,418,086，数值零 50,375,226。223,119条边压力行的非对角系数与RHS均严格为0；全局对角值范围1–5，因为共享节点的本地单位条目会经ADD_VALUES累加。零残差、正对角仍只约束压力增量为0，不增加压力基函数。此计数属于初始残差/Jacobian，不是稳态场；一般非线性状态下数值非零总数可能变化。
